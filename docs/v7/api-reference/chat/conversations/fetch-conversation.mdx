---
title: "Fetch Conversation"
api: "GET /v7/:projectId/chat/conversations/:conversationId"
description: "Fetch a single conversation by ID"
---

Returns a [Conversation](/v7/data-models/conversation) object with the caller's membership row and active member count included. The caller must be a member of the conversation, current or former; for a space chat, any member of the space who is not banned there or in a parent space (including one whose request is pending or was declined) can fetch it before opening it for the first time. A space chat in a space the caller can't see (see [who can see a space](/v7/data-models/space#visibility)) answers `403 chat/not-a-member` even if they opened it before.

## Path Parameters

<ParamField path="conversationId" type="string" required>
  The ID of the conversation to fetch.
</ParamField>

## Response

Returns a [Conversation](/v7/data-models/conversation) with two additional fields:

<ResponseField name="currentMember" type="ConversationMember | null">
  The calling user's membership row for this conversation. `null` if the user has no membership record.
</ResponseField>

<ResponseField name="memberCount" type="number">
  Number of currently active members.
</ResponseField>

## Error Responses

<AccordionGroup>
  <Accordion title="Forbidden — 403">
    ```json
    { "error": "You are not a member of this conversation.", "code": "chat/not-a-member" }
    ```
  </Accordion>
  <Accordion title="Not Found — 404">
    ```json
    { "error": "Conversation not found.", "code": "chat/not-found" }
    ```
  </Accordion>
</AccordionGroup>

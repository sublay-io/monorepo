## Overview

`useUnbanMember` returns a callable function for unbanning a member. Sets their membership status from `"banned"` back to `"active"`, in this space and in the child spaces where they are banned. Refused while the member is still banned in a parent space. Requires the caller to be a moderator or admin.

## Usage Example

```tsx
import { useUnbanMember } from "@sublay/react-js";

function BannedMemberRow({ spaceId, userId }: { spaceId: string; userId: string }) {
  const unban = useUnbanMember();

  return (
    <button onClick={() => unban({ spaceId, userId })}>
      Unban
    </button>
  );
}
```

## Parameters

<ParamField path="spaceId" type="string" required>
  UUID of the space.
</ParamField>

<ParamField path="userId" type="string" required>
  UUID of the banned user to unban — their user id, not a membership id. Must be another member: your own id is refused (`400 space/own-member-id`). Your own membership is [`useCheckMyMembership`](/v8/hooks/spaces/use-check-my-membership) / [`useLeaveSpace`](/v8/hooks/spaces/use-leave-space).
</ParamField>

## Returns

<ResponseField name="message" type="string">
  Confirmation message.
</ResponseField>

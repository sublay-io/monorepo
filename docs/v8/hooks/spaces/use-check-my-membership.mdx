## Overview

`useCheckMyMembership` returns a callable function that checks the authenticated user's membership in a specific space without loading the full space object. A user with a membership gets it back whatever its status (a banned user learns they're banned); a user with no membership in a space they can't see gets `404 space/not-found`. It calls `GET /spaces/:spaceId/members/me`.

Your own membership is always `…/members/me`: this hook reads it and [`useLeaveSpace`](/v8/hooks/spaces/use-leave-space) leaves it. The member hooks that take a `userId` ([`useUpdateMemberRole`](/v8/hooks/spaces/use-update-member-role), [`useApproveMember`](/v8/hooks/spaces/use-approve-member), [`useDeclineMember`](/v8/hooks/spaces/use-decline-member), [`useBanMember`](/v8/hooks/spaces/use-ban-member), [`useUnbanMember`](/v8/hooks/spaces/use-unban-member)) act on other members and refuse your own id.

## Usage Example

```tsx
import { useCheckMyMembership } from "@sublay/react-js";

function MembershipBadge({ spaceId }: { spaceId: string }) {
  const checkMembership = useCheckMyMembership();

  const handleCheck = async () => {
    const result = await checkMembership({ spaceId });
    console.log(result.isMember, result.role, result.status);
  };
}
```

## Parameters

<ParamField path="spaceId" type="string" required>
  UUID of the space to check membership for.
</ParamField>

## Returns

<ResponseField name="isMember" type="boolean">
  Whether the user has an active membership.
</ResponseField>

<ResponseField name="role" type='"admin" | "moderator" | "member" | undefined'>
  The user's role. Present only when `isMember` is `true`.
</ResponseField>

<ResponseField name="status" type='"pending" | "active" | "banned" | "rejected" | undefined'>
  The user's membership status. Present only when a membership record exists, whatever its status.
</ResponseField>

<ResponseField name="joinedAt" type="string | undefined">
  ISO timestamp of when the membership was created. Present only when `isMember` is `true`.
</ResponseField>

<ResponseField name="permissions" type="object">
  Resolved permissions: `canPost`, `canModerate`, `canRead`, `isAdmin`, `isModerator`, from the same calculation as a fetched space's `memberPermissions` (see [How permissions are calculated](/v8/data-models/space#how-permissions-are-calculated)). Present for a user with no membership too.
</ResponseField>

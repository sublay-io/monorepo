## Overview

Returns a function that deletes a connection record by its `connectionId`. It withdraws a pending request the current user sent, or disconnects an accepted connection (either user can). The current user must be authenticated.

If you don't have the connection ID, use `useRemoveConnectionByUserId` instead.

## Usage Example

```tsx
import { useRemoveConnection } from "@sublay/react-js";

function DisconnectButton({ connectionId }: { connectionId: string }) {
  const removeConnection = useRemoveConnection();

  return (
    <button onClick={() => removeConnection({ connectionId })}>
      Disconnect
    </button>
  );
}
```

## Parameters

The hook returns a function. That function accepts:

<ParamField path="connectionId" type="string" required>
  The ID of the connection record to remove.
</ParamField>

## Returns

A `Promise<void>`. It resolves with no value once the connection is removed (the server answers `204 No Content`), and rejects if the request fails.

---
title: "Update Member Role"
api: "PATCH /v7/:projectId/spaces/:spaceId/members/:memberId/role"
description: "Update a member's role within a space"
---

Changes a member's role. Only space admins can perform this action. The role also applies in the space's child spaces: giving `"admin"` or `"moderator"` gives it there too (a promotion never lowers a role, so someone who is an admin of a child space stays one there), and a role below that removes `"admin"` and `"moderator"` there.

## Path Parameters

<ParamField path="spaceId" type="string" required>
  UUID of the space.
</ParamField>

<ParamField path="memberId" type="string" required>
  UUID of the membership record to update.
</ParamField>

## Body Parameters

<ParamField body="role" type="string" required>
  New role: `"admin"`, `"moderator"`, or `"member"`.
</ParamField>

## Response

<ResponseField name="message" type="string">
  Confirmation message.
</ResponseField>

<ResponseField name="membership" type="object">
  Updated membership with `id`, `role`, `status`, `joinedAt`, and `userId`.
</ResponseField>

## Errors

<AccordionGroup>
  <Accordion title="Membership Not Found — 404">
    ```json
    { "error": "Membership not found.", "code": "space/membership-not-found" }
    ```
  </Accordion>
  <Accordion title="Creator Required — 403">
    Someone other than the space creator (or a service or master key) promoting a member to, or demoting them from, `"admin"`.
    ```json
    { "error": "Only the space creator can promote or demote admins.", "code": "space/creator-required" }
    ```
  </Accordion>
  <Accordion title="Last Admin — 400">
    ```json
    { "error": "Cannot demote the last admin. Promote another member to admin first.", "code": "space/last-admin" }
    ```
    A role below `"admin"` also applies in the child spaces, so it is refused too when the member is the last admin of one of them, named by `spaceId`:
    ```json
    { "error": "This member is the last admin of a child space. Promote another member to admin there first.", "code": "space/last-admin", "spaceId": "…" }
    ```
  </Accordion>
  <Accordion title="Member Banned — 409">
    Giving the role `"admin"` or `"moderator"` to a member who is banned in this space or in one of its child spaces (the role also applies in the child spaces). `bannedSpaceIds` lists where the bans are, so they can be lifted first with [Unban Member](/v7/api-reference/spaces/membership/unban-member).
    ```json
    { "error": "This member is banned in this space or one of its child spaces. Lift those bans before giving them a role.", "code": "space/member-banned", "bannedSpaceIds": ["…"] }
    ```
  </Accordion>
  <Accordion title="Member Not Active — 409">
    Giving the role `"admin"` or `"moderator"` to a member whose request is pending or was rejected.
    ```json
    { "error": "Only an active member can be given a role.", "code": "space/member-not-active" }
    ```
  </Accordion>
</AccordionGroup>

See also: [useUpdateMemberRole](/v7/hooks/spaces/use-update-member-role)

# Sublay Components

Sublay provides a **CLI-based component distribution** system inspired by shadcn/ui. Instead of hiding UI components in `node_modules`, Sublay copies the full source code directly into your project so you own and control every line.

<Info>
**The philosophy:** Copy, paste, customize. Not install and configure.

You get **source code**, not packages. You **own** your components and can modify anything.
</Info>

---

## How It Works

<Steps>
  <Step title="Initialize Sublay">
    ```bash
    npx @sublay/cli init
    ```
    Configure your platform (React/React Native/Expo), styling preference (Tailwind/Inline styles), and component installation path.
  </Step>

  <Step title="Add Components">
    ```bash
    npx @sublay/cli add comments-threaded --ref v8
    # or
    npx @sublay/cli add comments-social --ref v8
    ```
    Components are copied directly into your `src/components/` directory as editable source files. `--ref v8` reads the component from the `v8` branch of the registry, where the v8 components live.
  </Step>

  <Step title="Use & Customize">
    ```tsx
    import { ThreadedCommentSection } from './components/comments-threaded';

    <ThreadedCommentSection entityId={entity.id} />
    ```
    Pass the Sublay entity the comments belong to — its `entityId`, or the `entity` object itself. The component works out of the box. Want to customize? Edit the source files directly.

    For a record in your own database, pass its ID as `foreignId` with `createIfNotFound` instead; see [Attach comments to records you already have](/v8/components/installation/quick-start#attach-comments-to-records-you-already-have).
  </Step>
</Steps>

## Styling Options

Each component comes in two styling variants:

### Inline Styles
- All styles as `style={{}}` objects in JSX
- No external dependencies
- Works everywhere
- Easy to find and change colors
- Theme support via conditional logic

### Tailwind CSS
- Utility classes for styling
- Requires Tailwind CSS 3.3 or later (4 included) on React, and NativeWind 4 on React Native and Expo
- Dark mode: the `dark:` prefix on React, the `theme` prop on React Native and Expo
- More concise code
- Easy to integrate with design systems

Choose your variant during `init` — you can switch by re-running `add` commands.

## What Gets Installed

When you add a comment component, about **40 TypeScript/TSX files** are copied into your project (threaded comments: 42 on React, 43 with Tailwind, 47 on React Native and Expo; social comments: 43 on React, 44 with Tailwind, 44 on React Native and Expo, 43 with Tailwind), plus the `index.ts` the CLI writes:

```
src/components/comments-threaded/
├── index.ts                    # Entry point
├── components/                 # All UI components (22 files on React)
│   ├── threaded-comment-section.tsx
│   ├── new-comment-form.tsx
│   ├── comments-feed/
│   └── modals/
├── hooks/                      # React hooks
├── utils/                      # Utilities
├── context/                    # React context
└── shared/                     # Shared pieces: GIF picker, avatar, skeletons, icons (13 files, 14 with Tailwind)
```

Every file is:
- ✅ Visible in your project
- ✅ Editable
- ✅ TypeScript with full type annotations
- ✅ Self-documenting with inline comments

## Required Dependencies

Components depend on Sublay's core libraries for data fetching, real-time updates, authentication, and more. The files in a component's `shared/` folder add a few third-party packages.

**For React (Web):**

| Package | Used for |
|---------|----------|
| `@sublay/react-js` `^8.0.0-beta.0` | Data, authentication, real-time updates |
| `@giphy/js-fetch-api` `^5.7.0`, `@giphy/react-components` `^10.1.1` | The GIF picker |
| `clsx` `^2.1.1`, `tailwind-merge` `^3.0.0` | Tailwind variant only: `cn`, which joins class names |

**For React Native / Expo:**

| Package | Used for |
|---------|----------|
| `@sublay/react-native` `^8.0.0-beta.0` (`@sublay/expo` on Expo) | Data, authentication, real-time updates |
| `@gorhom/bottom-sheet` `^5.0.0`, `react-native-reanimated` `>=3.16.0` | The comment menu and report sheets, and the collapse slide of threaded comments |
| `react-native-gesture-handler` `^2.31.1` | The sheets and the GIF picker |
| `react-native-svg` `^15` | Icons and the generated avatar for users without one |
| `nativewind` `^4.0.0` | Tailwind variant only |

Reanimated 4 and later also need `react-native-worklets`: on Expo, `add` installs it with Reanimated; on React Native, follow [Reanimated's install steps](https://docs.swmansion.com/react-native-reanimated/docs/fundamentals/getting-started/).

The CLI checks for these and offers to install them automatically. On Expo it installs them with `npx expo install`, so each matches your Expo SDK.

## Philosophy

The Sublay CLI follows these principles:

1. **Minimal Props** — Components work with a single prop that identifies the entity. No complex configuration required.
2. **Sensible Defaults** — Beautiful, accessible styling out of the box.
3. **Edit, Don't Configure** — Customize by editing source code, not passing config objects.
4. **Progressive Disclosure** — Ignore implementation details until you need to customize.
5. **Self-Documenting Code** — Clear file names, thorough comments, and color palettes documented in headers.

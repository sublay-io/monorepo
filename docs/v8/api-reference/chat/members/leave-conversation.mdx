---
title: "Leave Conversation"
api: "DELETE /v8/:projectId/chat/conversations/:conversationId/leave"
description: "Leave a group or space conversation"
---

Removes the current user from a conversation. Direct conversations (`type: "direct"`) cannot be left.

For group conversations, if the caller is the last `admin`, they must promote another member before leaving. The caller is evicted from the real-time room immediately.

## Path Parameters

<ParamField path="conversationId" type="string" required>
  The ID of the conversation to leave.
</ParamField>

## Query Parameters

<ParamField query="actingUserId" type="string">
  Service key only, and required with one: the user this request acts as. The member who leaves. A user token always acts as its own user and must not send it (`400 chat/acting-user-not-allowed`).
</ParamField>

## Response

```json
{ "message": "Left conversation." }
```

## Error Responses

<AccordionGroup>
  <Accordion title="Acting User Not Allowed — 400">
    A user token sent `actingUserId`, even naming its own user. Only a service key names the user it acts as; a user token always acts as its own user.
    ```json
    { "error": "actingUserId is only accepted with a service key. A user's own token always acts as that user.", "code": "chat/acting-user-not-allowed" }
    ```
  </Accordion>
  <Accordion title="Unsupported Parameter — 400">
    The request sent `userId`. On this route the user a service key acts as is `actingUserId`.
    ```json
    {
      "error": "`userId` was renamed to `actingUserId`: send the user this service key acts as in `actingUserId`.",
      "code": "chat/unsupported-param",
      "param": "userId"
    }
    ```
  </Accordion>
  <Accordion title="Missing User — 400">
    A service key sent no `actingUserId`.
    ```json
    { "error": "Missing user ID", "code": "chat/missing-user-id" }
    ```
  </Accordion>
  <Accordion title="Not Found — 404">
    ```json
    { "error": "Conversation not found.", "code": "chat/not-found" }
    ```
  </Accordion>
  <Accordion title="Cannot Leave DM — 400 Bad Request">
    ```json
    { "error": "Direct conversations cannot be left.", "code": "chat/cannot-leave-dm" }
    ```
  </Accordion>
  <Accordion title="Not a Member — 400 Bad Request">
    ```json
    { "error": "You are not an active member of this conversation.", "code": "chat/not-a-member" }
    ```
  </Accordion>
  <Accordion title="Last Admin — 400 Bad Request">
    ```json
    { "error": "You are the last admin. Promote another member before leaving.", "code": "chat/last-admin" }
    ```
  </Accordion>
</AccordionGroup>

## Overview

`useAddHost` returns a callable that adds a user to an event's `hostIds`. **Owner-only**: the logged-in user must be the event's [owner](/v8/data-models/event#owner-and-hosts), and, for an event in a space, an active member of that space who isn't banned in it or a space above it (`403 event/not-space-member` otherwise). Other hosts get `403 event/forbidden`. For an event in a space, the new host must be an active member of it (`409 event/host-not-member`). The operation is idempotent.

## Usage Example

```tsx
import { useAddHost } from "@sublay/react-js";

function AddCoHost({ eventId }: { eventId: string }) {
  const addHost = useAddHost();
  return (
    <button onClick={() => addHost({ eventId, userId: "usr_cohost" })}>
      Add co-host
    </button>
  );
}
```

## Parameters

<ParamField path="eventId" type="string" required>The event ID.</ParamField>
<ParamField path="userId" type="string" required>The user to make a host. For an event in a space, an active member of it.</ParamField>

## Returns

Returns a `Promise<Event>` — the [Event](/v8/data-models/event) with the new `hostIds`.

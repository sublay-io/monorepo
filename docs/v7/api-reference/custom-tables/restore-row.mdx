---
title: "Restore Row"
api: "POST /v7/:projectId/db/:tableName/:rowId/restore"
description: "Bring back a soft-deleted row on a paranoid table"
---

Clears a row's `deletedAt`, returning it to normal reads.

Only works on a **paranoid** table — one created with `paranoid: true`, where deletes are soft by default. Restoring on a non-paranoid table fails with `database/not-paranoid`, since a delete there removed the row permanently and there is nothing to bring back.

<Warning>
  Row endpoints capture the caller's identity but **enforce no authorization**. See [Security: open row CRUD](/custom-tables#security-open-row-crud).
</Warning>

## Path Parameters

<ParamField path="tableName" type="string" required>
  Logical name of the custom table — pass `orders`, not `custom_orders`.
</ParamField>

<ParamField path="rowId" type="string" required>
  UUID of the soft-deleted row to restore.
</ParamField>

## Response

<ResponseField name="row" type="object">
  The restored row, with `deletedAt` cleared.
</ResponseField>

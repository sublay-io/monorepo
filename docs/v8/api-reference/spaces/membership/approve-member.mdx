---
title: "Approve Member"
api: "PATCH /v8/:projectId/spaces/:spaceId/members/:memberId/approve"
description: "Approve a pending membership request"
---

Sets a pending member's status to `"active"`. Requires the caller to be a moderator or admin.

## Path Parameters

<ParamField path="spaceId" type="string" required>
  UUID of the space.
</ParamField>

<ParamField path="memberId" type="string" required>
  UUID of the membership record to approve.
</ParamField>

## Body Parameters

<ParamField body="actingUserId" type="string">
  Required with a service key: the user this request acts as. The request has exactly that user's permissions, so it is refused unless they are a moderator or admin of the space, and it is recorded as theirs. With a user token, omit it (it may only name the token's own user).
</ParamField>

## Response

<ResponseField name="message" type="string">
  Confirmation message.
</ResponseField>

<ResponseField name="membership" type="object">
  Updated membership with `id`, `status: "active"`, and `joinedAt`.
</ResponseField>

## Errors

<AccordionGroup>
  <Accordion title="Missing Acting User — 400">
    A service key sent no `actingUserId`.
    ```json
    { "error": "A service key must send actingUserId: the user this request acts as.", "code": "space/missing-user-id" }
    ```
  </Accordion>
  <Accordion title="Invalid Acting User — 400">
    `actingUserId` is not a user id.
    ```json
    { "error": "actingUserId must be a user id.", "code": "space/invalid-body" }
    ```
  </Accordion>
  <Accordion title="Unauthorized — 403">
    A user token sent an `actingUserId` other than its own user.
    ```json
    { "error": "Unauthorized", "code": "space/unauthorized" }
    ```
  </Accordion>
  <Accordion title="Not a Moderator — 403">
    The caller (or the user named by `actingUserId`) is not a moderator or admin of the space.
    ```json
    { "error": "Moderator access required", "code": "space/moderator-required" }
    ```
  </Accordion>
  <Accordion title="Not Found — 404">
    ```json
    { "error": "Membership not found.", "code": "space/membership-not-found" }
    ```
  </Accordion>
  <Accordion title="Not Pending — 400">
    The request is no longer pending: it was already approved, declined or banned. The message names the current status, or says the request is no longer pending if it changed while the request was being handled.
    ```json
    { "error": "Membership is already banned.", "code": "space/not-pending" }
    ```
  </Accordion>
  <Accordion title="Banned in a Parent Space — 409">
    The member is banned in a parent of this space; `bannedSpaceIds` lists where.
    ```json
    { "error": "This member is banned in a parent of this space.", "code": "space/banned-in-parent", "bannedSpaceIds": ["…"] }
    ```
  </Accordion>
</AccordionGroup>

The `spaces` module includes a full set of membership management functions. Use these to build admin tools, automate onboarding flows, or enforce membership policies server-side.

Members are addressed by their **user id**. The acting user's own membership is checked with [checkMyMembership](#checkmymembership) and left with [leaveSpace](#leavespace) (`GET` / `DELETE /spaces/:spaceId/members/me`); the functions that take a `userId` (`updateMemberRole`, `approveMembership`, `declineMembership`, `banMember`, `unbanMember`) act on **another** member, and a `userId` equal to `actingUserId` is refused with `400 space/own-member-id`. The space creator stays an admin for good: they can't step down, leave the space, or be banned.

---

### joinSpace

Joins a space as the user named in `actingUserId`. If the space requires approval (`requireJoinApproval: true`), the membership is created in a pending state. A private space can't be joined: joining a space the user can't see answers `404 space/not-found`. Its moderators and admins add members with [addMember](#addmember).

```typescript
const result = await sublay.spaces.joinSpace({
  spaceId: "spc_abc123",
  actingUserId: "usr_abc123",
});
```

<ParamField body="spaceId" type="string" required>
  The Sublay space ID.
</ParamField>

<ParamField body="actingUserId" type="string" required>
  The user the service key acts as: the user who joins.
</ParamField>

**Returns** — `Promise<JoinSpaceResponse>`: `{ message, membership, memberPermissions }`, where [`memberPermissions`](/v8/data-models/space#spacememberpermissions) is what the user may do in the space now (a request awaiting approval reports `status: "pending"` and `isMember: false`).

### leaveSpace

Removes a member from a space, acting as that member (`DELETE /spaces/:spaceId/members/me`). The space creator can't leave (`400 space/creator-cannot-leave`).

```typescript
const result = await sublay.spaces.leaveSpace({
  spaceId: "spc_abc123",
  actingUserId: "usr_abc123",
});
```

<ParamField body="spaceId" type="string" required>
  The Sublay space ID.
</ParamField>

<ParamField body="actingUserId" type="string" required>
  The member who leaves: the request acts as them, and they must be an active member of the space.
</ParamField>

**Returns** — `Promise<LeaveSpaceResponse>`: `{ message, memberPermissions }`, where [`memberPermissions`](/v8/data-models/space#spacememberpermissions) is what the user may still do in the space as a non-member.

### checkMyMembership

Returns the membership status of a user in a space (`GET /spaces/:spaceId/members/me`). A user with a membership gets it back whatever its status (a banned user learns they're banned); a user with no membership in a space they can't see gets `404 space/not-found`.

```typescript
const result = await sublay.spaces.checkMyMembership({
  spaceId: "spc_abc123",
  actingUserId: "usr_abc123",
});
```

<ParamField body="spaceId" type="string" required>
  The Sublay space ID.
</ParamField>

<ParamField body="actingUserId" type="string" required>
  The user the service key acts as, whose membership is checked.
</ParamField>

**Returns** — `Promise<CheckMyMembershipResponse>`: `{ isMember, role?, status?, joinedAt?, permissions }`. `role` and `joinedAt` are present only when `isMember` is `true`, and `status` only when a membership record exists; a field that doesn't apply is left out, never `null`. Its `permissions` come from the same calculation as a fetched space's [`memberPermissions`](/v8/data-models/space#spacememberpermissions).

### fetchSpaceMembers

Returns a paginated list of approved members in a space.

```typescript
const result = await sublay.spaces.fetchSpaceMembers({
  spaceId: "spc_abc123",
  page: 1,
  limit: 20,
});
```

Open to anyone who can read the space. A members-only space, or a space under one, answers `403 space/members-access-denied` to a user who isn't an active member of that members-only space or of a space between it and this one.

<ParamField body="spaceId" type="string" required>
  The Sublay space ID.
</ParamField>

<ParamField body="page" type="number">
  Page number (1-indexed). Defaults to `1`.
</ParamField>

<ParamField body="limit" type="number">
  Results per page. Defaults to `20`.
</ParamField>

<ParamField body="role" type="string">
  Filter by role: `"admin"`, `"moderator"`, or `"member"`.
</ParamField>

<ParamField body="status" type="string">
  Filter by membership status: `"pending"`, `"active"`, `"banned"`, or `"rejected"`.
</ParamField>

<ParamField body="actingUserId" type="string">
  The user to list as, exactly as their own access token: a members-only space's list is open to them only as an active member. Omit it for the anonymous view (a members-only space returns `403 space/members-access-denied`).
</ParamField>

### updateMemberRole

Updates another member's role within a space. Only the space creator can promote or demote admins, and nobody can demote the creator.

```typescript
const result = await sublay.spaces.updateMemberRole({
  spaceId: "spc_abc123",
  actingUserId: "usr_admin123",
  userId: "usr_xyz789",
  role: "moderator",
});
```

<ParamField body="spaceId" type="string" required>
  The Sublay space ID.
</ParamField>

<ParamField body="actingUserId" type="string" required>
  The user the request acts as: they must be an admin of the space, and the action is recorded as theirs.
</ParamField>

<ParamField body="userId" type="string" required>
  The user id of the member to update. An id equal to `actingUserId` is refused (`400 space/own-member-id`).
</ParamField>

<ParamField body="role" type="string" required>
  The new role to assign: `"admin"`, `"moderator"`, or `"member"`.
</ParamField>

**Returns** — `Promise<UpdateMemberRoleResponse>`

### addMember

Adds a user to a space directly: they become an active member at once, with no request or approval step. This is how users get into a private space, which can't be joined.

A user with a `pending` or `rejected` membership becomes active; one who is already an active member is left as they are (`message` says so). A banned user can't be added until unbanned (`409 space/member-banned`), nor can a user banned in a parent space (`409 space/banned-in-parent`). A user can't be added when there is a block between them and the adder, in either direction, or when they are suspended (`403 space/user-cannot-be-added`; the response doesn't say which). The added user gets a `space-member-added` notification. See [Add Member](/v8/api-reference/spaces/membership/add-member) for every case and error.

```typescript
const result = await sublay.spaces.addMember({
  spaceId: "spc_abc123",
  actingUserId: "usr_mod123",
  userId: "usr_xyz789",
});
```

<ParamField body="spaceId" type="string" required>
  The Sublay space ID.
</ParamField>

<ParamField body="actingUserId" type="string" required>
  The user the request acts as: they must be an active moderator or admin of the space, and the action is recorded as theirs.
</ParamField>

<ParamField body="userId" type="string" required>
  The user to add.
</ParamField>

**Returns** — `Promise<AddMemberResponse>`: `{ message, membership }`, where `membership` has `id`, `spaceId`, `userId`, `role`, `status: "active"`, `joinedAt` and `createdAt`.

### banMember

Bans another member from a space, preventing them from rejoining. A moderator can ban only regular members; only the space creator can ban an admin, and the creator can't be banned.

```typescript
const result = await sublay.spaces.banMember({
  spaceId: "spc_abc123",
  actingUserId: "usr_mod123",
  userId: "usr_xyz789",
});
```

<ParamField body="spaceId" type="string" required>
  The Sublay space ID.
</ParamField>

<ParamField body="actingUserId" type="string" required>
  The user the request acts as: they must be a moderator or admin of the space, and the action is recorded as theirs.
</ParamField>

<ParamField body="userId" type="string" required>
  The user id of the member to ban. An id equal to `actingUserId` is refused (`400 space/own-member-id`).
</ParamField>

<ParamField body="reason" type="string">
  Why the member is banned; kept in the space's ban log.
</ParamField>

**Returns** — `Promise<BanMemberResponse>`

---
title: "Update Space"
api: "PATCH /v8/:projectId/spaces/:spaceId"
description: "Update a space's settings, name, description, or images"
---

Updates a space. Only the space's admin can update it. Supports multipart form data for avatar/banner image uploads.

## Path Parameters

<ParamField path="spaceId" type="string" required>
  UUID of the space to update.
</ParamField>

## Body Parameters

All fields are optional. Only provided fields are updated.

<ParamField body="name" type="string">
  Updated display name. 3–100 characters.
</ParamField>

<ParamField body="slug" type="string">
  Updated URL slug. Pass empty to clear.
</ParamField>

<ParamField body="description" type="string">
  Updated description.
</ParamField>

<ParamField body="readingPermission" type="string">
  `"anyone"` or `"members"`.
</ParamField>

<ParamField body="postingPermission" type="string">
  `"anyone"`, `"members"`, or `"admins"`.
</ParamField>

<ParamField body="visibility" type="string">
  `"public"`, `"unlisted"`, or `"private"`. Controls listing/discoverability, independent of `readingPermission`. Changes take effect immediately and are freely reversible. See [Space visibility](/v8/data-models/space#visibility).
</ParamField>

<ParamField body="requireJoinApproval" type="boolean">
  Whether joining the space needs admin approval. Applies to joins from this point on — memberships that are already pending or active are unaffected.
</ParamField>

<ParamField body="metadata" type="object">
  Updated metadata object.
</ParamField>

<ParamField body="avatarFile" type="file">
  New avatar image. Requires `avatarFile.options` when provided.
</ParamField>

<ParamField body="bannerFile" type="file">
  New banner image. Requires `bannerFile.options` when provided.
</ParamField>

<ParamField body="actingUserId" type="string">
  Required with a service key: the user this request acts as. The request has exactly that user's permissions, so it is refused unless they are an admin of the space, and it is recorded as theirs. A user token always acts as its own user and must not send it (`400 space/acting-user-not-allowed`).
</ParamField>

## Response

Returns the updated [SpaceDetailed](/v8/data-models/space) object.

## Error Responses

<AccordionGroup>
  <Accordion title="Invalid Id — 400">
    Returned when `spaceId` isn't a valid UUID. Checked before sign-in, permissions and the endpoint's other checks.
    ```json
    { "error": "Invalid space id: expected a UUID.", "code": "space/invalid-params" }
    ```
  </Accordion>
  <Accordion title="Missing Acting User — 400">
    A service key sent no `actingUserId`.
    ```json
    { "error": "A service key must send actingUserId: the user this request acts as.", "code": "space/missing-user-id" }
    ```
  </Accordion>
  <Accordion title="Invalid Acting User — 400">
    `actingUserId` is not a user id.
    ```json
    { "error": "actingUserId must be a user id.", "code": "space/invalid-body" }
    ```
  </Accordion>
  <Accordion title="Acting User Not Allowed — 400">
    A user token sent `actingUserId`, even naming its own user. Only a service key names the user it acts as; a user token always acts as its own user.
    ```json
    { "error": "actingUserId is only accepted with a service key. A user's own token always acts as that user.", "code": "space/acting-user-not-allowed" }
    ```
  </Accordion>
  <Accordion title="User Not Found — 404">
    Returned when a service key names an `actingUserId` that isn't a user in this project.
    ```json
    { "error": "No user with this actingUserId exists in this project.", "code": "space/user-not-found" }
    ```
  </Accordion>
  <Accordion title="Not an Admin — 403">
    The caller (or the user named by `actingUserId`) is not an admin of the space.
    ```json
    { "error": "Admin access required", "code": "space/admin-required" }
    ```
  </Accordion>
  <Accordion title="Not Found — 404">
    ```json
    { "error": "Space not found.", "code": "space/not-found" }
    ```
  </Accordion>
  <Accordion title="Forbidden — 403">
    Caller is not an admin of the space.
  </Accordion>
</AccordionGroup>

See also: [useUpdateSpace](/v8/hooks/spaces/use-update-space)

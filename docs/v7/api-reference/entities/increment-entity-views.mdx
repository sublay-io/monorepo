---
title: "Increment Entity Views"
api: "PATCH /v7/:projectId/entities/:entityId/increment-views"
description: "Add to an entity's view count"
---

Increments an entity's `views` counter and returns the updated entity.

<Warning>
  This endpoint requires a **service or master key** and cannot be called with an end-user token. Count views from your own backend rather than from the client, so a browser cannot inflate the number.
</Warning>

## Path Parameters

<ParamField path="entityId" type="string" required>
  UUID of the entity.
</ParamField>

## Query Parameters

<ParamField query="count" type="number">
  How much to add to the counter. Defaults to `1`. Must be a positive integer — pass a batch total to record views your backend has buffered rather than calling the endpoint once per view.
</ParamField>

## Response

Returns the full updated [Entity](/v7/data-models/entity), with `views` reflecting the increment.

<ResponseField name="id" type="string">
  UUID of the entity.
</ResponseField>

<ResponseField name="views" type="number">
  The view count after the increment.
</ResponseField>

## Overview

`useCollectionEntitiesWrapper` fetches the paginated list of entities saved in a collection. It supports multiple sort modes and infinite-scroll pagination via `loadMore`.

If no `collectionId` is passed, it defaults to the current collection from the Redux collections state (i.e., whatever `useCollections` is currently navigated to).

## Usage Example

```tsx
import { useCollectionEntitiesWrapper } from "@sublay/react-js";

function SavedFeed({ collectionId }) {
  const {
    entities,
    loading,
    hasMore,
    sortBy,
    setSortBy,
    loadMore,
    refetch,
  } = useCollectionEntitiesWrapper({
    collectionId,
    defaultSortBy: "addedAt",
    defaultSortDir: "desc",
    limit: 20,
  });

  return (
    <div>
      <select value={sortBy} onChange={(e) => setSortBy(e.target.value as any)}>
        <option value="addedAt">Recently Added</option>
        <option value="createdAt">Newest</option>
        <option value="top">Top Voted</option>
      </select>
      <ul>
        {entities.map((entity) => (
          <li key={entity.id}>{entity.title}</li>
        ))}
      </ul>
      {hasMore && (
        <button onClick={loadMore} disabled={loading}>
          Load more
        </button>
      )}
    </div>
  );
}
```

## Parameters

<ParamField body="collectionId" type="string | null" optional>
  The collection to fetch entities from. Defaults to the current collection in Redux state.
</ParamField>

<ParamField body="limit" type="number">
  Number of entities per page: a whole number from `1` to `100`. Defaults to `20`. A larger value is rejected with `400 collection/invalid-query`, never lowered to `100`.
</ParamField>

<ParamField body="defaultSortBy" type='"createdAt" | "addedAt" | "top" | "hot"' optional>
  Initial sort mode. Default: `"addedAt"` (sorted by when the entity was saved).
</ParamField>

<ParamField body="defaultSortByReaction" type="SortByReaction" optional>
  Initial reaction type `top` ranks by: `"upvote"`, `"downvote"`, `"like"`, `"love"`, `"wow"`, `"sad"`, `"angry"`, or `"funny"`. Only sent while `sortBy` is `"top"`. Default: `"upvote"`.
</ParamField>

<ParamField body="defaultSortDir" type='"asc" | "desc"' optional>
  Initial sort direction. Default: `"desc"`; ignored (not sent) for `"hot"`, which ranks one way only.
</ParamField>

<ParamField body="include" type="CollectionEntityIncludeParam" optional>
  Optional associations to include with each entity: `"user"`, `"space"`, `"topComments"`, `"files"`, `"grants"`. `"saved"` isn't accepted: every entity returned is in this collection.
</ParamField>

<ParamField body="topCommentsLimit" type="number" optional>
  With `"topComments"` included: how many top comments per entity. Server default `1`, maximum `5`. Not sent when `include` doesn't contain `"topComments"`.
</ParamField>

<ParamField body="topCommentsSortByReaction" type="ReactionType" optional>
  With `"topComments"` included: the reaction whose raw count ranks the top comments. Server default `"upvote"`. Not sent when `include` doesn't contain `"topComments"`.
</ParamField>

## Returns

<ResponseField name="entities" type="Entity[]">
  The current list of fetched entities. Appended to on each `loadMore` call.
</ResponseField>

<ResponseField name="loading" type="boolean">
  `true` while fetching the initial page or loading more.
</ResponseField>

<ResponseField name="error" type="SublayError | null">
  The last load failure, or `null`. Cleared when the next load starts; `loadMore()` retries it. A [`SublayError`](/v8/hooks/overview#sublayerror).
</ResponseField>

<ResponseField name="hasMore" type="boolean">
  `true` while `loadMore()` has something to fetch: a next page, or a load that failed.
</ResponseField>

<ResponseField name="sortBy" type='"createdAt" | "addedAt" | "top" | "hot"'>
  Current sort mode.
</ResponseField>

<ResponseField name="sortByReaction" type="SortByReaction">
  Current reaction type `top` ranks by.
</ResponseField>

<ResponseField name="sortDir" type='"asc" | "desc"'>
  Current sort direction.
</ResponseField>

<ResponseField name="setSortBy" type="(sortBy: 'createdAt' | 'addedAt' | 'top' | 'hot') => void">
  Change the sort mode. Resets the entity list and re-fetches from page 1.
</ResponseField>

<ResponseField name="setSortByReaction" type="(sortByReaction: SortByReaction) => void">
  Change which reaction `top` ranks by. Resets the entity list and re-fetches from page 1.
</ResponseField>

<ResponseField name="setSortDir" type="(sortDir: 'asc' | 'desc') => void">
  Change the sort direction. Resets the entity list and re-fetches from page 1.
</ResponseField>

<ResponseField name="loadMore" type="() => Promise<void>">
  Load the next page of entities and append it, or retry the load that failed. Does nothing while a load is running or when there is nothing more. Never rejects: a failure lands in `error`.
</ResponseField>

<Note>The entities are kept in the shared store under the collection, so saving or removing an entity shows in every hook on that collection, but each hook pages and sorts on its own. Show a collection's entities with one `useCollectionEntitiesWrapper` at a time: a second one on the same collection replaces them with its own first page.</Note>

<ResponseField name="refetch" type="() => Promise<void>">
  Reload from the first page with the current sort. The loaded entities stay until the new first page replaces them. Never rejects: a failure lands in `error`.
</ResponseField>

## Sort Modes

| Value | Description |
|-------|-------------|
| `addedAt` | Sorted by when the entity was added to the collection |
| `createdAt` | Sorted by entity creation date |
| `top` | Sorted by reaction count — upvotes by default, or the reaction set with `sortByReaction` |
| `hot` | Sorted by hot score (engagement-based) |

The whole collection is sorted before it is paginated, so `loadMore` continues the same order.

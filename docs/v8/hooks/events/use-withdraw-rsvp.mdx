## Overview

`useWithdrawRsvp` returns a callable that removes the logged-in user's RSVP. The RSVP row is deleted and the matching count decremented. The user can always withdraw their own RSVP, also from an event they can no longer [see](/v8/data-models/event#visibility) (for example after leaving its space). Withdrawing with no RSVP succeeds and changes nothing if they can see the event, and answers `404` if they can't.

## Usage Example

```tsx
import { useWithdrawRsvp } from "@sublay/react-js";

function WithdrawButton({ eventId }: { eventId: string }) {
  const withdrawRsvp = useWithdrawRsvp();
  return <button onClick={() => withdrawRsvp({ eventId })}>Withdraw RSVP</button>;
}
```

## Parameters

<ParamField path="eventId" type="string" required>The event ID.</ParamField>

## Returns

Returns a `Promise<WithdrawRsvpResponse>`: the [Event](/v8/data-models/event) with refreshed `rsvpCounts`, or, when the logged-in user can no longer see the event, only `{ id, userRsvp: null }`.

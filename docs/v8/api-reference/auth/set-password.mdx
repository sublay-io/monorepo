---
title: "Set Password"
api: "POST /v8/:projectId/auth/set-password"
description: "Set an initial password for an OAuth-only user"
---

Sets an initial password for the currently authenticated user. This is for accounts that signed up through OAuth (or an external identity) and have **no password yet** — for example, so they can later sign in with email and password, or unlink their last OAuth identity without being locked out. Requires the user's own access token in the `Authorization` header; a service key is refused (`403 auth/user-token-required`).

<Note>
  This endpoint is only for users who do **not** already have a password. If the
  user already has one, use [Change Password](/v8/api-reference/auth/change-password)
  instead, which verifies the current password before changing it.
</Note>

## Headers

<ParamField header="Authorization" type="string" required>
  `Bearer {accessToken}` — a valid access token for the authenticated user. A service key is refused.
</ParamField>

## Body Parameters

<ParamField body="newPassword" type="string" required>
  The password to set for the account.
</ParamField>

## Response

<ResponseField name="success" type="boolean">
  `true` on success.
</ResponseField>

<ResponseField name="message" type="string">
  Confirmation message: `"Password set successfully."`
</ResponseField>

## Error Responses

<AccordionGroup>
  <Accordion title="User Not Found — 403">
    ```json
    {
      "error": "User not found.",
      "code": "auth/no-user-found"
    }
    ```
  </Accordion>
  <Accordion title="Already Password Authenticated — 400">
    ```json
    {
      "error": "User already has a password. Use change-password instead.",
      "code": "auth/already-password-authenticated"
    }
    ```
    Returned when the user already has a password. Use
    [Change Password](/v8/api-reference/auth/change-password) instead.
  </Accordion>
  <Accordion title="Session Ended — 401">
    ```json
    { "error": "This session has ended. Sign in again.", "code": "auth/session-ended" }
    ```
    The access token is still valid, but its session no longer exists (signed out, password reset, or the account was claimed by a provider sign-in after its email went unverified). Adding a password needs a live session, so sign in again.
  </Accordion>
  <Accordion title="User Token Required — 403">
    A service key called this endpoint, with or without `actingUserId`. It needs the signed-in user's own access token.

    ```json
    {
      "error": "This endpoint needs the user's own access token; a service key can't use it.",
      "code": "auth/user-token-required"
    }
    ```
  </Accordion>
  <Accordion title="Unsupported Parameter — 400">
    The request sent `userId`, in the body or the query. These endpoints always act as the signed-in user, so there is no user to name.

    ```json
    {
      "error": "`userId` isn't accepted here: these endpoints always act as the signed-in user.",
      "code": "auth/unsupported-param",
      "param": "userId"
    }
    ```
  </Accordion>
</AccordionGroup>

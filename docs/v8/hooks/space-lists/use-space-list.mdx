## Overview

`useSpaceList` provides a stateful, paginated list of public spaces (the space directory) with support for filtering, sorting, search, and creation. For the spaces the current user is a member of, whatever their visibility, use [`useFetchMySpaces`](/v8/hooks/spaces/use-fetch-my-spaces). Each list is identified by a `listId` and maintains independent Redux state, allowing multiple lists on the same page. Spaces in a list carry no `memberPermissions`; to show what the current user may do in one, load it with [`SpaceProvider`](/v8/sdk/spaces/provider-and-hook) or [`useFetchSpace`](/v8/hooks/spaces/use-fetch-space).

For full integration guidance, see [Space Lists](/v8/sdk/spaces/space-lists).

## Usage Example

```tsx
import { useSpaceList } from "@sublay/react-js";
import { useEffect } from "react";

function SpaceDirectory() {
  const { spaces, loading, hasMore, fetchSpaces, loadMore } = useSpaceList({ listId: "directory" });

  useEffect(() => {
    fetchSpaces({ filters: { sortBy: "createdAt" } });
  }, []);

  return (
    <div>
      {spaces.map((space) => <div key={space.id}>{space.name}</div>)}
      {hasMore && <button onClick={loadMore} disabled={loading}>Load more</button>}
    </div>
  );
}
```

## Parameters

<ParamField path="listId" type="string" required>
  Unique identifier for this list's Redux state slice. Use distinct IDs for independent lists.
</ParamField>

## Returns

<ResponseField name="spaces" type="Space[]">
  Currently loaded spaces.
</ResponseField>

<ResponseField name="loading" type="boolean">
  `true` while fetching.
</ResponseField>

<ResponseField name="error" type="SublayError | null">
  The last load failure, or `null`. Cleared when the next load starts; `loadMore()` retries it. Shared by every mounted hook on the same `listId`. A [`SublayError`](/v8/hooks/overview#sublayerror).
</ResponseField>

<ResponseField name="hasMore" type="boolean">
  `true` while `loadMore()` has something to fetch: a next page, or a load that failed.
</ResponseField>

<ResponseField name="fetchSpaces" type="({ filters?, config?, options? }) => void">
  Trigger a new fetch. Resets to page 1. Takes one object: `filters` merge into the list's current filters, `config` is the list's page size, and `options` control this fetch.

  ```ts
  fetchSpaces({
    filters?: {
      sortBy?: "createdAt" | "members" | "alphabetical";
      sortDir?: "asc" | "desc" | null; // null: the sort's natural direction
      query?: string | null; // a blank value is left out of the request
      searchFields?: "slug" | "name" | "description" | null; // null: slug, name or description
      parentSpaceId?: string | "none" | "any" | null; // "none" (the default; null resets to it): top-level only; "any": every level
    },
    config?: { limit?: number },
    options?: { fetchImmediately?: boolean; resetUnspecified?: boolean; clearImmediately?: boolean };
  }) => void
  ```
</ResponseField>

<ResponseField name="loadMore" type="() => Promise<void>">
  Load the next page of spaces and append it, or retry the load that failed (a failed first page is retried as the first page). Does nothing before the first `fetchSpaces`, while a load is running on this list, while a debounced filter change is waiting to be fetched, or when there is nothing more. Never rejects: a failure lands in `error`.
</ResponseField>

<ResponseField name="refetch" type="() => Promise<void>">
  Reload page 1 with the list's stored filters, sort and config; a debounced filter change still waiting runs now instead. The loaded spaces stay until the new first page replaces them. Does nothing before the first `fetchSpaces`. Never rejects: a failure lands in `error`.
</ResponseField>

<ResponseField name="createSpace" type="function">
  Create a new space and insert it into the list. `name` is required (3–100 characters after trimming); every other field is optional, and `null` is the same as leaving it out. Resolves with the created space plus `memberPermissions` (see [SpaceMemberPermissions](/v8/data-models/space#spacememberpermissions)), or `undefined` if the request failed.

  ```ts
  createSpace(props: {
    name: string;
    slug?: string | null;
    description?: string | null;
    readingPermission?: "anyone" | "members";
    postingPermission?: "anyone" | "members" | "team";
    visibility?: "public" | "unlisted" | "private";
    requireJoinApproval?: boolean;
    metadata?: Record<string, any>;
    nsfw?: boolean;
    parentSpaceId?: string | null;
    insertPosition?: "first" | "last";
  }) => Promise<SpaceWithPermissions | undefined>
  ```

  <Note>
    Space avatars and banners are uploaded as files, not URLs, so they can't be
    set through this hook. Use [useCreateSpace](/v8/hooks/spaces/use-create-space)
    or [useUpdateSpace](/v8/hooks/spaces/use-update-space), which send the image as
    `multipart/form-data`.
  </Note>
</ResponseField>

<ResponseField name="deleteSpace" type="function">
  Delete a space and remove it from the list.

  ```ts
  deleteSpace(props: { spaceId: string }) => Promise<void>
  ```
</ResponseField>

<ResponseField name="sortBy" type="string | null">
  Current sort setting from Redux state. The list sorts by `"createdAt"` (newest first) until you pass another `sortBy`.
</ResponseField>

<ResponseField name="sortDir" type='"asc" | "desc" | null'>
  Current sort direction. `null` means the sort's natural direction: A–Z for `"alphabetical"`, otherwise newest / most first.
</ResponseField>

<ResponseField name="query" type="string | null">
  Current search term from Redux state.
</ResponseField>

<ResponseField name="searchFields" type='"slug" | "name" | "description" | null'>
  The field the current search term is matched against. `null` matches the slug, the name or the description.
</ResponseField>

<ResponseField name="parentSpaceId" type='string | "none" | "any"'>
  The parent filter in use: a space id (its direct sub-spaces the user can see that are public or that they're an active member of), `"none"` (top-level spaces only, the default) or `"any"` (spaces at every level). Every page, including `loadMore` and a re-sort, is fetched with it.
</ResponseField>

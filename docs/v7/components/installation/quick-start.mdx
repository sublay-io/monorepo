# Quick Start Guide

This guide will have you up and running with Sublay comment components in under 5 minutes.

---

## Before You Begin

- ✅ Node.js 20.5+ installed
- ✅ A React, React Native, or Expo project
- ✅ A [Sublay project](https://dash.sublay.io) created

---

## Step 1: Initialize the CLI

Run the init command in your project directory:

```bash
cd your-project
npx @sublay/cli init
```

### Answer the prompts:

<Steps>
  <Step title="Select Platform">
    ```
    ? Which platform are you using?
    ❯ React (Web)
      React Native
      Expo
    ```
  </Step>

  <Step title="Choose Styling">
    ```
    ? Which styling approach do you prefer?
    ❯ Tailwind CSS
      Inline Styles
    ```

    - Select **Tailwind CSS** if you use Tailwind
    - Select **Inline Styles** otherwise
  </Step>

  <Step title="Set Component Path">
    ```
    ? Where should components be installed? (src/components)
    ```

    Press Enter to use the default, or type a custom path.
  </Step>
</Steps>

The CLI creates a `sublay.json` configuration file and checks for required dependencies.

## Step 3: Add a Component

<Tabs>
  <Tab title="Threaded Comments">
    ```bash
    npx @sublay/cli add comments-threaded
    ```

    Reddit-style discussions with unlimited nesting, upvote/downvote, threading lines, and collapsible threads.
  </Tab>

  <Tab title="Social Comments">
    ```bash
    npx @sublay/cli add comments-social
    ```

    Instagram-style comments with single-level nesting, heart/like system, and Top/New/Old sorting.
  </Tab>
</Tabs>

The CLI copies ~25 source files into your project and shows a usage example.

---

## Step 4: Set Up SublayProvider

Wrap your app (or the relevant section) with `SublayProvider`:

<Tabs>
  <Tab title="React (Web)">
    ```tsx
    // App.tsx
    import { SublayProvider } from '@sublay/react-js';

    function App() {
      return (
        <SublayProvider projectId="your-project-id">
          {/* Your app content */}
        </SublayProvider>
      );
    }
    ```
  </Tab>

  <Tab title="React Native / Expo">
    ```tsx
    // App.tsx
    import { SublayProvider } from '@sublay/react-native'; // or '@sublay/expo'

    function App() {
      return (
        <SublayProvider projectId="your-project-id">
          {/* Your app content */}
        </SublayProvider>
      );
    }
    ```
  </Tab>
</Tabs>

To post, reply or vote, a user must be signed in. Sublay's [built-in auth](/v7/sdk/authentication/built-in) handles sign-up and sign-in for you; the [complete example](#complete-example) below adds a sign-in form.

<Note>
If your app already has its own authentication, see [External Authentication](/v7/sdk/authentication/external) to connect it to Sublay.
</Note>

## Step 5: Use the Component

<Tabs>
  <Tab title="Threaded Comments">
    ```tsx
    // BlogPost.tsx
    import { ThreadedCommentSection } from './components/comments-threaded';

    function BlogPost({ post }) {
      return (
        <div>
          <h1>{post.title}</h1>
          <p>{post.content}</p>
          <ThreadedCommentSection entityId={post.id} />
        </div>
      );
    }
    ```
  </Tab>

  <Tab title="Social Comments">
    ```tsx
    // Post.tsx
    import { SocialCommentSection } from './components/comments-social';

    function Post({ post }) {
      return (
        <div>
          <img src={post.image} />
          <p>{post.caption}</p>
          <SocialCommentSection entityId={post.id} />
        </div>
      );
    }
    ```
  </Tab>
</Tabs>

That's it! You now have a fully functional comment system.

## Complete Example

A working page with a sign-in form, using [built-in auth](/v7/sdk/authentication/built-in). Users sign up with `signUpWithEmailAndPassword` the same way. Sublay doesn't require a username, but the comment components do: as installed, they stop a user without one from posting, replying, voting or reporting. Pass a `username` at sign-up, or change `usernameRequiredCallback` in `hooks/use-threaded-comments.tsx` (or `hooks/use-social-comments.tsx`).

<Tabs>
  <Tab title="Threaded Comments">
    ```tsx
    import { SublayProvider, useAuth } from '@sublay/react-js';
    import { ThreadedCommentSection } from './components/comments-threaded';

    const PROJECT_ID = import.meta.env.VITE_PUBLIC_SUBLAY_PROJECT_ID;

    function SignInForm() {
      const { initialized, accessToken, signInWithEmailAndPassword } = useAuth();

      // Hide the form until auth has loaded, and once the user is signed in
      if (!initialized || accessToken) return null;

      const handleSubmit = (e: React.FormEvent<HTMLFormElement>) => {
        e.preventDefault();
        const form = e.currentTarget;
        signInWithEmailAndPassword({
          email: form.email.value,
          password: form.password.value,
        }).catch(console.error);
      };

      return (
        <form onSubmit={handleSubmit}>
          <input name="email" type="email" placeholder="Email" />
          <input name="password" type="password" placeholder="Password" />
          <button type="submit">Sign in</button>
        </form>
      );
    }

    function App() {
      return (
        <SublayProvider projectId={PROJECT_ID}>
          <div className="max-w-4xl mx-auto p-8">
            <SignInForm />
            <h1>My Blog Post</h1>
            <p>This is my awesome blog post content...</p>
            <ThreadedCommentSection entityId="blog-post-123" />
          </div>
        </SublayProvider>
      );
    }

    export default App;
    ```
  </Tab>

  <Tab title="Social Comments">
    ```tsx

      };

          <input name="email" type="email" placeholder="Email" />
          <input name="password" type="password" placeholder="Password" />

    }

          </div>
        </SublayProvider>
      );
    }

    export default App;
    ```
  </Tab>
</Tabs>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Import errors after adding component" icon="triangle-exclamation">
    Make sure the import path matches your `paths.components` in `sublay.json`:

    ```tsx
    // paths.components = "src/components"
    import { ThreadedCommentSection } from './components/comments-threaded';

    // paths.components = "app/ui"
    import { ThreadedCommentSection } from './ui/comments-threaded';
    ```
  </Accordion>

  <Accordion title="Components not rendering" icon="eye-slash">
    1. Check that `<SublayProvider>` wraps the component
    2. Verify `projectId` is correctly set
    3. Check the browser console for errors
  </Accordion>

  <Accordion title="TypeScript errors" icon="code">
    Ensure your `tsconfig.json` includes the components directory:

    ```json
    { "include": ["src/**/*"] }
    ```
  </Accordion>

  <Accordion title="Dark mode not working (Tailwind)" icon="moon">
    Set `darkMode: 'class'` in `tailwind.config.js` and add a `dark` class to a parent element:

    ```tsx
    <html className={isDark ? 'dark' : ''}>
    ```
  </Accordion>
</AccordionGroup>

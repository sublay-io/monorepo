## Overview

`useSpacePermissions` is a utility hook that turns a space's [`memberPermissions`](/v8/data-models/space#spacememberpermissions) into flat permission flags. Every flag comes from the server's calculation (see [How permissions are calculated](/v8/data-models/space#how-permissions-are-calculated)); the hook never works them out from the space's settings. When `memberPermissions` is missing (for example while the space is loading), every flag is `false`. It is used internally by `useSpaceData` and exposed for cases where you need the flags outside of a `SpaceProvider`.

<Tip>In most cases, you should use `useSpace` instead — it exposes `isMember`, `isAdmin`, `canPost`, etc. directly. Use `useSpacePermissions` only when working outside a SpaceProvider context.</Tip>

## Usage Example

```tsx
import { useSpacePermissions } from "@sublay/core";

const permissions = useSpacePermissions({
  memberPermissions: space.memberPermissions,
  postingPermission: space.postingPermission,
  readingPermission: space.readingPermission,
});

console.log(permissions.canPost, permissions.isAdmin);
```

## Parameters

<ParamField path="memberPermissions" type="SpaceMemberPermissions | null | undefined" required>
  The space's `memberPermissions`, which every single-space fetch returns, for members and non-members alike. `null` or `undefined` makes every flag `false`.
</ParamField>

<ParamField path="postingPermission" type='"anyone" | "members" | "team"' required>
  The space's posting permission setting. It doesn't change the flags.
</ParamField>

<ParamField path="readingPermission" type='"anyone" | "members"'>
  The space's reading permission setting. Defaults to `"anyone"`. It doesn't change the flags.
</ParamField>

## Returns

<ResponseField name="isMember" type="boolean">
  Whether the user is an active member.
</ResponseField>

<ResponseField name="isAdmin" type="boolean">
  Whether the user is an admin.
</ResponseField>

<ResponseField name="isModerator" type="boolean">
  Whether the user is a moderator.
</ResponseField>

<ResponseField name="canPost" type="boolean">
  Whether the user can post entities in the space, as the server reports it.
</ResponseField>

<ResponseField name="canModerate" type="boolean">
  Whether the user can moderate content.
</ResponseField>

<ResponseField name="canRead" type="boolean">
  Whether the user can read content in the space, as the server reports it.
</ResponseField>

<ResponseField name="isPending" type="boolean">
  Whether the user has a pending membership.
</ResponseField>

<ResponseField name="isBanned" type="boolean">
  Whether the user is banned.
</ResponseField>

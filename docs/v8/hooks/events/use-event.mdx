## Overview

`useEvent` reads the event loaded by [`EventProvider`](/v8/sdk/events/provider-and-hook) from context, returning the event plus bound actions (`updateEvent`, `deleteEvent`, `cancelEvent`, `setRsvp`, `withdrawRsvp`). `useEventData` is the underlying hook the provider uses — call it directly when you want the same managed state without the provider/context.

## useEvent

Call inside a descendant of `EventProvider`.

```tsx
import { useEvent } from "@sublay/react-js";

function EventDetail() {
  const { event, setRsvp, withdrawRsvp, cancelEvent } = useEvent();

  if (event === undefined) return <p>Loading…</p>;
  if (!event) return <p>Not found.</p>;

  return (
    <div>
      <h1>{event.title}</h1>
      <button onClick={() => setRsvp("going")}>Going</button>
    </div>
  );
}
```

`useEvent` returns a `Partial<UseEventDataValues>` (empty object outside a provider).

## useEventData

Manage an event without the provider. Pass either a pre-fetched `event` or an `eventId` to fetch.

```tsx
import { useEventData } from "@sublay/react-js";

function EventCard({ eventId }: { eventId: string }) {
  const { event, setRsvp } = useEventData({ eventId, include: "userRsvp" });
  // ...
}
```

### Parameters

<ParamField path="event" type="Event">A pre-fetched event. Use this or `eventId`.</ParamField>
<ParamField path="eventId" type="string">An event ID to fetch. Use this or `event`.</ParamField>
<ParamField path="include" type="EventIncludeParam">Associations to expand when fetching by `eventId`, as a single value or an array: `"user"`, `"space"`, `"files"`, `"userRsvp"`.</ParamField>

## Returns (both hooks)

<ResponseField name="event" type="Event | null | undefined">The event. `undefined` while loading, `null` if not found or inaccessible — also after the event is deleted, and after a cancel or withdraw answers with a short body because the user can no longer see it. Such an event stays `null` for that `eventId`: the hook doesn't fetch it again.</ResponseField>
<ResponseField name="setEvent" type="React.Dispatch">Set the event state directly (optimistic updates).</ResponseField>
<ResponseField name="updateEvent" type="(props: { update }) => Promise<Event | undefined>">Update mutable fields (hosts who are active members of the event's space).</ResponseField>
<ResponseField name="deleteEvent" type="() => Promise<void>">Delete the event (its [owner](/v8/data-models/event#owner-and-hosts), or the space's admins and moderators). Sets `event` to `null`.</ResponseField>
<ResponseField name="cancelEvent" type="() => Promise<CancelEventResponse | undefined>">Cancel the event (its owner, or the space's admins and moderators). Resolves with the event, or with `{ id, status: "cancelled" }` when the user can't see it, which sets `event` to `null`.</ResponseField>
<ResponseField name="setRsvp" type="(status: RsvpStatus) => Promise<Event | undefined>">Set/change the caller's RSVP.</ResponseField>
<ResponseField name="withdrawRsvp" type="() => Promise<WithdrawRsvpResponse | undefined>">Withdraw the caller's RSVP. Resolves with the event, or with `{ id, userRsvp: null }` when the user can no longer see it, which sets `event` to `null`.</ResponseField>

Every full-event response (update, cancel, RSVP, withdraw) is merged onto the loaded event, so the `space` and `files` it was fetched with stay, and the result is kept for when the hook comes back to the same `eventId`.

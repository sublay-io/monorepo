---
title: "Connections"
description: "Read and manage the logged-in user's own connections and pending requests"
---

The `connections` module acts on the **logged-in user's own** mutual connections — bidirectional relationships, similar to "friends." Use it to list accepted connections, inspect outgoing and incoming pending requests, and accept, decline, or remove connections.

<Tip>
  To **request** a connection with someone, check the connection status against a
  specific user, or remove a connection by the other user's ID, use the
  [`users`](/v8/js-sdk/users) module.
</Tip>

---

### fetchConnections

Returns a paginated list of your accepted connections.

```typescript
const { data, pagination } = await sublay.connections.fetchConnections({
  page: 1,
  limit: 20,
});
```

<ParamField body="page" type="number">
  Page number (1-indexed). Defaults to `1`.
</ParamField>

<ParamField body="limit" type="number">
  Results per page. Defaults to `20`.
</ParamField>

<ParamField body="query" type="string">
  Optional search term. Filters the list to connections whose other user's username or name contains this text (case-insensitive). When omitted, no filtering is applied.
</ParamField>

<ParamField body="searchFields" type="string">
  Restricts which field `query` matches against — `username` or `name`. When omitted, `query` matches either field.
</ParamField>

**Returns** — `Promise<PaginatedResponse<AcceptedConnectionRow>>`, where [`AcceptedConnectionRow`](/v8/data-models/connection#acceptedconnectionrow) is `{ id, user, status: "accepted", createdAt, respondedAt }` and `user` is the other user in the connection.

---

### fetchConnectionsCount

Returns the number of your accepted connections.

```typescript
const { count } = await sublay.connections.fetchConnectionsCount();
```

**Returns** — `Promise<{ count: number }>`

---

### fetchSentPendingConnections

Returns a paginated list of your outgoing connection requests that are still pending.

```typescript
const { data, pagination } =
  await sublay.connections.fetchSentPendingConnections({
    page: 1,
    limit: 20,
  });
```

<ParamField body="page" type="number">
  Page number (1-indexed). Defaults to `1`.
</ParamField>

<ParamField body="limit" type="number">
  Results per page. Defaults to `20`.
</ParamField>

**Returns** — `Promise<PaginatedResponse<ConnectionRow>>`, where [`ConnectionRow`](/v8/data-models/connection#connectionrow) is `{ id, user, type, message, status, createdAt, respondedAt }`. Here `user` is the user the request was sent to, `type` is `"sent"`, `status` is `"pending"` and `respondedAt` is `null`.

---

### fetchReceivedPendingConnections

Returns a paginated list of incoming connection requests you have received.

```typescript
const { data, pagination } =
  await sublay.connections.fetchReceivedPendingConnections({
    page: 1,
    limit: 20,
  });
```

<ParamField body="page" type="number">
  Page number (1-indexed). Defaults to `1`.
</ParamField>

<ParamField body="limit" type="number">
  Results per page. Defaults to `20`.
</ParamField>

**Returns** — `Promise<PaginatedResponse<ConnectionRow>>`. Here `user` is the user who sent the request, `type` is `"received"`, `status` is `"pending"` and `respondedAt` is `null`.

---

### acceptConnection

Accepts a pending incoming connection request.

```typescript
const result = await sublay.connections.acceptConnection({
  connectionId: "con_xyz789",
});
```

<ParamField body="connectionId" type="string" required>
  The ID of the pending connection request to accept.
</ParamField>

**Returns** — `Promise<ConnectionRow>`: the accepted connection from your side (`user` is the requester, `type` is `"received"`, `status` is `"accepted"`). See [ConnectionRow](/v8/data-models/connection#connectionrow).

---

### declineConnection

Declines a pending incoming connection request.

```typescript
const result = await sublay.connections.declineConnection({
  connectionId: "con_xyz789",
});
```

<ParamField body="connectionId" type="string" required>
  The ID of the pending connection request to decline.
</ParamField>

**Returns** — `Promise<ConnectionRow>`: the declined connection from your side (`user` is the requester, `type` is `"received"`, `status` is `"declined"`). See [ConnectionRow](/v8/data-models/connection#connectionrow).

---

### removeConnection

Removes a connection by its connection ID: withdraws a pending request you sent, or disconnects an accepted connection (either user can).

```typescript
await sublay.connections.removeConnection({ connectionId: "con_xyz789" });
```

<ParamField body="connectionId" type="string" required>
  The connection ID to remove.
</ParamField>

**Returns** — `Promise<void>`. It resolves with no value once the connection is removed (the server answers `204 No Content`).

## Overview

Returns a function that fetches the paginated list of users who follow the currently authenticated user. Each entry is a follow row: the follow record's `id`, the follower as `user`, and `createdAt`.

For fetching another user's followers, see `useFetchFollowersByUserId`.

<Note>
  Users with a block between them and you, in either direction, are excluded
  from the results. Requires the `moderation` bundle.
</Note>

## Usage Example

```tsx
import { useFetchFollowers } from "@sublay/react-js";

function FollowersList() {
  const fetchFollowers = useFetchFollowers();
  const [followers, setFollowers] = useState([]);

  useEffect(() => {
    fetchFollowers({ page: 1, limit: 20 }).then((res) => {
      setFollowers(res.data);
    });
  }, []);

  return (
    <ul>
      {followers.map(({ id, user }) => (
        <li key={id}>{user.name}</li>
      ))}
    </ul>
  );
}
```

## Parameters

The hook returns a function. That function accepts:

<ParamField path="page" type="number">
  Page number to fetch. Defaults to `1`.
</ParamField>

<ParamField path="limit" type="number">
  Number of results per page. Defaults to `20`.
</ParamField>

<ParamField path="query" type="string">
  Optional search term. Filters the list to users whose username or name contains this text (case-insensitive). When omitted or blank, no filtering is applied: a blank `query` is left out of the request, and `searchFields` with it.
</ParamField>

<ParamField path="searchFields" type="string">
  Restricts which field `query` matches against — `username` or `name`. When omitted, `query` matches either field.
</ParamField>

<SpaceReputationParams variant="user" field="path" />

## Returns

Returns a `PaginatedResponse<FollowRow>`. Each entry is a [`FollowRow`](/v8/data-models/follow#followrow):

<ResponseField name="data" type="FollowRow[]">
  Array of follower entries.
  <Expandable title="FollowRow properties">
    <ResponseField name="id" type="string">
      ID of the follow record.
    </ResponseField>
    <ResponseField name="user" type="User">
      The follower's user profile. When `spaceReputation` is requested, it carries an added `spaceReputation` number. See [User data model](/v8/data-models/user) and [Reputation](/v8/data-models/reputation).
    </ResponseField>
    <ResponseField name="createdAt" type="string">
      ISO timestamp of when the follow was created.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="pagination" type="object">
  Pagination metadata: `page`, `pageSize`, `totalPages`, `totalItems` and `hasMore`.
</ResponseField>

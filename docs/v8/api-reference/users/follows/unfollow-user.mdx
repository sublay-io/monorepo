---
title: "Unfollow User"
api: "DELETE /v8/:projectId/users/:userId/follow"
description: "Unfollow a user by their user ID"
---

Removes the follow relationship between the authenticated user and the specified user. This is a convenience alternative to [Delete Follow](/v8/api-reference/follows/delete-follow) — it looks up the follow record by user ID rather than requiring the follow ID.

## Path Parameters

<ParamField path="userId" type="string" required>
  The Sublay user ID (UUID) of the user to unfollow.
</ParamField>

## Query Parameters

<ParamField query="actingUserId" type="string">
  Service key only, and required with one: the user this request acts as, who stops following the user in the path. A user token always acts as its own user and must not send it (`400 follow/acting-user-not-allowed`).
</ParamField>

## Response

On success, returns HTTP `204` with no body.

## Error Responses

<AccordionGroup>
  <Accordion title="Missing User — 400">
    A service key sent no `actingUserId`.
    ```json
    {
      "error": "A service key must send actingUserId: the user this request acts as.",
      "code": "follow/missing-user-id"
    }
    ```
  </Accordion>
  <Accordion title="Acting User Not Allowed — 400">
    A user token sent `actingUserId`, even naming its own user. Only a service key names the user it acts as; a user token always acts as its own user.
    ```json
    {
      "error": "actingUserId is only accepted with a service key. A user's own token always acts as that user.",
      "code": "follow/acting-user-not-allowed"
    }
    ```
  </Accordion>
  <Accordion title="User Not Found — 404">
    Returned when a service key names an `actingUserId` that isn't a user in this project.
    ```json
    { "error": "No user with this actingUserId exists in this project.", "code": "follow/user-not-found" }
    ```
  </Accordion>
  <Accordion title="Not Following — 404">
    ```json
    {
      "error": "Follow relationship does not exist.",
      "code": "follow/not-found"
    }
    ```
  </Accordion>
</AccordionGroup>

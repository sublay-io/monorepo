## Overview

Returns an async function that returns the direct (1:1) conversation with a given user, creating it when there is none. A direct conversation between the two users that already exists is returned rather than duplicated. The conversation is also stored in Redux state.

Most hooks resolve to the plain record. This one resolves to `{ conversation, created }`, because whether the call created the conversation is part of its answer.

<Note>Requires `ChatProvider` in the component tree.</Note>

## Usage Example

```tsx
import { useCreateDirectConversation } from "@sublay/react-js";

function UserCard({ userId }: { userId: string }) {
  const createDirect = useCreateDirectConversation();

  const handleMessage = async () => {
    const { conversation, created } = await createDirect({ userId });
    // Navigate to the conversation, e.g. router.push(`/chat/${conversation.id}`)
  };

  return <button onClick={handleMessage}>Message</button>;
}
```

## Parameters

The hook returns a function. That function accepts:

<ParamField body="userId" type="string" required>
  The ID of the user to start a conversation with.
</ParamField>

## Returns

<ResponseField name="conversation" type="Conversation">
  The direct [Conversation](/v8/data-models/conversation), existing or just created.
</ResponseField>

<ResponseField name="created" type="boolean">
  `true` when this call created the conversation (HTTP `201`), `false` when it already existed (HTTP `200`).
</ResponseField>

## Overview

Returns a function that follows a target user. The current user must be authenticated. Use `useFollowManager` if you need status tracking and toggle behavior; use this hook directly when you need fine-grained control.

## Usage Example

```tsx
import { useFollowUser } from "@sublay/react-js";

function FollowButton({ userId }: { userId: string }) {
  const followUser = useFollowUser();

  const handleFollow = async () => {
    const follow = await followUser({ userId });
    console.log("Followed", follow.user.username);
  };

  return <button onClick={handleFollow}>Follow</button>;
}
```

## Parameters

The hook returns a function. That function accepts:

<ParamField path="userId" type="string" required>
  The ID of the user to follow.
</ParamField>

## Returns

The function resolves to the follow row, a [`FollowRow`](/v8/data-models/follow#followrow). Following a user you already follow is rejected with `409 follow/already-exists`.

<ResponseField name="id" type="string">
  ID of the follow record. [useUnfollowByFollowId](/v8/hooks/follows/use-unfollow-by-follow-id) takes it.
</ResponseField>

<ResponseField name="user" type="User">
  The followed user. See [User data model](/v8/data-models/user).
</ResponseField>

<ResponseField name="createdAt" type="string">
  ISO timestamp of when the follow was created.
</ResponseField>

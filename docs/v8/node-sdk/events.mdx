---
title: "Events"
description: "Create and manage events, RSVPs, hosts, and invites from the server"
---

The `events` module covers the full events surface: creating and editing events, the RSVP lifecycle, host and invite management, and the guest list. It maps directly to the [Events API](/v8/api-reference/events/create-event).

Because the Node SDK authenticates with a **service key** (it acts as the whole project, not a single end user), functions that act as a user take that user in [`actingUserId`](/v8/node-sdk/overview#acting-on-behalf-of-a-user). On the event-management functions (`updateEvent`, `cancelEvent`, `deleteEvent`, the host and invite functions, `fetchInvitees`), `actingUserId` is the host the call acts as, with exactly that host's powers. On the host and invite functions, `userId` is the **target** user (the host or invitee).

<Note>
  **Image upload caveat.** The Node SDK does not support inline cover/gallery
  upload on `createEvent`/`updateEvent` yet. Create the event first, then attach
  images with [`sublay.storage.uploadImage`](/v8/node-sdk/storage) using its
  `eventId` parameter. (The browser [JS SDK](/v8/js-sdk/events) and the
  [React SDK](/v8/sdk/events/overview) do support inline upload.)
</Note>

Requires the `events` bundle. Space-scoping needs the `spaces` bundle; images need `files-images`; notifications need `notifications`.

---

### createEvent

Creates an event. The `actingUserId` you pass becomes the creator and is auto-added to `hostIds`. Returns the event with inline `rsvpCounts`.

```typescript
const event = await sublay.events.createEvent({
  actingUserId: "usr_abc123",
  title: "Launch Party",
  type: "physical",
  startTime: "2026-09-01T18:00:00.000Z",
  endTime: "2026-09-01T22:00:00.000Z",
  timezone: "America/New_York",
  venueName: "The Loft",
  address: "123 Main St, New York, NY",
  location: { latitude: 40.7128, longitude: -74.006 },
  capacity: 100,
  visibility: "public",
});
```

<ParamField body="title" type="string" required>Event title. 1–300 characters.</ParamField>
<ParamField body="startTime" type="string" required>ISO datetime when the event starts.</ParamField>
<ParamField body="type" type='"online" | "physical" | "hybrid"' required>
  Event format. `online` requires `url`; `physical` requires `address` or `location`; `hybrid` requires both.
</ParamField>
<ParamField body="actingUserId" type="string" required>
  The user the service key acts as: the event's creator and first host, held to their own permissions (a space-scoped event needs them to be an active member). A user that doesn't exist returns `404 event/user-not-found`.
</ParamField>
<ParamField body="description" type="string">Optional description.</ParamField>
<ParamField body="endTime" type="string">Optional ISO end datetime.</ParamField>
<ParamField body="timezone" type="string">Optional IANA timezone.</ParamField>
<ParamField body="url" type="string">Join/stream URL.</ParamField>
<ParamField body="venueName" type="string">Venue name.</ParamField>
<ParamField body="address" type="string">Street address.</ParamField>
<ParamField body="location" type="{ latitude: number; longitude: number }">Coordinates for proximity search.</ParamField>
<ParamField body="spaceId" type="string">Scope the event to a space. Required when `visibility` is `"members"`.</ParamField>
<ParamField body="visibility" type='"public" | "members" | "invite"'>Defaults to `"public"`.</ParamField>
<ParamField body="capacity" type="number">Max `going` RSVPs. Omit for unlimited.</ParamField>
<ParamField body="allowMaybe" type="boolean">Allow `"maybe"` RSVPs. Defaults to `true`.</ParamField>
<ParamField body="guestListVisible" type="boolean">Expose the named guest list to non-hosts. Defaults to `true`.</ParamField>
<ParamField body="hostIds" type="string[]">Additional host user IDs (the creator is always added).</ParamField>
<ParamField body="metadata" type="object">Arbitrary key-value data. Up to 1 MB.</ParamField>

**Returns** — `Promise<Event>`

### fetchEvent

Fetches a single event by ID. Pass `actingUserId` to resolve visibility for that user and to populate `userRsvp` (with the `userRsvp` include).

```typescript
const event = await sublay.events.fetchEvent({
  eventId: "evt_abc123",
  include: ["user", "space", "files", "userRsvp"],
  actingUserId: "usr_abc123",
});
```

<ParamField body="eventId" type="string" required>The event ID.</ParamField>
<ParamField body="include" type="EventIncludeParam">Associations to expand, as a single value or an array: `"user"`, `"space"`, `"files"`, `"userRsvp"`.</ParamField>
<ParamField body="actingUserId" type="string">The user to read as: exactly what their own access token would get (visibility, `userRsvp`). Omit it for the anonymous view: only a `public` event is returned, any other answers `404`.</ParamField>

**Returns** — `Promise<Event>`

---

### fetchManyEvents

Lists events with visibility enforced, plus filtering, sorting, geo, and free-text search. Pass `actingUserId` to resolve member/invite/host visibility and to use the `myRsvp` filter.

```typescript
const { data, pagination } = await sublay.events.fetchManyEvents({
  timeWindow: "upcoming",
  sortBy: "startTime",
  sortDir: "asc",
  type: "physical",
  page: 1,
  limit: 20,
  actingUserId: "usr_abc123",
  include: ["user", "userRsvp"],
});
```

<ParamField body="page" type="number">Page number (1-indexed). Defaults to `1`.</ParamField>
<ParamField body="limit" type="number">Results per page. Capped at `100`.</ParamField>
<ParamField body="sortBy" type='"startTime" | "going"'>Sort field. Defaults to `"startTime"`.</ParamField>
<ParamField body="sortDir" type='"asc" | "desc"'>Sort direction. Left out, the sort's natural direction: soonest first for `"startTime"`, most going first for `"going"`.</ParamField>
<ParamField body="timeWindow" type='"upcoming" | "ongoing" | "past"'>Derived time window.</ParamField>
<ParamField body="startsAfter" type="string">ISO datetime lower bound on `startTime`.</ParamField>
<ParamField body="startsBefore" type="string">ISO datetime upper bound on `startTime`.</ParamField>
<ParamField body="spaceId" type="string">Restrict to one space.</ParamField>
<ParamField body="hostId" type="string">Only events this user hosts.</ParamField>
<ParamField body="type" type='"online" | "physical" | "hybrid"'>Filter by type.</ParamField>
<ParamField body="status" type='"active" | "cancelled"'>Defaults to `"active"`.</ParamField>
<ParamField body="myRsvp" type='RsvpStatus | RsvpStatus[]'>Statuses the requester RSVP'd with: `"going"`, `"maybe"` or `"not_going"`, e.g. `["going", "maybe"]`. Sent as one comma-separated value; values match exactly. Requires `actingUserId`.</ParamField>
<ParamField body="locationFilters" type="{ latitude: string; longitude: string; radius: string }">Proximity filter (radius in meters).</ParamField>
<ParamField body="titleFilters" type="{ hasTitle?; includes?; doesNotInclude? }">Free-text filter on `title`.</ParamField>
<ParamField body="descriptionFilters" type="{ hasDescription?; includes?; doesNotInclude? }">Free-text filter on `description`.</ParamField>
<ParamField body="include" type="EventIncludeParam">Associations to expand, as a single value or an array: `"user"`, `"space"`, `"files"`, `"userRsvp"`.</ParamField>
<ParamField body="actingUserId" type="string">The user to list as: exactly what their own access token would get (visibility, `myRsvp`, `userRsvp`). Omit it for the anonymous view: `public` events only.</ParamField>

**Returns** — `Promise<PaginatedResponse<Event>>`

### updateEvent

Edits an event's mutable fields. Host-only: `actingUserId` must be one of the event's hosts. `hostIds`, `status`, and `spaceId` are not editable here.

```typescript
const event = await sublay.events.updateEvent({
  eventId: "evt_abc123",
  actingUserId: "usr_host",
  capacity: 150,
  description: "Now with more space!",
});
```

<ParamField body="eventId" type="string" required>The event ID.</ParamField>
<ParamField body="actingUserId" type="string" required>The user the call acts as, with exactly their powers on the event; the action is recorded as theirs.</ParamField>
<ParamField body="title" type="string">New title.</ParamField>
<ParamField body="description" type="string">New description.</ParamField>
<ParamField body="startTime" type="string">New ISO start datetime.</ParamField>
<ParamField body="endTime" type="string">New ISO end datetime.</ParamField>
<ParamField body="timezone" type="string">New timezone.</ParamField>
<ParamField body="type" type='"online" | "physical" | "hybrid"'>New type (re-validates location fields).</ParamField>
<ParamField body="url" type="string">New URL.</ParamField>
<ParamField body="venueName" type="string">New venue name.</ParamField>
<ParamField body="address" type="string">New address.</ParamField>
<ParamField body="location" type="{ latitude: number; longitude: number }">New coordinates.</ParamField>
<ParamField body="visibility" type='"public" | "members" | "invite"'>New visibility.</ParamField>
<ParamField body="capacity" type="number">New capacity.</ParamField>
<ParamField body="allowMaybe" type="boolean">Allow `"maybe"` RSVPs.</ParamField>
<ParamField body="guestListVisible" type="boolean">Expose the guest list.</ParamField>
<ParamField body="metadata" type="object">New metadata.</ParamField>

**Returns** — `Promise<Event>`

### cancelEvent

Cancels an event (sets `status: "cancelled"`). The event stays fetchable but rejects new RSVPs. `actingUserId` must be a host, or an active admin or moderator of the event's space.

```typescript
const event = await sublay.events.cancelEvent({
  eventId: "evt_abc123",
  actingUserId: "usr_host",
});
```

<ParamField body="eventId" type="string" required>The event ID.</ParamField>
<ParamField body="actingUserId" type="string" required>The user the call acts as, with exactly their powers on the event; the action is recorded as theirs.</ParamField>

**Returns** — `Promise<Event>`

---

### deleteEvent

Permanently (or soft-, per the project's `eventDeletion` settings) deletes an event and cleans up its RSVPs and invites. `actingUserId` must be a host, or an active admin or moderator of the event's space.

```typescript
await sublay.events.deleteEvent({
  eventId: "evt_abc123",
  actingUserId: "usr_host",
});
```

<ParamField body="eventId" type="string" required>The event ID.</ParamField>
<ParamField body="actingUserId" type="string" required>The user the call acts as, with exactly their powers on the event; the action is recorded as theirs.</ParamField>

**Returns** — `Promise<void>`

### setRsvp

Sets or changes a user's RSVP. Transitions into `going` are capacity-checked.

```typescript
const event = await sublay.events.setRsvp({
  eventId: "evt_abc123",
  status: "going",
  actingUserId: "usr_abc123",
});
```

<ParamField body="eventId" type="string" required>The event ID.</ParamField>
<ParamField body="status" type='"going" | "maybe" | "not_going"' required>The RSVP response.</ParamField>
<ParamField body="actingUserId" type="string" required>The user the service key acts as, who RSVPs, held to their own event visibility (an event they can't see returns `404`).</ParamField>

**Returns** — `Promise<Event>` (with refreshed `rsvpCounts`)

```typescript

  actingUserId: "usr_host",
  userId: "usr_cohost",
});
```

<ParamField body="eventId" type="string" required>The event ID.</ParamField>
<ParamField body="actingUserId" type="string" required>The user the call acts as, with exactly their powers on the event; the action is recorded as theirs.</ParamField>
<ParamField body="userId" type="string" required>The user to grant host on the event.</ParamField>

<ParamField body="actingUserId" type="string" required>The user the call acts as, with exactly their powers on the event; the action is recorded as theirs.</ParamField>

### fetchEventRsvps

Named RSVP (guest) list. Returns paginated [EventRsvp](/v8/data-models/event-rsvp) records with the user populated. Visible to hosts always, and to anyone who can see the event when `guestListVisible` is `true`; otherwise `403 event/guest-list-hidden`. Pass `actingUserId` to read as that user. RSVP counts themselves are public via the event's `rsvpCounts`.

```typescript
const { data, pagination } = await sublay.events.fetchEventRsvps({
  eventId: "evt_abc123",
  status: ["going", "maybe"],
  page: 1,
  limit: 20,
});
```

<ParamField body="eventId" type="string" required>The event ID.</ParamField>
<ParamField body="status" type='RsvpStatus | RsvpStatus[]'>Statuses to filter by: `"going"`, `"maybe"` or `"not_going"`, e.g. `["going", "maybe"]`. Sent as one comma-separated value; values match exactly. Omit for all.</ParamField>
<ParamField body="actingUserId" type="string">The user to read as: exactly what their own access token would get (event visibility, whether they host it). Omit it for the anonymous view.</ParamField>
<ParamField body="page" type="number">Page number (1-indexed).</ParamField>
<ParamField body="limit" type="number">Results per page. Capped at `100`.</ParamField>

**Returns** — `Promise<PaginatedResponse<EventRsvp>>`

## Attaching images

Create the event, then upload a cover or gallery image and associate it with `eventId`:

```typescript
import { readFile } from "node:fs/promises";

const event = await sublay.events.createEvent({
  actingUserId: "usr_abc123",
  title: "Launch Party",
  type: "online",
  url: "https://meet.example.com/launch",
  startTime: "2026-09-01T18:00:00.000Z",
});

const buffer = await readFile("./cover.jpg");
await sublay.storage.uploadImage({
  file: new Uint8Array(buffer),
  filename: "cover.jpg",
  mimeType: "image/jpeg",
  imageOptions: { mode: "original-aspect", sizes: { full: 1600 }, format: "webp" },
  eventId: event.id,
  actingUserId: "usr_abc123",
});
```

<Note>
  Uploading via `storage.uploadImage` attaches a gallery image (a `File` with the
  event's `eventId`). Setting it as the event's single cover (`coverImageId`) is
  done by the inline-upload path, which the Node SDK does not yet expose.
</Note>

---
title: "Delete User"
api: "DELETE /v7/:projectId/users/:userId"
description: "Permanently delete a user and cascade cleanup across all of their related data"
---

Permanently deletes the specified user and cascades cleanup across all of their related records. Reactions, files, follows, connections, notifications, collections and reports are removed. The user's drafts are deleted, with everything attached to them (files, reactions, comments, collection entries, reports). Their published entities and comments stay, with no author (`userId: null`) and stripped of their authored content. Their chat messages are deleted the way a user [deleting their own message](/v7/api-reference/chat/messages/delete-message) deletes it: content, GIF and mentions are cleared, attached files are removed and `userDeletedAt` is set, and each message stays in its conversation as deleted, so replies and quotes still point at it. Each conversation's connected clients get the `message:deleted` event for every message this deletes, as they do when a user deletes their own. Mentions of the user in other entities, comments and chat messages keep their text, but their `id` and `foreignId` become `null`. This is the same full-cascade delete performed from the dashboard.

<Warning>
  This is a hard, irreversible delete. It cannot be undone.
</Warning>

## Authentication

Requires a **service key**. User auth tokens are rejected with a `403`.

## Path Parameters

<ParamField path="userId" type="string" required>
  The Sublay user ID (UUID) to delete.
</ParamField>

## Response

On success, returns HTTP `204 No Content` with an empty body.

# File Structure

When you install threaded comments, its TypeScript/TSX files are copied (42 on React, 47 on React Native and Expo, plus the `index.ts` the CLI writes) into your project in a clear, navigable structure: the component's own files, and the shared pieces it is built from in `shared/`. The trees below list every file.

## Key Files

### `index.ts` — Entry Point

Barrel export for clean imports:

```tsx
export { default as ThreadedCommentSection } from './components/threaded-comment-section';
export * from './components/threaded-comment-section';
```

This lets you write:
```tsx
// React (Web)
import { ThreadedCommentSection } from './components/comments-threaded';

// React Native / Expo
import {
  ThreadedComments,
  ThreadedCommentSection,
  ThreadedCommentInput,
} from './components/comments-threaded';
```

---

### `threaded-comment-section.tsx` — Main Component

The entry file that orchestrates everything. Edit this to:
- Add custom headers or footers
- Modify the overall layout
- Change the component structure

On React (Web) it holds `ThreadedCommentSection`: the comment box, Sort by and the comments, with no scrolling of its own. On React Native and Expo it holds the three components: `ThreadedComments` (the shared state, and the sheets over the screen), `ThreadedCommentSection` (Sort by and the comments) and `ThreadedCommentInput` (the comment box). See [React Native and Expo Components](/v8/components/components/threaded/props-api#react-native-and-expo-components).

---

### `new-comment-form.tsx` — Comment Input

The text input and submit button for top-level comments (and, on React Native and Expo, replies). Edit this to:
- Customize placeholder text
- Change button styles
- Add character counters

---

### `sort-by-dropdown.tsx` — Sort By (Web)

The **Sort by** dropdown between the comment box and the comments. Edit this to:
- Remove or reorder the sort options (the list at the top of the file)
- Change the button and menu styles

---

### `sort-by-trigger.tsx`, `sort-sheet.tsx` and `sort-options.ts` — Sort By (React Native, Expo)

`sort-by-trigger/sort-by-trigger.tsx` is the **Sort by: Top** button above the comments. It opens `sheets/sort-sheet.tsx`, the **Sort comments by** sheet, which `ThreadedComments` renders over the screen. Edit:
- `utils/sort-options.ts` to remove or reorder the sort options
- `sort-by-trigger.tsx` and `sort-sheet.tsx` to change the button and sheet styles

The button works anywhere inside `ThreadedComments`, so you can move it out of the section.

---

### `single-comment.tsx` — Individual Comment

The core comment display component. Edit this to:
- Change author name styling
- Modify comment body layout
- Add custom badges or labels

---

### `vote-buttons.tsx` — Voting UI

Upvote and downvote buttons with score display. Edit this to:
- Change button colors
- Modify vote count formatting
- Change icon styles

---

### `use-threaded-comments.tsx` — Main Hook

Contains all comment data logic and callbacks. This is where you customize behavior like:
- `loginRequiredCallback` — Called when an unauthenticated user tries to comment
- `usernameRequiredCallback` — Called when a user without a username tries to comment
- `commentTooShortCallback` — Called when a user tries to post an empty comment or reply
- `otherUserClickCallback` — Called when a user clicks on another user's name/avatar

The hook returns `{ CommentSectionProvider, providerProps, CommentsFeed, NewCommentForm }`. `providerProps` holds everything the provider is given: the entity, the highlighted comment, the callbacks and the loading settings (`limit`, `replyDepth`, `replyLimit`). ``threaded-comment-section.tsx`` spreads it onto the provider:

```tsx
const { CommentSectionProvider, providerProps } = useThreadedComments({ entityId });

<CommentSectionProvider {...providerProps}>
  {/* feed and form */}
</CommentSectionProvider>
```

To pass the provider something new, add it to `providerProps`.

---

### `shared/` — Shared Pieces

Presentational pieces the component is built from: the GIF picker, the user avatar, loading skeletons, mention parsing, icons and a few helpers. They are installed into the component's own folder and are yours to edit like every other file. Each installed component has its own copy, so editing one component's `shared/` folder does not affect another.

`user-avatar.tsx` shows the first of these a user has: the avatar file uploaded through Sublay, then the `avatar` URL, then a generated avatar. An uploaded avatar is stored in several sizes, and `pick-avatar-source.ts` picks the smallest one that is still sharp at the size the avatar is displayed at on the device's screen.

`theme.ts` holds the light and dark colors these pieces draw with (GIF picker surface and controls, skeletons, mention text). Edit it to change them.

- **Inline styles variant, and every React Native / Expo variant:** the component passes its `theme` to the pieces.
- **Tailwind variant on web:** the pieces read CSS custom properties (`--sublay-ui-surface`, `--sublay-ui-control`, `--sublay-ui-muted`, `--sublay-ui-text`, `--sublay-ui-divider`, `--sublay-ui-skeleton`, `--sublay-ui-mention`). The root element in `threaded-comment-section.tsx` sets them to the dark values under `dark:`. If you build your own layout from `CommentsFeed` and `NewCommentForm`, keep those classes on an element that wraps both.

## Common Customizations

### Change Colors

**Inline Styles Variant:** Look for the color palette guide at the top of component files:

```tsx
/**
 * COLOR PALETTE
 * - #3B82F6 → Primary blue (votes, links)
 * - #EF4444 → Red (downvotes, delete)
 * - #111827 → #F9FAFB (text)
 * - #FFFFFF → #1F2937 (backgrounds)
 */
```

Find and replace hex codes throughout the file.

**Tailwind Variant:** Change utility classes directly:

```tsx
// Before
<button className="bg-blue-600 hover:bg-blue-700">
// After
<button className="bg-purple-600 hover:bg-purple-700">
```

---

### Modify Layout

Open `threaded-comment-section.tsx` and rearrange JSX:

```tsx
return (
  <div>
    <h2>Discussion ({totalComments} comments)</h2>
    <NewCommentForm />
    <CommentsFeed />
  </div>
);
```

---

### Remove Features

Don't want vote buttons? Remove them from `single-comment.tsx`:

```tsx
return (
  <div>
    <AuthorInfo />
    <CommentBody />
    {/* <VoteButtons /> */}
    <ReplyButton />
  </div>
);
```

## File Responsibilities

| Directory | Purpose |
|-----------|---------|
| `/components/` | All UI/JSX components |
| `/hooks/` | React hooks for state and logic |
| `/utils/` | Helper functions |
| `/context/` | React context providers |
| `/shared/` | Presentational pieces the component is built from (GIF picker, avatar, skeletons, icons) |
| `/components/modals/` | Comment menu and report dialogs (web) |
| `/components/sheets/` | Sort, comment menu and report bottom sheets (React Native, Expo) |

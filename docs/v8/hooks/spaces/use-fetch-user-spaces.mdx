## Overview

`useFetchUserSpaces` returns a callable function that fetches the spaces where the authenticated user has a membership (active by default). The response includes membership metadata alongside each space. Spaces of every visibility are listed, so this is the hook for a "my spaces" screen; [`useFetchManySpaces`](/v8/hooks/spaces/use-fetch-many-spaces) lists public spaces only. It can search within the user's spaces and sort them.

## Usage Example

```tsx
import { useFetchUserSpaces } from "@sublay/react-js";

function MySpaces() {
  const fetchUserSpaces = useFetchUserSpaces();

  const loadSpaces = async () => {
    const result = await fetchUserSpaces({ page: 1, limit: 20 });
    // Search within them, A–Z: fetchUserSpaces({ query: "design", sortBy: "alphabetical" })
    // result.data: UserSpaceItem[]
    result.data.forEach(({ space, membership }) => {
      console.log(space.name, membership.role, membership.status);
    });
  };
}
```

## Parameters

<ParamField path="status" type="string">
  Membership status to list: `"active"` (default), `"pending"`, or `"banned"`. Use `"pending"` to show join requests still awaiting approval.
</ParamField>

<ParamField path="page" type="number">
  Page number. Defaults to `1`.
</ParamField>

<ParamField path="limit" type="number">
  Number of results per page.
</ParamField>

<ParamField path="role" type="SpaceMemberRole | SpaceMemberRole[]">
  Only memberships with this role: `"admin"`, `"moderator"` or `"member"`, or an array of them.
</ParamField>

<ParamField path="all" type="boolean">
  `true` returns every matching membership without pagination; the response then has no `pagination`.
</ParamField>

<ParamField path="query" type="string | null">
  Free-text search term, matched as a case-insensitive substring. A blank value is left out of the request, and `searchFields` with it.
</ParamField>

<ParamField path="searchFields" type='"slug" | "name" | "description" | null'>
  The one field `query` is matched against. Leave it out to match the slug, the name or the description.
</ParamField>

<ParamField path="sortBy" type="string">
  Sort order: `"joinedAt"` (when the user joined), `"createdAt"` (when the space was created), `"alphabetical"` (by name) or `"members"` (by active member count). Defaults to `"joinedAt"`.
</ParamField>

<ParamField path="sortDir" type="string">
  Direction, `"asc"` or `"desc"`, for any `sortBy`. Left out: A–Z for `"alphabetical"`, otherwise newest / most first.
</ParamField>

<ParamField path="include" type="SpaceIncludeParam">
  Optional. A single value or an array; the only value is `"files"`. Pass it to populate avatar and banner file objects on each space.
</ParamField>

## Returns

<ResponseField name="data" type="UserSpaceItem[]">
  Each item contains a `space` ([Space](/v8/data-models/space)) and a `membership` object with `membershipId`, `role`, `status`, and `joinedAt`.
</ResponseField>

<ResponseField name="pagination" type="object">
  Standard pagination metadata.
</ResponseField>

---
title: "Leave Space"
api: "DELETE /v8/:projectId/spaces/:spaceId/leave"
description: "Leave a space"
---

Removes the authenticated user's membership from a space and from its child spaces, and ends their membership of those spaces' chats. A ban in a child space is kept: leaving does not clear it.

## Path Parameters

<ParamField path="spaceId" type="string" required>
  UUID of the space to leave.
</ParamField>

## Query Parameters

<ParamField query="actingUserId" type="string">
  Required with a service key: the user this request acts as. The request has exactly that user's permissions, so it is refused unless they are an active member of the space, and it is recorded as theirs. With a user token, omit it (it may only name the token's own user).
</ParamField>

## Response

<ResponseField name="message" type="string">
  Confirmation message.
</ResponseField>

## Errors

<AccordionGroup>
  <Accordion title="Invalid Id — 400">
    Returned when `spaceId` isn't a valid UUID. Checked before sign-in, permissions and the endpoint's other checks.
    ```json
    { "error": "Invalid space id: expected a UUID.", "code": "space/invalid-params" }
    ```
  </Accordion>
  <Accordion title="Missing Acting User — 400">
    A service key sent no `actingUserId`.
    ```json
    { "error": "A service key must send actingUserId: the user this request acts as.", "code": "space/missing-user-id" }
    ```
  </Accordion>
  <Accordion title="Invalid Acting User — 400">
    `actingUserId` is not a user id.
    ```json
    { "error": "actingUserId must be a user id.", "code": "space/invalid-query" }
    ```
  </Accordion>
  <Accordion title="Unauthorized — 403">
    A user token sent an `actingUserId` other than its own user.
    ```json
    { "error": "Unauthorized", "code": "space/unauthorized" }
    ```
  </Accordion>
  <Accordion title="Not a Member — 403">
    The user is not an active member of the space (no membership, or one that is pending, banned or rejected), including when a service key acts for them.
    ```json
    { "error": "Space membership required", "code": "space/membership-required" }
    ```
  </Accordion>
  <Accordion title="Creator Cannot Leave — 400">
    ```json
    { "error": "The space creator cannot leave the space. Transfer ownership or delete the space instead.", "code": "space/creator-cannot-leave" }
    ```
  </Accordion>
  <Accordion title="Last Admin — 400">
    The user is the last admin of this space:
    ```json
    { "error": "You are the last admin of this space. Promote another member to admin before leaving, or delete the space.", "code": "space/last-admin" }
    ```
    or of one of its child spaces, named by `spaceId`:
    ```json
    { "error": "You are the last admin of a child space. Promote another member to admin there before leaving.", "code": "space/last-admin", "spaceId": "…" }
    ```
  </Accordion>
</AccordionGroup>

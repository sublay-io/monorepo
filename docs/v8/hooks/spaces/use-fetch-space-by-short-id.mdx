## Overview

`useFetchSpaceByShortId` returns a callable function that fetches a space using its `shortId`. The `shortId` is a compact, URL-safe identifier generated automatically when a space is created.

## Usage Example

```tsx
import { useFetchSpaceByShortId } from "@sublay/react-js";

function SpacePage({ shortId }: { shortId: string }) {
  const fetchSpace = useFetchSpaceByShortId();

  const handleFetch = async () => {
    const space = await fetchSpace({ shortId });
    console.log(space.name);
  };
}
```

## Parameters

<ParamField path="shortId" type="string" required>
  The short identifier of the space.
</ParamField>

<ParamField path="include" type="SpaceIncludeParam">
  Optional. A single value or an array; the only value is `"files"`. Pass it to include avatar and banner file objects.
</ParamField>

## Returns

Returns a [SpaceDetailed](/v8/data-models/space) object, which includes `memberPermissions`, `parentSpace`, and `childSpaces` in addition to all base space fields. `memberPermissions` is always present and reports what the current user may do in the space, also when they have no membership (`isMember: false`, `status: null`); a signed-out user gets the anonymous view. See [How permissions are calculated](/v8/data-models/space#how-permissions-are-calculated).

For most use cases, prefer [`SpaceProvider shortId`](/v8/sdk/spaces/provider-and-hook) prop over calling this hook directly.

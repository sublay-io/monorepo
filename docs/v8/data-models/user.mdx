Sublay exposes two user type variants depending on context: `User` (public profile) and `AuthUser` (the authenticated user's own data). All SDK hooks and API endpoints return one of these two types.

## User

The `User` type is returned when fetching another user's public profile. Sensitive and internal fields are excluded.

| Property | Type | Description |
|----------|------|-------------|
| `id` | `string` | Unique user identifier (UUID). |
| `foreignId` | `string \| null` | Your system's user ID if this user was created via external auth. |
| `role` | `"admin" \| "moderator" \| "visitor"` | The user's role within the project. |
| `name` | `string \| null` | Display name. |
| `username` | `string \| null` | Unique username handle. |
| `avatar` | `string \| null` | Avatar image URL. |
| `avatarFileId` | `string \| null` | ID of the managed avatar file record. Set by uploading `avatarFile` at sign-up or on update; cleared by listing it in `removeFileIds` on [Update User](/v8/api-reference/users/update-user). |
| `bannerFileId` | `string \| null` | ID of the managed banner file record. Set and cleared like `avatarFileId`, with `bannerFile`. |
| `avatarFile` | `File \| null` | Populated avatar file object when `include` contains `"files"`. |
| `bannerFile` | `File \| null` | Populated banner file object when `include` contains `"files"`. |
| `bio` | `string \| null` | Short biography (max 300 characters). |
| `birthdate` | `Date \| null` | User's date of birth. |
| `location` | `GeoPoint \| null` | GeoJSON point representing the user's location. |
| `metadata` | `Record<string, any>` | Custom key-value data for your project (max 10 KB). |
| `reputation` | `number` | The user's overall reputation total — the sum of all their reputation buckets across every space. Always present. See [Reputation](/v8/data-models/reputation). |
| `spaceReputation` | `number` | Opt-in. The user's reputation in a specific space, added only when an endpoint is called with the `spaceReputation` object (over REST, the `spaceReputationId` param). A space the viewer can't read reads `0`. See [Reputation](/v8/data-models/reputation#who-sees-space-reputation). |
| `createdAt` | `Date` | Timestamp when the account was created. |
| `updatedAt` | `Date` | Timestamp when the account was last modified. |

### GeoPoint

| Property | Type | Description |
|----------|------|-------------|
| `type` | `"Point"` | GeoJSON geometry type. Always `"Point"`. |
| `coordinates` | `[number, number]` | Longitude and latitude, in that order. |

## AuthUser

The `AuthUser` type is returned to the currently authenticated user about themselves: by sign-up, sign-in, token refresh, external-user verification and a profile update. It carries exactly these fields; the other `User` fields (`avatarFileId`, `bannerFileId`, `birthdate`, `location`, `updatedAt`, `spaceReputation`) are not on it.

| Property | Type | Description |
|----------|------|-------------|
| `id` | `string` | Unique user identifier (UUID). |
| `foreignId` | `string \| null` | Your system's user ID if this user was created via external auth. |
| `role` | `"admin" \| "moderator" \| "visitor"` | The user's role within the project. |
| `email` | `string \| null` | The user's email address. |
| `name` | `string \| null` | Display name. |
| `username` | `string \| null` | Unique username handle. |
| `avatar` | `string \| null` | Avatar image URL. |
| `bio` | `string \| null` | Short biography (max 300 characters). |
| `metadata` | `Record<string, any>` | Custom key-value data for your project. |
| `reputation` | `number` | The user's overall reputation total. |
| `isVerified` | `boolean` | Whether the user's email address has been verified. |
| `isActive` | `boolean` | Whether the account is currently active. |
| `lastActive` | `Date` | Timestamp of the user's last activity. |
| `suspensions` | `Suspension[]` | The user's active suspensions; empty when there are none (and when the `moderation` bundle isn't installed). See [Suspensions](/v8/sdk/moderation/suspensions). |
| `avatarFile` | `File \| null` | The managed avatar [File](/v8/data-models/file), always present: `null` when there is none or the `files-images` bundle isn't installed. |
| `bannerFile` | `File \| null` | The managed banner file; same as `avatarFile`. |
| `authMethods` | `string[]` | Authentication methods linked to this account (e.g. `["password", "google"]`). |
| `createdAt` | `Date` | Timestamp when the account was created. |

### Suspension

An active suspension is an enforced, platform-wide timeout: it blocks all participation and content writes while leaving reads, sign-in, and account self-management open. Multiple active suspensions can coexist; the "effective" one is the furthest-reaching active row (an indefinite `endDate` of `null` reaches furthest). The [`useUser`](/v8/hooks/user/use-user) hook derives `isSuspended` and `activeSuspension` from this array. See [Suspensions](/v8/sdk/moderation/suspensions) for the full behavior and response contract.

| Property | Type | Description |
|----------|------|-------------|
| `id` | `string` | Unique suspension identifier (UUID). |
| `userId` | `string` | The suspended user. |
| `reason` | `string` | The reason provided for the suspension. |
| `startDate` | `Date` | When the suspension began. |
| `endDate` | `Date \| null` | When the suspension ends, or `null` for indefinite. |
| `createdBy` | `string \| null` | Who issued the suspension, when recorded. |
| `createdAt` | `Date` | When the suspension was created. |
| `updatedAt` | `Date` | When the suspension was last modified. |

## Includes

User fetches by ID, foreign ID and username accept an `include` parameter that populates additional fields. Its only value is `"files"`, which populates `avatarFile` and `bannerFile` with [File](/v8/data-models/file) objects.

## Reputation

Every user object always carries `reputation` — the maintained sum of the user's reputation across all spaces. When the optional `reputation` bundle is installed, you can additionally read a user's reputation in a specific space via the `spaceReputation` object (over REST, the `spaceReputationId` param), which adds a `spaceReputation` field to each returned user. Only spaces the viewer can read count: a space they can't read reads `0` (see [Who sees space reputation](/v8/data-models/reputation#who-sees-space-reputation)). See the [Reputation data model](/v8/data-models/reputation) for the full opt-in read contract.

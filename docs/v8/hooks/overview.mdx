Browse the full reference for all Sublay hooks, organized by feature area. Each hook page documents its props, return values, and usage examples.

Hooks resolve to the plain value: a count is a `number`, an unpaged list an array and a single record the record itself, with no one-field wrapper such as `{ count }` or `{ data }`. Answers that carry several fields (a status check, for example) stay records, paginated hooks keep their paging, and fetch-or-create hooks ([`useFetchOrCreateEntityByForeignId`](/v8/hooks/entities/use-fetch-or-create-entity-by-foreign-id), [`useCreateDirectConversation`](/v8/hooks/chat/conversations/use-create-direct-conversation)) resolve to `{ <record>, created }`, where `created` is `true` when the call created the record. Actions that are safe to repeat, such as adding a chat member, blocking a user or joining a space, are not fetch-or-create: they give the same response whether or not this call made the change.

For higher-level integration guidance, see the [SDK Reference](/v8/sdk/getting-started).

---
title: "Fetch Spaces"
api: "GET /v8/:projectId/spaces"
description: "Get a paginated list of spaces with filtering and sorting"
---

Fetches a paginated list of spaces. Supports filtering by search query, membership, and parent space. Authentication is optional — if provided, member-only spaces the user belongs to are included.

<Note>
  This is a discovery surface: only `public` spaces are listed. Spaces with `visibility` of `"unlisted"` or `"private"` are excluded for non-members (they remain reachable by direct link/slug via [Fetch Space by Slug](/v8/api-reference/spaces/fetch-space-by-slug) or [by Short ID](/v8/api-reference/spaces/fetch-space-by-short-id)). The exception is `memberOf=true`, which returns the caller's own spaces regardless of visibility. See [Space visibility](/v8/data-models/space#visibility).
</Note>

## Query Parameters

<ParamField query="actingUserId" type="string">
  Service key only: the user to list as. The page is exactly what that user's own access token would get (`memberOf` and their membership on each space). Leave it out for the anonymous view (`memberOf=true` then returns `401`). A user token always acts as its own user and must not send it, and neither may a request with no credentials (`400 space/acting-user-not-allowed`).
</ParamField>

<ParamField query="page" type="number">
  Page number. Defaults to `1`.
</ParamField>

<ParamField query="limit" type="number">
  Results per page.
</ParamField>

<ParamField query="sortBy" type="string">
  Sort order: `"createdAt"` (when the space was created), `"alphabetical"` (by name) or `"members"` (by active member count). Defaults to `"members"`.
</ParamField>

<ParamField query="sortDir" type="string">
  Direction, `"asc"` or `"desc"` (either case), for any `sortBy`. Left out: A–Z for `"alphabetical"`, otherwise newest / most first.
</ParamField>

<ParamField query="query" type="string">
  Free-text search term, matched as a case-insensitive substring. Trimmed; a blank value returns `400 space/invalid-query`. Leave it out for no text filtering.
</ParamField>

<ParamField query="searchFields" type="string">
  The one field `query` is matched against: `"slug"`, `"name"` or `"description"`. Left out, `query` matches the slug, the name or the description. Values match exactly; any other value returns `400 space/invalid-query`.
</ParamField>

<ParamField query="memberOf" type="string">
  `"true"` returns only spaces where the viewer is an active member: the signed-in user, or the user a service key names in `actingUserId`. Without a viewer — no credentials, or a service key naming nobody — it returns `401 space/auth-required`. `"false"` lists the same as leaving it out. Any other value returns `400 space/invalid-query`.
</ParamField>

<ParamField query="parentSpaceId" type="string">
  Filter to child spaces of a specific parent. Pass `"null"` for root-level spaces only.
</ParamField>

<ParamField query="include" type="string">
  Associations to include, as a comma-separated value or repeated params. The only value is:
  - `files` — the processed `avatarFile` and `bannerFile` objects on each space (requires the `files-images` bundle)

  Matching ignores case. An unknown value returns `400 space/invalid-query`.
</ParamField>

## Response

<ResponseField name="data" type="Space[]">
  Array of [Space](/v8/data-models/space) objects.
</ResponseField>

<ResponseField name="pagination" type="object">
  <Expandable title="properties">
    <ResponseField name="page" type="number">Current page.</ResponseField>
    <ResponseField name="pageSize" type="number">Results per page.</ResponseField>
    <ResponseField name="totalPages" type="number">Total number of pages.</ResponseField>
    <ResponseField name="totalItems" type="number">Total matching spaces.</ResponseField>
    <ResponseField name="hasMore" type="boolean">Whether more pages exist.</ResponseField>
  </Expandable>
</ResponseField>

## Error Responses

<AccordionGroup>
  <Accordion title="Unsupported sort — 400">
    `sortBy=newest` is rejected with a pointer to its replacement, `sortBy=createdAt`.

    ```json
    {
      "error": "`sortBy=newest` isn't supported in v8. Use `sortBy=createdAt`, which lists newest first by default.",
      "code": "space/unsupported-param",
      "param": "sortBy"
    }
    ```
  </Accordion>
  <Accordion title="Unsupported search parameter — 400">
    `searchSlug`, `searchName`, `searchDescription` and `searchAny` are rejected with a pointer to `query` and `searchFields`. `param` names the parameter sent.

    ```json
    {
      "error": "`searchName` isn't supported in v8. Search with `query` and `searchFields=name`.",
      "code": "space/unsupported-param",
      "param": "searchName"
    }
    ```

    The `error` names the replacement for each:
    - `searchSlug`: `query` with `searchFields=slug`
    - `searchName`: `query` with `searchFields=name`
    - `searchDescription`: `query` with `searchFields=description`
    - `searchAny`: `query` without `searchFields`, which matches the slug, name and description
  </Accordion>
  <Accordion title="Invalid query — 400">
    Returned with code `space/invalid-query` for invalid values — for example an unknown `sortBy`, `sortDir`, `searchFields` or `include` value, a blank `query`, or a `memberOf` other than `"true"` or `"false"`. `error` names the first problem found.

    ```json
    { "error": "include: Unknown include `members`. Allowed: files.", "code": "space/invalid-query" }
    ```
  </Accordion>
  <Accordion title="Auth Required — 401">
    `memberOf=true` without a viewer: no credentials, or a service key naming nobody.

    ```json
    { "error": "Authentication required to filter by membership.", "code": "space/auth-required" }
    ```
  </Accordion>
  <Accordion title="Acting User Not Allowed — 400">
    A user token, or a request with no credentials, sent `actingUserId`, even naming its own user. Only a service key names the user it acts as; a user token always acts as its own user.

    ```json
    { "error": "actingUserId is only accepted with a service key. A user's own token always acts as that user.", "code": "space/acting-user-not-allowed" }
    ```
  </Accordion>
  <Accordion title="User Not Found — 404">
    Returned when a service key names an `actingUserId` that isn't a user in this project.

    ```json
    { "error": "No user with this actingUserId exists in this project.", "code": "space/user-not-found" }
    ```
  </Accordion>
</AccordionGroup>

See also: [useFetchManySpaces](/v8/hooks/spaces/use-fetch-many-spaces)

---
title: "Add Host"
api: "POST /v8/:projectId/events/:eventId/hosts"
description: "Grant a user host privileges on an event (host-only)"
---

Adds a user to the event's `hostIds`. **Host-only**: the caller must already be a host. A service key acts as the host it names in `actingUserId`. The operation is idempotent (adding an existing host is a no-op) and takes a row-level lock to serialize concurrent host changes.

There is no requirement that the target be a space member or invitee — any user can be made a host.

## Path Parameters

<ParamField path="eventId" type="string" required>
  UUID of the event.
</ParamField>

## Body Parameters

<ParamField body="userId" type="string" required>
  The user to grant host on the event.
</ParamField>

<ParamField body="actingUserId" type="string">
  Required with a service key: the user this request acts as. It has exactly that user's powers, so it is refused unless they are a host of the event, and it is recorded as theirs. A user token always acts as its own user and must not send it (`400 event/acting-user-not-allowed`).
</ParamField>

## Response

Returns the updated [Event](/v8/data-models/event) with the new `hostIds`.

## Error Responses

<AccordionGroup>
  <Accordion title="Missing Acting User — 400">
    A service key sent no `actingUserId`.
    ```json
    { "error": "A service key must send actingUserId: the user this request acts as.", "code": "event/missing-user-id" }
    ```
  </Accordion>
  <Accordion title="Invalid Acting User — 400">
    `actingUserId` is not a user id.
    ```json
    { "error": "actingUserId must be a user id.", "code": "event/invalid-body" }
    ```
  </Accordion>
  <Accordion title="Acting User Not Allowed — 400">
    A user token sent `actingUserId`, even naming its own user. Only a service key names the user it acts as; a user token always acts as its own user.
    ```json
    { "error": "actingUserId is only accepted with a service key. A user's own token always acts as that user.", "code": "event/acting-user-not-allowed" }
    ```
  </Accordion>
  <Accordion title="User Not Found — 404">
    Returned when a service key names an `actingUserId` that isn't a user in this project.
    ```json
    { "error": "No user with this actingUserId exists in this project.", "code": "event/user-not-found" }
    ```
  </Accordion>
  <Accordion title="Not Found — 404">
    ```json
    { "error": "Event not found", "code": "event/not-found" }
    ```
  </Accordion>
  <Accordion title="Forbidden (not a host) — 403">
    ```json
    { "error": "Only a host of this event may manage its hosts.", "code": "event/forbidden" }
    ```
  </Accordion>
</AccordionGroup>

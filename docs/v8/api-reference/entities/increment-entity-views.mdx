---
title: "Increment Entity Views"
api: "PATCH /v8/:projectId/entities/:entityId/increment-views"
description: "Add to an entity's view count"
---

Increments an entity's `views` counter and returns the updated entity.

<Warning>
  This endpoint requires a **service key** and cannot be called with an end-user token. It always acts as your app: sending `actingUserId` returns `400 entity/unsupported-param`. Count views from your own backend rather than from the client, so a browser cannot inflate the number.
</Warning>

## Path Parameters

<ParamField path="entityId" type="string" required>
  UUID of the entity.
</ParamField>

## Body Parameters

<ParamField body="count" type="number">
  How much to add to the counter: a JSON integer of at least `1`. Defaults to `1` (an empty body or no body increments by one). A string such as `"3"`, a fraction or `0` returns `400 entity/invalid-body`. Pass a batch total to record views your backend has buffered rather than calling the endpoint once per view.
</ParamField>

```json Example body
{ "count": 25 }
```

## Response

Returns the full updated [Entity](/v8/data-models/entity), with `views` reflecting the increment.

<ResponseField name="id" type="string">
  UUID of the entity.
</ResponseField>

<ResponseField name="views" type="number">
  The view count after the increment.
</ResponseField>

## Error Responses

<AccordionGroup>
  <Accordion title="Invalid Parameters — 400">
    ```json

    ```
  </Accordion>

  <Accordion title="Invalid Count — 400">
    Returned when `count` is not a JSON integer of at least `1` (a string, a fraction or `0`).

    ```json
    { "error": "count: Count must be a positive integer", "code": "entity/invalid-body" }
    ```
  </Accordion>

  <Accordion title="Wrong Location — 400">
    Returned when `count` is sent in the query string. On this endpoint it goes in the request body.

    ```json
    { "error": "`count` goes in the request body on this endpoint.", "code": "entity/wrong-location", "param": "count" }
    ```
  </Accordion>

  <Accordion title="Elevated Auth Required — 403">
    ```json
    {
      "error": "Service key required.",
      "code": "auth/elevated-auth-required"
    }
    ```
  </Accordion>

  <Accordion title="Entity Not Found — 404">
    ```json

    ```

  </Accordion>
  <Accordion title="Unsupported Parameter — 400">
    The request sent `actingUserId`. This endpoint always acts as the app, so no caller may name a user.

  </Accordion>

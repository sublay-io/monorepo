---
title: "Collections"
description: "Organize a user's saved entities into a tree of collections from your server"
---

The `collections` module manages a user's saved-content collections. Every user has a single **root collection**, under which they can nest sub-collections and into which they can save entities.

<Note>
  Collections are always scoped to a specific user. Pass that user's Sublay ID as
  [`actingUserId`](/v8/node-sdk/overview#acting-on-behalf-of-a-user), the user your service key acts as, on every call.
</Note>

---

### fetchRootCollection

Fetches a user's root collection, creating it on first access if it does not yet exist.

```typescript
const root = await sublay.collections.fetchRootCollection({
  actingUserId: "usr_abc123",
});
```

<ParamField body="actingUserId" type="string" required>
  The user the service key acts as, whose root collection to fetch.
</ParamField>

**Returns** — `Promise<Collection>`

---

### fetchSubCollections

Fetches the direct child collections nested under a given collection.

```typescript
const subCollections = await sublay.collections.fetchSubCollections({
  collectionId: "col_root123",
  actingUserId: "usr_abc123",
});
```

<ParamField body="collectionId" type="string" required>
  The parent collection ID.
</ParamField>

<ParamField body="actingUserId" type="string" required>
  The user the service key acts as, who owns the collection.
</ParamField>

**Returns** — `Promise<Collection[]>`

---

### createNewCollection

Creates a new sub-collection under an existing parent collection.

```typescript
const collection = await sublay.collections.createNewCollection({
  collectionId: "col_root123",
  name: "Recipes",
  actingUserId: "usr_abc123",
});
```

<ParamField body="collectionId" type="string" required>
  The parent collection under which to create the sub-collection.
</ParamField>

<ParamField body="name" type="string" required>
  The name of the new collection. Trimmed; 1 to 255 characters after trimming.
</ParamField>

<ParamField body="actingUserId" type="string" required>
  The user the service key acts as, who will own the collection.
</ParamField>

**Returns** — `Promise<Collection>`

### fetchCollectionEntities

Fetches a paginated list of entities saved in a collection.

```typescript
const { data, pagination } = await sublay.collections.fetchCollectionEntities({
  collectionId: "col_xyz789",
  actingUserId: "usr_abc123",
  sortBy: "addedAt",
  page: 1,
  limit: 20,
});
```

<ParamField body="collectionId" type="string" required>
  The collection ID.
</ParamField>

<ParamField body="actingUserId" type="string" required>
  The user the service key acts as, who owns the collection.
</ParamField>

<ParamField body="page" type="number">
  Page number (1-indexed). Defaults to `1`.
</ParamField>

<ParamField body="limit" type="number">
  Results per page. Defaults to `20`.
</ParamField>

<ParamField body="sortBy" type="string">
  Sort order: `"createdAt"` (creation date), `"addedAt"` (when saved), `"top"` (reaction count), or `"hot"` (engagement score).
</ParamField>

<ParamField body="sortByReaction" type="string">
  Which reaction `top` ranks by: `"upvote"`, `"downvote"`, `"like"`, `"love"`, `"wow"`, `"sad"`, `"angry"`, or `"funny"`. Defaults to `"upvote"`. Only valid with `sortBy: "top"` — the server rejects it with any other sort.
</ParamField>

<ParamField body="sortDir" type="string">
  Sort direction: `"asc"` or `"desc"`. Not accepted with `"hot"`, which ranks one way only.
</ParamField>

<ParamField body="include" type="CollectionEntityIncludeParam">
  Associations to populate: `"user"`, `"space"`, `"topComments"`, `"files"`, `"grants"` (a single value or an array). `"saved"` isn't accepted — every returned entity already has `isSaved: true`. On an entity whose author has blocked the user, `topComments` is `[]`.
</ParamField>

<ParamField body="topCommentsLimit" type="number">
  With `include` containing `"topComments"`: how many top comments per entity. Server default `1`, maximum `5`. Rejected (`400`) without `"topComments"` in `include`.
</ParamField>

<ParamField body="topCommentsSortByReaction" type="ReactionType">
  With `include` containing `"topComments"`: the reaction whose raw count ranks the top comments. Server default `"upvote"`. Rejected (`400`) without `"topComments"` in `include`.
</ParamField>

**Returns** — `Promise<PaginatedResponse<Entity>>`

### addEntityToCollection

Saves an entity into a collection.

```typescript
const collection = await sublay.collections.addEntityToCollection({
  collectionId: "col_xyz789",
  entityId: "ent_xyz789",
  actingUserId: "usr_abc123",
});
```

<ParamField body="collectionId" type="string" required>
  The collection to add the entity to.
</ParamField>

<ParamField body="entityId" type="string" required>
  The Sublay entity ID to save.
</ParamField>

<ParamField body="actingUserId" type="string" required>
  The user the service key acts as, who owns the collection.
</ParamField>

**Returns** — `Promise<Collection>`

<ParamField body="actingUserId" type="string" required>

```typescript
const collection = await sublay.collections.updateCollection({

  actingUserId: "usr_abc123",
  name: "Favorite Recipes",
});
```

<ParamField body="collectionId" type="string" required>
  The collection ID to update.
</ParamField>

<ParamField body="actingUserId" type="string" required>
  The user the service key acts as, who owns the collection.
</ParamField>

<ParamField body="name" type="string" required>
  The new collection name. Must be a non-empty string.
</ParamField>

**Returns** — `Promise<Collection>`

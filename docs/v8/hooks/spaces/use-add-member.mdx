## Overview

`useAddMember` returns a callable function that adds a user to a space directly. The user becomes an active member at once, with no request or approval step. The signed-in user must be an active moderator or admin of the space.

This is how users get into a private space, which can't be joined. A user with a `pending` or `rejected` membership becomes active; a user who is already an active member is left as they are. A banned user can't be added until they are unbanned (`409 space/member-banned`), nor can a user banned in a parent space (`409 space/banned-in-parent`). A user can't be added when there is a block between them and the adder, in either direction (`404 space/user-not-found`, the same answer as for a user who doesn't exist), or when they are suspended (`403 space/user-cannot-be-added`). The added user gets a `space-member-added` notification. See [Add Member](/v8/api-reference/spaces/membership/add-member) for every case and error.

## Usage Example

```tsx
import { useAddMember } from "@sublay/react-js";

function AddToSpaceButton({ spaceId, userId }: { spaceId: string; userId: string }) {
  const addMember = useAddMember();

  return (
    <button onClick={() => addMember({ spaceId, userId })}>
      Add to space
    </button>
  );
}
```

## Parameters

<ParamField path="spaceId" type="string" required>
  UUID of the space.
</ParamField>

<ParamField path="userId" type="string" required>
  UUID of the user to add.
</ParamField>

## Returns

Resolves with the user's membership record (`status: "active"`), as a [SpaceMember](/v8/data-models/space-member) object: `id`, `spaceId`, `userId`, `role`, `status`, `joinedAt` and `createdAt`. `role` is `member` for a user just added; a user who was already an active member keeps their role. It resolves with the same record whether the user was just added or already was an active member, so a repeat is safe.

## Overview

Returns a function that blocks a user by their ID. On a new block, the server retroactively removes any existing follows and connections between the two users (both directions). Blocking is idempotent — re-blocking an already-blocked user succeeds.

<Note>
  Requires the `moderation` bundle. See [Moderation — Blocking](/v8/sdk/moderation/overview#blocking).
</Note>

## Usage Example

```tsx
import { useBlockUser } from "@sublay/react-js";

function BlockAction({ userId }: { userId: string }) {
  const blockUser = useBlockUser();

  const handleBlock = async () => {
    const block = await blockUser({ userId });
    console.log("Blocked", block.user.username);
  };

  return <button onClick={handleBlock}>Block</button>;
}
```

## Parameters

The hook returns a function. That function accepts:

<ParamField path="userId" type="string" required>
  The ID of the user to block (the target).
</ParamField>

## Returns

The returned function resolves to the block row, a [`BlockRow`](/v8/data-models/block#blockrow). Blocking a user the current user already blocks resolves to the existing row.

<ResponseField name="id" type="string">
  ID of the block record.
</ResponseField>

<ResponseField name="user" type="User">
  The blocked user. Public profile fields only. See [User data model](/v8/data-models/user).
</ResponseField>

<ResponseField name="createdAt" type="string">
  ISO timestamp of when the block was created.
</ResponseField>

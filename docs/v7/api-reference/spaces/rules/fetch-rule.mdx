---
title: "Fetch Rule"
api: "GET /v7/:projectId/spaces/:spaceId/rules/:ruleId"
description: "Get a single community rule by its ID"
---

Fetches a single rule by ID. Authentication is optional. In a space the caller can't see (a `private` space they aren't an active member of, or one under it), the rule answers `404`, exactly like a nonexistent rule.

## Path Parameters

<ParamField path="spaceId" type="string" required>
  UUID of the space.
</ParamField>

<ParamField path="ruleId" type="string" required>
  UUID of the rule.
</ParamField>

## Response

A single Rule object with all fields.

## Error Responses

<AccordionGroup>
  <Accordion title="Not Found — 404">
    ```json
    { "error": "Rule not found.", "code": "rule/not-found" }
    ```
  </Accordion>
</AccordionGroup>

See also: [useFetchRule](/v7/hooks/spaces/rules/use-fetch-rule)

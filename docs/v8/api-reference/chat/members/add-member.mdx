---
title: "Add Member"
api: "POST /v8/:projectId/chat/conversations/:conversationId/members"
description: "Add a user to a group conversation"
---

Adds a user to a group conversation. Only group conversations support explicit member management — this endpoint returns a 400 for direct and space conversations.

The caller must be an active `admin` of the conversation. The target user must belong to the same project.

If the user was previously a member who left or was removed, they are re-activated as a `member` (their `isActive` is set back to `true`, `lastReadAt` is reset to now, and any role they held before, such as `admin`, is not restored).

## Path Parameters

<ParamField path="conversationId" type="string" required>
  The ID of the conversation.
</ParamField>

## Body Parameters

<ParamField body="userId" type="string" required>
  The ID of the user to add. Must belong to the same project.
</ParamField>

<ParamField body="actingUserId" type="string">
  Service key only, and required with one: the user this request acts as. Must be an active `admin` of the conversation. A user token always acts as its own user and must not send it (`400 chat/acting-user-not-allowed`).
</ParamField>

## Response

Returns the [ConversationMember](/v8/data-models/conversation-member) record for the added user.

## Error Responses

<AccordionGroup>
  <Accordion title="Acting User Not Allowed — 400">
    A user token sent `actingUserId`, even naming its own user. Only a service key names the user it acts as; a user token always acts as its own user.
    ```json
    { "error": "actingUserId is only accepted with a service key. A user's own token always acts as that user.", "code": "chat/acting-user-not-allowed" }
    ```
  </Accordion>
  <Accordion title="User Not Found — 404">
    Returned when a service key names an `actingUserId` that isn't a user in this project.
    ```json
    { "error": "No user with this actingUserId exists in this project.", "code": "chat/user-not-found" }
    ```
  </Accordion>
  <Accordion title="Missing User — 400">
    A service key sent no `actingUserId`.
    ```json
    { "error": "A service key must send actingUserId: the user this request acts as.", "code": "chat/missing-user-id" }
    ```
  </Accordion>
  <Accordion title="Not Found — 404">
    ```json
    { "error": "Conversation not found.", "code": "chat/not-found" }
    ```
  </Accordion>
  <Accordion title="Invalid Type — 400 Bad Request">
    ```json
    { "error": "Members can only be added to group conversations.", "code": "chat/invalid-type" }
    ```
  </Accordion>
  <Accordion title="Forbidden — 403">
    ```json
    { "error": "Only group admins can add members.", "code": "chat/not-a-member" }
    ```
  </Accordion>
  <Accordion title="Invalid Member — 400 Bad Request">
    ```json
    { "error": "Target user does not belong to this project.", "code": "chat/invalid-member" }
    ```
  </Accordion>
</AccordionGroup>

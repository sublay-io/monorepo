---
title: "Follows"
description: "Read a user's follow graph and remove follows by ID from your server"
---

The `follows` module reads a user's follow graph — the users they follow and the users following them — and removes follow relationships by ID.

<Note>
  Every function acts on behalf of a named user. Pass that user's Sublay ID as
  [`actingUserId`](/v8/node-sdk/overview#acting-on-behalf-of-a-user), the user your service key acts as. The returned graph and counts are from that user's perspective.
</Note>

<Tip>
  To **create** a follow (or unfollow by target user ID, or check follow status),
  use the nested routes on the [`users`](/v8/node-sdk/users) module
  (`createFollow`, `deleteFollow`, `fetchFollowStatus`).
</Tip>

---

### fetchFollowing

Returns a paginated list of the follow records for users the given user follows.

```typescript
const { data, pagination } = await sublay.follows.fetchFollowing({
  actingUserId: "usr_abc123",
  page: 1,
  limit: 20,
});
```

<ParamField body="actingUserId" type="string" required>
  The user the service key acts as, whose following list to fetch.
</ParamField>

<ParamField body="page" type="number">
  Page number (1-indexed). Defaults to `1`.
</ParamField>

<ParamField body="limit" type="number">
  Results per page. Defaults to `20`.
</ParamField>

<ParamField body="query" type="string">
  Optional search term. Filters the list to users whose username or name contains this text (case-insensitive). When omitted, no filtering is applied.
</ParamField>

<ParamField body="searchFields" type="string">
  Restricts which field `query` matches against — `username` or `name`. When omitted, `query` matches either field.
</ParamField>

**Returns** — `Promise<PaginatedResponse<Follow>>`

### deleteFollow

Deletes a follow relationship by its follow record ID.

```typescript
await sublay.follows.deleteFollow({
  followId: "fol_xyz789",
  actingUserId: "usr_abc123",
});
```

<ParamField body="followId" type="string" required>
  The ID of the follow record to delete.
</ParamField>

<ParamField body="actingUserId" type="string" required>
  The user the service key acts as, on whose behalf the follow is removed (must be the follower).
</ParamField>

**Returns** — `Promise<void>`

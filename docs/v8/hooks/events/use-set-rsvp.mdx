## Overview

`useSetRsvp` returns a callable that sets or changes the logged-in user's RSVP. The event's `rsvpCounts` update atomically. A transition into `going` is capacity-checked. RSVPs close at `startTime`, are rejected on cancelled events, and `"maybe"` is rejected when `allowMaybe` is `false`.

The request is refused when:

- the logged-in user can't [see the event](/v8/data-models/event#visibility) — `404 event/not-found` (for example a `members` event once a ban ends their active membership);
- they can see it but are banned in its space or a space above it — `403 space/posting-not-allowed`;
- it's an `invite` event they see only as an admin or moderator of its space, without an invite — `403 event/not-invited`.

## Usage Example

```tsx
import { useSetRsvp } from "@sublay/react-js";

function GoingButton({ eventId }: { eventId: string }) {
  const setRsvp = useSetRsvp();
  return <button onClick={() => setRsvp({ eventId, status: "going" })}>Going</button>;
}
```

## Parameters

<ParamField path="eventId" type="string" required>The event ID.</ParamField>
<ParamField path="status" type='"going" | "maybe" | "not-going"' required>The RSVP response.</ParamField>

## Returns

Returns a `Promise<Event>` — the [Event](/v8/data-models/event) with refreshed `rsvpCounts` and `userRsvp`.

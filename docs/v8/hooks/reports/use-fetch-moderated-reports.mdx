## Overview

Returns a function to fetch content reports (entities and comments) from spaces where the current user has an `admin` or `moderator` role.

If `spaceId` is provided, returns reports for that specific space (the user must moderate it). If omitted, returns reports aggregated from **all** spaces the user moderates.

<Note>Requires an authenticated user with `admin` or `moderator` role in at least one space.</Note>

## Usage Example

```tsx
import { useFetchModeratedReports } from "@sublay/react-js";
import { useEffect, useState } from "react";

function ModerationQueue({ spaceId }: { spaceId: string }) {
  const fetchModeratedReports = useFetchModeratedReports();
  const [reports, setReports] = useState([]);

  useEffect(() => {
    fetchModeratedReports({ spaceId, status: "pending", page: 1, limit: 20 })
      .then(res => setReports(res.data));
  }, [spaceId]);

  return (
    <ul>
      {reports.map(r => (
        <li key={r.id}>{r.targetType}: {r.reporterCount} reports</li>
      ))}
    </ul>
  );
}
```

## Parameters

<ParamField body="spaceId" type="string">
  Filter reports to a specific space. If omitted, returns reports from all spaces the user moderates.
</ParamField>

<ParamField body="targetType" type='"comment" | "entity" | "message"'>
  Filter by target type.
</ParamField>

<ParamField body="status" type='"pending" | "on-hold" | "escalated" | "dismissed" | "actioned" | "auto-closed"'>
  Filter by report status.
</ParamField>

<ParamField body="sortBy" type='"createdAt"'>
  Reports are sorted by when they were created.
</ParamField>

<ParamField body="sortDir" type='"asc" | "desc"'>
  Direction of the `createdAt` sort. Default `"desc"` (newest first).
</ParamField>

<ParamField body="page" type="number">
  Page number for pagination. Defaults to `1`.
</ParamField>

<ParamField body="limit" type="number">
  Items per page: a whole number from `1` to `100`. Defaults to `20`. A larger value is rejected with `400 report/invalid-query`, never lowered to `100`.
</ParamField>

## Returns

Returns `Promise<PaginatedResponse<Report>>`:

```ts
{
  data: Report[];
  pagination: {
    page: number;
    pageSize: number;
    totalPages: number;
    totalItems: number;
    hasMore: boolean;
  };
}
```

### Report object

<ResponseField name="id" type="string">UUID of the report record.</ResponseField>
<ResponseField name="spaceId" type="string | null">Space the reported content belongs to.</ResponseField>
<ResponseField name="targetId" type="string">ID of the reported entity, comment, or chat message.</ResponseField>
<ResponseField name="targetType" type='"comment" | "entity" | "message"'>Type of the reported content.</ResponseField>
<ResponseField name="reporterCount" type="number">Total number of users who have reported this target.</ResponseField>
<ResponseField name="userReports" type="array">Individual user report entries. Each includes `id`, `reportId`, `userId`, `reason`, `details`, `createdAt` and `updatedAt`.</ResponseField>
<ResponseField name="status" type="string">Current moderation status: `pending`, `on-hold`, `escalated`, `dismissed`, `actioned`, or `auto-closed` (closed by the system with no moderator decision; the reason is in `actionTaken`).</ResponseField>
<ResponseField name="actionTaken" type="string | null">Free-text description of action taken, if any.</ResponseField>
<ResponseField name="target" type="Entity | Comment | ChatMessage | null">The reported content's stored record, with its author as `user` (a public [User](/v8/data-models/user), or `null`); the fields a regular fetch computes or joins, such as `userReaction` or `files`, aren't included. `null` when the content is no longer there, including an entity soft-deleted under the project's [entity deletion](/v8/api-reference/entities/delete-entity) setting. When `spaceReputation` is requested, the embedded author carries an added `spaceReputation` number. See [Reputation](/v8/data-models/reputation).</ResponseField>
<ResponseField name="space" type="Space | null">The space the report was filed in, as its stored record: without `membersCount`, `childSpacesCount`, `isMember` or the avatar and banner file objects. `null` when the report has no space.</ResponseField>
<ResponseField name="createdAt" type="Date">When the first report for this target was submitted.</ResponseField>
<ResponseField name="updatedAt" type="Date">When the report record was last updated.</ResponseField>

## Notes

- Message reports appear in this queue only for conversations attached to a space. DM and group chat reports have no space, so they are project-level and appear only in the Sublay dashboard — see [`useCreateReport`](/v8/hooks/reports/use-create-report).

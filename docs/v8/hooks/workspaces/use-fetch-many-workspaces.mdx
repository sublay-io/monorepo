## Overview

`useFetchManyWorkspaces` returns a callable that fetches one page of the caller's **direct-membership + owned** workspaces. The actor is derived from the bearer token — no `actingUserId` is sent. For a managed paginated list with load-more, prefer [`useFetchManyWorkspacesWrapper`](/v8/hooks/workspaces/use-fetch-many-workspaces-wrapper).

## Usage Example

```tsx
import { useFetchManyWorkspaces } from "@sublay/react-js";

function useMyWorkspaces() {
  const fetchManyWorkspaces = useFetchManyWorkspaces();

  return async () => {
    const { data, pagination } = await fetchManyWorkspaces({
      page: 1,
      limit: 20,
      parentWorkspaceId: "none", // top-level workspaces only
      include: ["memberCount"],
    });
    return data;
  };
}
```

## Parameters

The callable takes an optional params object:

<ParamField path="page" type="number">Page number.</ParamField>
<ParamField path="limit" type="number">Page size.</ParamField>
<ParamField path="parentWorkspaceId" type='string | "none" | "any" | null'>Narrows the list by where each workspace sits in the tree. `"none"`: top-level workspaces only. A workspace id: the caller's workspaces directly under that workspace. `"any"`, left out or `null`: workspaces at every level (the default). `null` is left out of the request.</ParamField>
<ParamField path="include" type="WorkspaceIncludeParam">A single value or an array. The only value is `"memberCount"`: it adds each row's **direct** member count, resolved in one grouped query over the returned page rather than one request per workspace; omit it and the field is absent from each row.</ParamField>

## Returns

Returns a `PaginatedResponse<Workspace>` (`{ data, pagination }`).

---
title: "Conversation"
description: "The shape of a conversation object returned by the Chat API and SDK"
---

A `Conversation` represents a messaging thread between two or more participants. Sublay supports three conversation types: **direct** (1:1 DMs), **group** (multi-member chat), and **space** (a single shared chat channel attached to a Space).

## Properties

| Property | Type | Description |
|----------|------|-------------|
| `id` | `string` | Unique conversation identifier (UUID). |
| `type` | `"direct" \| "group" \| "space"` | Conversation type. |
| `name` | `string \| null` | Display name. Always `null` for direct conversations. |
| `description` | `string \| null` | Optional description. Used for group and space conversations. |
| `spaceId` | `string \| null` | The Space this conversation belongs to. Set only when `type` is `"space"`. |
| `directKey` | `string \| null` | Identifies the pair of members of a `direct` conversation. Set on direct conversations only; `null` for group and space conversations. |
| `createdById` | `string \| null` | ID of the user who created the conversation. `null` for auto-created space conversations. |
| `avatarFileId` | `string \| null` | ID of the conversation's avatar file: uploaded as `avatarFile` on [Create Group Conversation](/v8/api-reference/chat/conversations/create-group) or [Update Conversation](/v8/api-reference/chat/conversations/update-conversation), and removed with `removeFileIds` on the update. |
| `avatarFile` | `File \| null \| undefined` | Populated avatar file object. Returned by [Create Group Conversation](/v8/api-reference/chat/conversations/create-group) and [Update Conversation](/v8/api-reference/chat/conversations/update-conversation) when the `files-images` bundle is installed, and sent to members in the [`conversation:updated`](/v8/sdk/chat/real-time) event when the avatar changes; `null` when the conversation has no avatar. |
| `lastMessageAt` | `Date \| null` | Timestamp of the most recent message. Used for conversation list sorting. `null` if no messages have been sent. |
| `postingPermission` | `"members" \| "team" \| null` | Who can post in the conversation: any active member (`"members"`), or only the space's active admins and moderators (`"team"`). Only set for `space` conversations. `null` for direct and group conversations. |
| `metadata` | `Record<string, any>` | Custom key-value data. Limited to 1 MB. |
| `memberCount` | `number \| undefined` | Total number of active members. Returned by Fetch Conversation and Fetch Space Conversation, and on every `ConversationPreview`. |
| `currentMember` | `ConversationMember \| null \| undefined` | The requesting user's own membership row, with their mute state. Returned by Fetch Conversation and Fetch Space Conversation; `null` when they have no row. |
| `createdAt` | `Date` | Timestamp when the conversation was created. |
| `updatedAt` | `Date` | Timestamp of the last update. |

## ConversationPreview

When listing conversations (e.g. in an inbox), the API returns `ConversationPreview` objects, which carry the `Conversation` fields except `currentMember` and `avatarFile`, plus these:

| Property | Type | Description |
|----------|------|-------------|
| `unreadCount` | `number` | Number of messages sent after the current user's `lastReadAt`. |
| `memberCount` | `number` | Total number of active members. |
| `mutedUntil` | `string \| null` | When the current user's timed mute of the conversation ends (ISO timestamp). `null` when they haven't muted it, or muted it with no end (see `mutedForever`). |
| `mutedForever` | `boolean` | `true` when the current user muted the conversation with no end. |
| `lastMessage` | `ConversationPreviewLastMessage \| null` | The most recent top-level message in the conversation (thread replies are never the last message), as a preview subset — see [ConversationPreviewLastMessage](#conversationpreviewlastmessage). `null` if there is no top-level message. A [deleted or removed](/v8/data-models/chat-message#deleted-and-removed-messages) last message is shown as its placeholder. |
| `otherMembers` | `{ id, name, username, avatar }[]` | Up to 5 active members other than the current user. Populated for `direct` and `group` conversations (a DM/group has no `name`, so the counterparty supplies the title/avatar); capped at 5 (use `memberCount` for the group total); empty for `space` conversations. |

### ConversationPreviewLastMessage

| Property | Type | Description |
|----------|------|-------------|
| `id` | `string` | The message's ID. |
| `conversationId` | `string` | The conversation's ID. |
| `content` | `string \| null` | The message text, cut to 100 characters. `null` on a placeholder. |
| `gif` | `GifData \| null` | The GIF, if any. `null` on a placeholder. |
| `userId` | `string \| null` | The sender's ID. `null` on a removed message for everyone but its author, and when the sender's account was deleted. |
| `moderationStatus` | `"removed" \| null` | The message's moderation status. |
| `userDeletedAt` | `Date \| null` | Set when the sender deleted the message, or their account was deleted. |
| `createdAt` | `Date` | When the message was sent. |
| `files` | `File[]` | The message's files. `[]` on a placeholder and without the `files-images` bundle. |
| `user` | `{ id, name, username, avatar, reputation } \| null` | The sender, on `group` and `space` conversations only (a DM's counterparty is in `otherMembers`). `null` on `direct` conversations and whenever `userId` is `null`. |

The preview carries no mentions, quotes or reactions.

## Conversation Types

| Type | Description |
|------|-------------|
| `direct` | A private 1:1 DM between two users. Only one direct conversation can exist per user pair per project. |
| `group` | A multi-member chat created by a user. Members can have `admin` or `member` roles. |
| `space` | The shared chat channel for a Space. Exactly one space conversation exists per Space. Created automatically when the Space is created. Only someone who can see the space can use it: a space chat in a space the caller can't see answers like a conversation they aren't in (see [Visibility](/v8/data-models/space#visibility)). |

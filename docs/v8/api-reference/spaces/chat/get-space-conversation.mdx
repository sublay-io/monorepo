---
title: "Get Space Conversation"
api: "GET /v8/:projectId/spaces/:spaceId/conversation"
description: "Get or create the chat conversation for a space"
---

Returns the chat conversation associated with a space. If no conversation exists yet, one is created automatically. Requires authentication. The caller must be an active member of the space: a request still awaiting approval, a rejected request and a ban are all refused.

## Path Parameters

<ParamField path="spaceId" type="string" required>
  UUID of the space.
</ParamField>

## Response

Returns a [Conversation](/v8/data-models/conversation) object with two additional fields:

<ResponseField name="currentMember" type="object | null">
  The caller's `ConversationMember` record for this conversation. Created or re-activated on first call.
</ResponseField>

<ResponseField name="memberCount" type="number">
  Number of currently active members in the conversation.
</ResponseField>

<Note>Each space has at most one associated conversation. This endpoint is idempotent — calling it multiple times returns the same conversation.</Note>

## Error Responses

<AccordionGroup>
  <Accordion title="Invalid Id — 400">
    Returned when `spaceId` isn't a valid UUID. Checked before sign-in, permissions and the endpoint's other checks.
    ```json
    { "error": "Invalid space id: expected a UUID.", "code": "chat/invalid-params" }
    ```
  </Accordion>
  <Accordion title="Not a Member — 403">
    Also returned when the caller's request to join was rejected.

    ```json
    { "error": "You are not a member of this space.", "code": "chat/not-a-member" }
    ```
  </Accordion>
  <Accordion title="Awaiting Approval — 403">
    ```json
    { "error": "Your request to join this space is awaiting approval.", "code": "chat/membership-pending" }
    ```
  </Accordion>
  <Accordion title="Banned — 403">
    ```json
    { "error": "You are banned from this space.", "code": "chat/banned" }
    ```
  </Accordion>
</AccordionGroup>

---
title: "Spaces"
description: "Create, fetch, update, and navigate spaces from the browser"
---

Spaces are containers — communities for organizing content. The `spaces` module covers the space lifecycle and navigation: creating spaces, looking them up by ID, slug, or short ID, updating settings, and traversing parent-child hierarchies.

For membership management see [Space Members](/v8/js-sdk/spaces-members), and for moderation and rules see [Space Moderation](/v8/js-sdk/spaces-moderation).

---

### createSpace

Creates a new space.

```typescript
const space = await sublay.spaces.createSpace({
  name: "Photography",
  slug: "photography",
  description: "A community for photographers",
  postingPermission: "members",
});
```

<ParamField body="name" type="string | null">
  Display name for the space (3–100 characters). Left out or `null`, the space has no name.
</ParamField>

<ParamField body="slug" type="string | null">
  URL-friendly identifier. Must be unique within the project. Left out or `null`, the space has no slug.
</ParamField>

<ParamField body="description" type="string | null">
  Short description of the space. Left out or `null`, the space has no description.
</ParamField>

<ParamField body="readingPermission" type="string">
  Who can read content: `"anyone"` or `"members"`.
</ParamField>

<ParamField body="postingPermission" type="string">
  Who can post content: `"anyone"`, `"members"`, or `"team"` (the space's active admins and moderators).
</ParamField>

<ParamField body="visibility" type="string">
  Who can find and see the space: `"public"` (default), `"unlisted"`, or `"private"`. Independent of `readingPermission` (which governs content). `"unlisted"` keeps the space out of the directory and search, and out of sub-space lists for non-members, but reachable by id, short id or slug; `"private"` makes it seen only by its active members (everyone else gets `404`), and it can't be joined: members are [added](/v8/api-reference/spaces/membership/add-member) by its moderators and admins. See [Space visibility](/v8/data-models/space#visibility).
</ParamField>

<ParamField body="requireJoinApproval" type="boolean">
  When `true`, join requests must be manually approved.
</ParamField>

<ParamField body="nsfw" type="boolean">
  The space's own NSFW flag. Defaults to `false`. A space created under an NSFW parent is effectively NSFW regardless of this value. See [Space NSFW flagging](/v8/data-models/space#nsfw-flagging).
</ParamField>

<ParamField body="parentSpaceId" type="string | null">
  Makes this space a child of the specified parent space. The signed-in user must be an active admin of the parent space, or the request is refused with `403 space/parent-admin-required`. Left out or `null`, the space is top-level.
</ParamField>

<ParamField body="metadata" type="Record<string, any>">
  Arbitrary metadata attached to the space.
</ParamField>

<ParamField body="avatarFile" type="{ file: Blob | File; options: ImageOptions }">
  An avatar image to upload, up to 50 MB. `options` says how to process it and must include `mode` (see [Upload Image](/v8/api-reference/storage/upload-image)). With an image, the request is sent as `multipart/form-data`.
</ParamField>

<ParamField body="bannerFile" type="{ file: Blob | File; options: ImageOptions }">
  A banner image to upload; same shape as `avatarFile`.
</ParamField>

```typescript
const space = await sublay.spaces.createSpace({
  name: "Photography",
  avatarFile: {
    file, // a File from an <input type="file">, or any Blob
    options: { mode: "exact-dimensions", dimensions: { small: { width: 64, height: 64 } } },
  },
});
```

**Returns** — `Promise<SpaceWithPermissions>`: the created space plus [`memberPermissions`](/v8/data-models/space#spacememberpermissions), what the creator may do in it.

### fetchSpace

Fetches a single space, including detailed information, by its ID.

```typescript
const space = await sublay.spaces.fetchSpace({ spaceId: "spc_abc123" });
```

<ParamField body="spaceId" type="string" required>
  The Sublay space ID.
</ParamField>

<ParamField body="include" type="SpaceIncludeParam">
  A single value or an array. The only value is `"files"`, which populates the avatar and banner file objects.
</ParamField>

**Returns** — `Promise<SpaceDetailed>`. Its [`memberPermissions`](/v8/data-models/space#spacememberpermissions) is always present, also for a user with no membership (`isMember: false`, `status: null`); a signed-out user gets the anonymous view. See [How permissions are calculated](/v8/data-models/space#how-permissions-are-calculated).

### fetchManySpaces

Fetches a paginated, filterable list of public spaces (the space directory). For the spaces the logged-in user belongs to, whatever their visibility, use [fetchMySpaces](#fetchmyspaces).

```typescript
const { data, pagination } = await sublay.spaces.fetchManySpaces({
  sortBy: "members",
  parentSpaceId: "any", // every level; left out, top-level spaces only
  limit: 20,
});
```

<ParamField body="page" type="number">
  The page number to fetch.
</ParamField>

<ParamField body="limit" type="number">
  The number of spaces to return per page: a whole number from `1` to `100`. Defaults to `20`. A larger value is rejected with `400 space/invalid-query`, never lowered to `100`.
</ParamField>

<ParamField body="sortBy" type="string">
  Sort order: `"createdAt"` (when the space was created), `"alphabetical"` (by name) or `"members"` (by active member count). Defaults to `"members"`.
</ParamField>

<ParamField body="sortDir" type="string">
  Direction, `"asc"` or `"desc"`, for any `sortBy`. Left out: A–Z for `"alphabetical"`, otherwise newest / most first.
</ParamField>

<ParamField body="query" type="string">
  Free-text search term, matched as a case-insensitive substring. Trimmed; a blank value returns `400 space/invalid-query`.
</ParamField>

<ParamField body="searchFields" type='"slug" | "name" | "description"'>
  The one field `query` is matched against. Leave it out to match the slug, the name or the description.
</ParamField>

<ParamField body="parentSpaceId" type='string | "none" | "any"'>
  Which level of the space tree to return. Left out or `"none"`: top-level spaces only (the default). A space id returns that space's direct sub-spaces the viewer can see that are `public` or that the viewer is an active member of — the same ones its `childSpaces` preview shows and its `childSpacesCount` counts; this is how to page through a space's sub-spaces (add `sortBy: "alphabetical"` to order them A–Z by name). An id that matches no space returns an empty page, not a 404. `"any"` returns spaces at every level.
</ParamField>

<ParamField body="nsfwFilter" type='"include-all" | "exclude" | "only"'>
  Filter by each space's `nsfwEffective` (own flag OR any ancestor). `"include-all"` (default) adds no predicate; `"exclude"` drops effective-NSFW spaces; `"only"` returns only them. `"only"` may return an NSFW child whose safe parent is omitted. See [Space NSFW flagging](/v8/data-models/space#nsfw-flagging).
</ParamField>

<ParamField body="include" type="SpaceIncludeParam">
  A single value or an array. The only value is `"files"`, which populates the avatar and banner file objects.
</ParamField>

**Returns** — `Promise<PaginatedResponse<Space>>`

### fetchMySpaces

Fetches the spaces the logged-in user belongs to (`GET /spaces/mine`), with the user's membership on each. Every space the user is an active member of is listed, whatever its visibility; a `pending`, `banned` or `rejected` membership of a space the user can't see (a private space, or one under it) is left out. It can search within them and sort them.

```typescript
const mySpaces = await sublay.spaces.fetchMySpaces({
  role: "admin,moderator",
  query: "design",
  sortBy: "alphabetical",
});
```

<ParamField body="page" type="number">
  The page number to fetch (1-indexed), `1` or more. Defaults to `1`.
</ParamField>

<ParamField body="limit" type="number">
  The number of spaces to return per page: a whole number from `1` to `100`. Defaults to `20`. A larger value is rejected with `400 space/invalid-query` (`param: "limit"`), never lowered to `100`. See [Pagination](/v8/api-reference/getting-started#pagination).
</ParamField>

<ParamField body="query" type="string">
  Free-text search term within the user's spaces, matched as a case-insensitive substring. Trimmed; a blank value returns `400 space/invalid-query`.
</ParamField>

<ParamField body="searchFields" type='"slug" | "name" | "description"'>
  The one field `query` is matched against. Leave it out to match the slug, the name or the description.
</ParamField>

<ParamField body="sortBy" type="string">
  Sort order: `"joinedAt"` (when the user joined), `"createdAt"` (when the space was created), `"alphabetical"` (by name) or `"members"` (by active member count). Defaults to `"joinedAt"`.
</ParamField>

<ParamField body="sortDir" type="string">
  Direction, `"asc"` or `"desc"`, for any `sortBy`. Left out: A–Z for `"alphabetical"`, otherwise newest / most first.
</ParamField>

<ParamField body="parentSpaceId" type='string | "none" | "any"'>
  Narrows the list by where each space sits in the tree. `"none"` returns the user's memberships in top-level spaces only. A space id returns their memberships in that space's direct sub-spaces; an id that matches no space returns an empty page, not a 404. `"any"` or left out: memberships at every level (the default).

  A membership in a sub-space whose parent the user isn't a member of is not top-level, so `"none"` leaves it out.
</ParamField>

<ParamField body="include" type="SpaceIncludeParam">
  A single value or an array. The only value is `"files"`, which populates the avatar and banner file objects.
</ParamField>

<ParamField body="role" type="string">
  Filter by role. A single role or a comma-separated list, e.g. `"admin,moderator"`.
</ParamField>

<ParamField body="status" type="string">
  Membership status to list: `"active"` (default), `"pending"`, or `"banned"`. Use `"pending"` to find join requests still awaiting approval.
</ParamField>

**Returns** — `Promise<MySpacesResponse>`

The list is always paged. To load every space the user is in, fetch page after page until `pagination.hasMore` is `false`; add `role: "admin,moderator"` to list only the spaces they moderate:

```typescript
const moderated = [];
for (let page = 1; ; page++) {
  const result = await sublay.spaces.fetchMySpaces({ role: "admin,moderator", limit: 100, page });
  moderated.push(...result.data);
  if (!result.pagination.hasMore) break;
}
```

### updateSpace

Updates a space's settings.

```typescript
const space = await sublay.spaces.updateSpace({
  spaceId: "spc_abc123",
  description: "An updated description",
  postingPermission: "team",
});
```

<ParamField body="spaceId" type="string" required>
  The Sublay space ID.
</ParamField>

<ParamField body="name" type="string | null">
  New display name. `null` clears it.
</ParamField>

<ParamField body="slug" type="string | null">
  New slug. Must be unique. `null` clears it.
</ParamField>

<ParamField body="description" type="string | null">
  New description. `null` clears it.
</ParamField>

<ParamField body="readingPermission" type="string">
  Who can read content: `"anyone"` or `"members"`.
</ParamField>

<ParamField body="postingPermission" type="string">
  Who can post content: `"anyone"`, `"members"`, or `"team"` (the space's active admins and moderators).
</ParamField>

<ParamField body="visibility" type="string">
  Updated visibility: `"public"`, `"unlisted"`, or `"private"`. Controls who can find and see the space, independent of `readingPermission`. See [Space visibility](/v8/data-models/space#visibility).
</ParamField>

<ParamField body="nsfw" type="boolean">
  Updated NSFW own-flag. Toggling it recomputes this space's effective NSFW and cascades it top-down to every descendant space (and, live, to their entities). See [Space NSFW flagging](/v8/data-models/space#nsfw-flagging).
</ParamField>

<ParamField body="requireJoinApproval" type="boolean">
  Whether joining needs approval. Applies to joins from now on.
</ParamField>

<ParamField body="metadata" type="Record<string, any>">
  Arbitrary metadata attached to the space.
</ParamField>

<ParamField body="avatarFile" type="{ file: Blob | File; options: ImageOptions }">
  A new avatar image, replacing the current one (up to 50 MB). `options` must include `mode`. With an image, the request is sent as `multipart/form-data`. A field set to `null` can't travel with an image: the call throws before sending anything, so clear it in a separate call without one.
</ParamField>

<ParamField body="bannerFile" type="{ file: Blob | File; options: ImageOptions }">
  A new banner image, replacing the current one; same shape as `avatarFile`.
</ParamField>

<ParamField body="removeFileIds" type="string[]">
  Files to remove: the space's `avatarFileId` and/or `bannerFileId`, nothing else. Removing one clears that image. Works alone or with uploads. Any other id throws a `400` (`space/invalid-remove-file-ids`, with `invalidIds`).
</ParamField>

```typescript
// Remove the space's banner
if (space.bannerFileId) {
  await sublay.spaces.updateSpace({ spaceId: space.id, removeFileIds: [space.bannerFileId] });
}
```

**Returns** — `Promise<SpaceWithPermissions>`: the updated space plus [`memberPermissions`](/v8/data-models/space#spacememberpermissions), what the user may do in it after the update (no `parentSpace` or `childSpaces`).

### fetchSpaceBreadcrumb

Fetches the path from the top-level space down to and including a space, root first, as the logged-in user may see it. A space the user can't see is answered `404 space/not-found`. Each entry carries `hidden`: a space above that the user can't see (a private space they aren't an active member of, or a space under one) is exactly `{ hidden: true }`, with no other field. Apps can skip those entries, show "…", or start after the last hidden one. See [Fetch Space Breadcrumb](/v8/api-reference/spaces/fetch-breadcrumb).

```typescript
const breadcrumb = await sublay.spaces.fetchSpaceBreadcrumb({
  spaceId: "spc_abc123",
});
```

<ParamField body="spaceId" type="string" required>
  The Sublay space ID.
</ParamField>

**Returns** — `Promise<SpaceBreadcrumb>`: `{ breadcrumb, depth }`, where each `breadcrumb` entry is either a visible space (`id`, `shortId`, `name`, `slug`, `avatarFileId`, `visibility`, `parentSpaceId`, `depth`, `hidden: false`) or `{ hidden: true }`.

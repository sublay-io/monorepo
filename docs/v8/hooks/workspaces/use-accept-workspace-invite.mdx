## Overview

`useAcceptWorkspaceInvite` returns a callable that accepts an [invitation](/v8/data-models/workspace-invitation). The `inviteId` is non-secret. Accepting when you are already a member or the owner, or accepting again an invite you already accepted while you are still a member, succeeds without changing anything.

**Authorization:** self-service. The invite must be addressed to the signed-in user (identity-matched), and a **verified email is required**.

## Usage Example

```tsx
import { useAcceptWorkspaceInvite } from "@sublay/react-js";

function AcceptButton({ inviteId }: { inviteId: string }) {
  const acceptWorkspaceInvite = useAcceptWorkspaceInvite();

  const handleAccept = async () => {
    const standing = await acceptWorkspaceInvite({ inviteId });
    console.log("Joined with capabilities:", standing.capabilities);
  };

  return <button onClick={handleAccept}>Accept</button>;
}
```

## Parameters

<ParamField path="inviteId" type="string" required>
  The (non-secret) invitation UUID.
</ParamField>

## Returns

Your standing in the workspace, a `WorkspaceMemberStanding` — the same record [`useFetchMyWorkspaceMembership`](/v8/hooks/workspaces/use-fetch-my-workspace-membership) returns: `{ user, reasons, capabilities, permissions, rank, relativeRank, title, metadata }`, with every field present. The server answers `201` when the accept made you a member and `200` when you already were (or own the workspace).

<Note>
  An unverified accept fails with `workspace/email-not-verified` — prompt the user to verify their email, then retry.
</Note>

## Error codes

| Code | Status | Meaning |
|------|--------|---------|
| `workspace/email-not-verified` | 403 | The accepting user's email is not verified. |
| `workspace/invite-not-found` | 404 | No such invitation, or it is not addressed to you. |
| `workspace/not-pending` | 409 | Declined, revoked, accepted by another user, accepted by you before you left the workspace, or expired. An expired invitation can be [resent](/v8/hooks/workspaces/use-resend-workspace-invite); `error` says which. |

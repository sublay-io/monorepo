---
title: "Filters"
description: "Complete filter reference for entity list queries"
---

Filters are passed as `filters` in the object `fetchEntities` takes. They narrow down which entities are returned without affecting the sort order.

```tsx
fetchEntities({
  filters: {
    followedOnly: true,
    keywordsFilters: { includes: ["react"] },
    metadataFilters: { includes: { category: "tutorial" } },
  },
  sort: { sortBy: "createdAt" },
});
```

---

## `timeFrame`

Limits results to entities created within a recent window.

| Value | Description |
|-------|-------------|
| `"day"` | Last 24 hours |
| `"week"` | Last 7 days |
| `"month"` | Last 30 days |
| `"year"` | Last 365 days |

```tsx
fetchEntities({ filters: { timeFrame: "week" }, sort: { sortBy: "top" } });
```

---

## `userId`

Filters to entities created by a specific user.

```tsx
fetchEntities({ filters: { userId: "user_abc123" }, sort: { sortBy: "createdAt" } });
```

---

## `followedOnly`

When `true`, returns only entities from users the authenticated user follows.

```tsx
fetchEntities({ filters: { followedOnly: true }, sort: { sortBy: "hot" } });
```

---

## `keywordsFilters`

Filters by the entity's `keywords` array.

```ts
interface KeywordsFilters {
  includes?: string[];       // Entity must include ALL of these keywords
  doesNotInclude?: string[]; // Entity must not include ANY of these keywords
}
```

```tsx
// Entities tagged with both "react" and "typescript"
fetchEntities({ filters: { keywordsFilters: { includes: ["react", "typescript"] } }, sort: { sortBy: "createdAt" } });

// Exclude entities tagged "archived"
fetchEntities({ filters: { keywordsFilters: { doesNotInclude: ["archived"] } }, sort: { sortBy: "hot" } });
```

---

## `titleFilters`

Filters by the entity's `title` field.

```ts
interface TitleFilters {
  hasTitle?: boolean;                // Only entities that have (or don't have) a title
  includes?: string | string[];      // Title must contain this text (case-insensitive)
  doesNotInclude?: string | string[]; // Title must not contain this text
}
```

```tsx
fetchEntities({ filters: { titleFilters: { includes: "product launch" } }, sort: { sortBy: "createdAt" } });
```

---

## `contentFilters`

Filters by the entity's `content` field.

```ts
interface ContentFilters {
  hasContent?: boolean;
  includes?: string | string[];
  doesNotInclude?: string | string[];
}
```

---

## `attachmentsFilters`

Filters by whether the entity has attachments.

```ts
interface AttachmentsFilters {
  hasAttachments?: boolean;
}
```

```tsx
// Only entities with attachments
fetchEntities({ filters: { attachmentsFilters: { hasAttachments: true } }, sort: { sortBy: "createdAt" } });
```

---

## `locationFilters`

Filters to entities within a geographic radius.

```ts
interface LocationFilters {
  latitude: number;
  longitude: number;
  radius: number;  // in meters, greater than 0 and at most 20,000,000
}
```

A `radius` outside that range, or one that isn't a finite number, is rejected with `400 entity/invalid-query`. 20,000 km is about half the Earth's circumference, so the largest radius already reaches any point.

```tsx
fetchEntities({
  filters: {
    locationFilters: {
      latitude: 37.7749,
      longitude: -122.4194,
      radius: 10000, // 10 km
    },
  },
  sort: { sortBy: "createdAt" },
});
```

---

## `metadataFilters`

Filters by fields inside the entity's `metadata` object.

```ts
interface MetadataFilters {
  includes?: Record<string, unknown>;        // All key-value pairs must match exactly
  includesAny?: Record<string, unknown>[];   // At least one object in the array must match
  doesNotInclude?: Record<string, unknown>;  // None of these key-value pairs may match
  exists?: string[];                         // These metadata keys must exist
  doesNotExist?: string[];                   // These metadata keys must not exist
}
```

Keys and values can't contain a NUL character (`\u0000`), which metadata can never hold. A filter with one anywhere is rejected with `400 entity/invalid-query`.

```tsx
// Only "tutorial" category entities
fetchEntities({ filters: { metadataFilters: { includes: { category: "tutorial" } } }, sort: { sortBy: "hot" } });

// Entities that have a "price" metadata key
fetchEntities({ filters: { metadataFilters: { exists: ["price"] } }, sort: { sortBy: "createdAt" } });

// Entities in either "news" or "announcements" category
fetchEntities({
  filters: {
    metadataFilters: {
      includesAny: [{ category: "news" }, { category: "announcements" }],
    },
  },
  sort: { sortBy: "hot" },
});
```

## `nsfwFilter`

Filters by an entity's **effective** NSFW status — `entity.nsfw OR its space's nsfwEffective` (which itself folds in the space's whole ancestor chain). On projects without the spaces bundle it applies against the entity's own `nsfw` flag alone.

| Value | Description |
|-------|-------------|
| `"include-all"` | **Default.** No NSFW predicate — all entities returned regardless of NSFW status. |
| `"exclude"` | Drops effective-NSFW entities. |
| `"only"` | Returns only effective-NSFW entities. |

```tsx
// Hide NSFW content from the feed
fetchEntities({ filters: { nsfwFilter: "exclude" }, sort: { sortBy: "hot" } });
```

Sublay only labels (`nsfw`) and filters (`nsfwFilter`) NSFW content — it does not blur, age-gate, or store a per-viewer preference. Presentation is your app's responsibility. See [Entity NSFW flagging](/v8/data-models/entity#nsfw-flagging).

---

## Combining Filters

All filters can be combined. An entity must satisfy all specified conditions.

```tsx
fetchEntities({
  filters: {
    timeFrame: "week",
    keywordsFilters: { includes: ["design"] },
    metadataFilters: { includes: { status: "published" } },
    attachmentsFilters: { hasAttachments: true },
  },
  sort: { sortBy: "top" },
  config: { limit: 20, include: ["user"] },
});
```

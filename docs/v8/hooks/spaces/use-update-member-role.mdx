## Overview

`useUpdateMemberRole` returns a callable function for changing a space member's role. Only admins can update roles.

The space creator always stays an admin: only the creator can promote or demote admins, and the creator can't change their own role.

## Usage Example

```tsx
import { useUpdateMemberRole } from "@sublay/react-js";

function RoleSelector({ spaceId, userId }: { spaceId: string; userId: string }) {
  const updateRole = useUpdateMemberRole();

  return (
    <select onChange={(e) => updateRole({ spaceId, userId, role: e.target.value as any })}>
      <option value="member">Member</option>
      <option value="moderator">Moderator</option>
      <option value="admin">Admin</option>
    </select>
  );
}
```

## Parameters

<ParamField path="spaceId" type="string" required>
  UUID of the space.
</ParamField>

<ParamField path="userId" type="string" required>
  UUID of the member's user — their user id, not a membership id. Must be another member: your own id is refused (`400 space/own-member-id`). Your own membership is [`useCheckMyMembership`](/v8/hooks/spaces/use-check-my-membership) / [`useLeaveSpace`](/v8/hooks/spaces/use-leave-space).
</ParamField>

<ParamField path="role" type='"admin" | "moderator" | "member"' required>
  The new role to assign.
</ParamField>

## Returns

<ResponseField name="message" type="string">
  Confirmation message.
</ResponseField>

<ResponseField name="membership" type="object">
  Updated membership with `id`, `role`, `status`, `joinedAt`, and `userId`.
</ResponseField>

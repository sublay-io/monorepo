---
title: "Fetch Space by Slug"
api: "GET /v7/:projectId/spaces/by-slug"
description: "Get a single space by its URL slug"
---

Fetches a space using its `slug`. Slugs are optional and unique per project. A space the caller can't see (a `private` space they aren't an active member of, or a space under one) answers `404`, exactly like a nonexistent space. See [Space visibility](/v7/data-models/space#visibility). `parentSpace` is `null` when the caller can't see the parent, and `childSpaces` holds the sub-spaces the caller can see that are `public` or that they're an active member of.

## Query Parameters

<ParamField query="slug" type="string" required>
  The URL slug of the space.
</ParamField>

<ParamField query="include" type="string">
  Optional. Pass `"files"` to include file objects.
</ParamField>

## Response

Returns a [SpaceDetailed](/v7/data-models/space) object.

## Error Responses

<AccordionGroup>
  <Accordion title="Not Found — 404">
    ```json
    { "error": "Space not found.", "code": "space/not-found" }
    ```
  </Accordion>
</AccordionGroup>

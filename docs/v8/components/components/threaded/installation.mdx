# Installing Threaded Comments

Add Reddit-style threaded comments to your project with a single command.

---

## Prerequisites

<Steps>
  <Step title="Initialize CLI">
    ```bash
    npx @sublay/cli init
    ```
    Creates your `sublay.json` configuration file.
  </Step>

  <Step title="Install Dependencies">
    **React (Web):**
    ```bash
    npm install @sublay/react-js @sublay/ui-core-react-js
    ```

    **React Native:**
    ```bash
    npm install @sublay/react-native @sublay/ui-core-react-native
    ```

    **Expo:**
    ```bash
    npm install @sublay/expo @sublay/ui-core-react-native
    ```
  </Step>
</Steps>

See the [CLI Setup Guide](/v8/components/installation/cli-setup) for details.

---

## Installation Command

```bash
npx @sublay/cli add comments-threaded
```

---

## What Gets Installed

The CLI will:

1. **Fetch the component** from the registry based on your `sublay.json` platform and style settings
2. **Copy the component's files** (28 on web, 27 on React Native and Expo) into your project at `{componentsPath}/comments-threaded/`
3. **Transform imports** to work with your project structure
4. **Create `index.ts`** barrel export for clean imports
5. **Display usage examples** and required dependencies

## Using the Component

After installation, import and use the component:

```tsx
import { ThreadedCommentSection } from './components/comments-threaded';

function BlogPost({ post }) {
  return (
    <div>
      <h1>{post.title}</h1>
      <article>{post.content}</article>
      <ThreadedCommentSection foreignId={post.id} createIfNotFound />
    </div>
  );
}
```

<Info>
Make sure your app is wrapped with `<SublayProvider>`. See the [Quick Start Guide](/v8/components/installation/quick-start) for setup details.
</Info>

## Switching Styling Variants

To switch between Tailwind and Inline Styles after installation:

<Steps>
  <Step title="Delete Current Components">
    ```bash
    rm -rf src/components/comments-threaded
    ```
  </Step>

  <Step title="Update Configuration">
    Edit `sublay.json`:
    ```json
    {
      "style": "styled"
    }
    ```
  </Step>

  <Step title="Re-install">
    ```bash
    npx @sublay/cli add comments-threaded
    ```
  </Step>
</Steps>

<Warning>
This replaces your component files. Back up any customizations first.
</Warning>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Import errors" icon="file-import">
    Make sure your import path matches your `paths.components` in `sublay.json`:

    ```tsx
    // paths.components = "src/components"
    import { ThreadedCommentSection } from './components/comments-threaded';
    ```
  </Accordion>

  <Accordion title="TypeScript errors" icon="code">
    Ensure your `tsconfig.json` includes the components directory:

    ```json
    { "include": ["src/**/*"] }
    ```
  </Accordion>

  <Accordion title="Component already exists" icon="copy">
    Re-running `add` overwrites the existing installation. The CLI prints a
    warning first, then proceeds:

    ```
    ⚠️  Overwriting existing component: comments-threaded
    ```

    Because these files are yours to edit, any customizations you made are
    replaced. Commit (or back up) your changes before re-adding a component:

    ```bash
    git status src/components/comments-threaded
    npx @sublay/cli add comments-threaded
    ```
  </Accordion>
</AccordionGroup>

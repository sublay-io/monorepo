---
title: "Mark as Read"
api: "POST /v8/:projectId/chat/conversations/:conversationId/read"
description: "Advance the current user's read cursor to a given message"
---

Updates the current user's `lastReadAt` timestamp on their conversation membership to the `createdAt` of the specified message. This reduces the unread count for the conversation.

The operation is monotonic — `lastReadAt` is never moved backward. If the provided message is older than the current `lastReadAt`, the call is a no-op.

## Path Parameters

<ParamField path="conversationId" type="string" required>
  The ID of the conversation.
</ParamField>

## Body Parameters

<ParamField body="messageId" type="string" required>
  The ID of the message to mark as read. The user's `lastReadAt` will be set to this message's `createdAt`.
</ParamField>

<ParamField body="actingUserId" type="string">
  Service key only, and required with one: the user this request acts as. Their read cursor is advanced. A user token always acts as its own user and must not send it (`400 chat/acting-user-not-allowed`).
</ParamField>

## Response

```json
{ "message": "Marked as read." }
```

## Error Responses

<AccordionGroup>
  <Accordion title="Acting User Not Allowed — 400">
    A user token sent `actingUserId`, even naming its own user. Only a service key names the user it acts as; a user token always acts as its own user.
    ```json
    { "error": "actingUserId is only accepted with a service key. A user's own token always acts as that user.", "code": "chat/acting-user-not-allowed" }
    ```
  </Accordion>
  <Accordion title="Unsupported Parameter — 400">
    The request sent `userId`. On this route the user a service key acts as is `actingUserId`.
    ```json
    {
      "error": "`userId` was renamed to `actingUserId`: send the user this service key acts as in `actingUserId`.",
      "code": "chat/unsupported-param",
      "param": "userId"
    }
    ```
  </Accordion>
  <Accordion title="Missing User — 400">
    A service key sent no `actingUserId`.
    ```json
    { "error": "Missing user ID", "code": "chat/missing-user-id" }
    ```
  </Accordion>
  <Accordion title="Forbidden — 403">
    ```json
    { "error": "You are not an active member of this conversation.", "code": "chat/not-a-member" }
    ```
  </Accordion>
</AccordionGroup>

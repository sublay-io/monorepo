---
title: "Remove Comment Reaction"
api: "DELETE /v8/:projectId/comments/:commentId/reactions"
description: "Remove the authenticated user's reaction from a comment"
---

Removes the authenticated user's reaction from a comment. The comment's `reactionCounts` map is decremented for the removed reaction type.

**Authentication required.**

## Path Parameters

<ParamField path="commentId" type="string" required>
  The UUID of the comment to remove the reaction from.
</ParamField>

## Body Parameters

<ParamField body="userId" type="string">
  The user whose reaction is removed. **Service or master key only**, and required with one — a key has no user of its own, so leaving it out returns `400 comment/missing-user-id`. A user token always acts as itself: naming a different user returns `403 comment/unauthorized`.
</ParamField>

## Blocks

Removing your own reaction is undoing your own action, so a block doesn't stop it: as long as the comment is visible to you — in full, or as a placeholder — your reaction is removed. This includes a comment whose author blocked you, a comment its author deleted and a moderator-removed comment — even though neither of the last two [takes new reactions](/v8/api-reference/comments/add-reaction#deleted-and-removed-comments).

When the comment isn't visible to you at all — it sits on an entity whose author has blocked you — the request returns `404 comment/not-found` and nothing changes. The exception is your **own** comment on such an entity: it stays visible to you, so removing your reaction from it works.

## Response

Returns the [Comment](/v8/data-models/comment) as you'd see it after the change — in full, flagged with `isAuthorBlocked`, or as a [placeholder](/v8/data-models/comment#placeholders) — with the updated `reactionCounts`. If you had no reaction on the comment, the comment is returned unchanged.

## Error Responses

<AccordionGroup>
  <Accordion title="Invalid Params — 400">
    Returned when `commentId` isn't a valid UUID.

    ```json
    { "error": "commentId: Invalid UUID format", "code": "comment/invalid-params" }
    ```
  </Accordion>
  <Accordion title="Acting as another user — 403">
    Returned when a request authenticated with a user token sends a `userId` other than that user's own ID.

    ```json
    { "error": "Unauthorized", "code": "comment/unauthorized" }
    ```
  </Accordion>
  <Accordion title="Missing User — 400">
    Returned when a service or master key sends no `userId`.

    ```json
    { "error": "Missing user ID", "code": "comment/missing-user-id" }
    ```
  </Accordion>
  <Accordion title="Not Found — 404">
    ```json
    { "error": "Comment not found.", "code": "comment/not-found" }
    ```
  </Accordion>
</AccordionGroup>

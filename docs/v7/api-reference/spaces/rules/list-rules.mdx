---
title: "List Rules"
api: "GET /v7/:projectId/spaces/:spaceId/rules"
description: "Get all community rules for a space"
---

Returns all rules for a space, ordered by their `order` field. Authentication is optional. A space the caller can't see (a `private` space they aren't an active member of, or one under it) has no rules to show: the list is empty, as for a nonexistent space.

## Path Parameters

<ParamField path="spaceId" type="string" required>
  UUID of the space.
</ParamField>

## Response

<ResponseField name="data" type="Rule[]">
  Array of rule objects ordered by `order` ascending.
</ResponseField>

<ResponseField name="count" type="number">
  Total number of rules.
</ResponseField>

Each rule has: `id`, `spaceId`, `projectId`, `title`, `description`, `order`, `lastApprovedBy`, `createdAt`, `updatedAt`.

See also: [useFetchManyRules](/v7/hooks/spaces/rules/use-fetch-many-rules)

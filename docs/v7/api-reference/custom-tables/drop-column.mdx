---
title: "Drop Column"
api: "DELETE /v7/:projectId/db/tables/:tableName/columns/:columnName"
description: "Permanently drop a column and its data from a custom table"
---

Drops one column from a custom table.

<Warning>
  **This is irreversible** — every value stored in that column is lost.
</Warning>

<Warning>
  **Service or master key required.**
</Warning>

## Path Parameters

<ParamField path="tableName" type="string" required>
  Logical name of the table — pass `orders`, not `custom_orders`.
</ParamField>

<ParamField path="columnName" type="string" required>
  Name of the column to drop. Managed columns (`id`, `createdAt`, `updatedAt`, `deletedAt`) cannot be dropped — the platform owns them, and dropping one would break the table's row machinery.
</ParamField>

## Response

<ResponseField name="dropped" type="string">
  The name of the column that was dropped.
</ResponseField>

## Error Responses

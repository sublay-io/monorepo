title: "Space Moderation"

The space moderation functions let admins and moderators resolve reports, moderate entities, comments, and chat messages, and manage community rules within a space.

---

### handleSpaceReport

Handles a report filed in a space, whatever was reported: an entity, a comment or a chat message in the space's conversation (`PATCH /spaces/:spaceId/reports/:reportId`). The server reads the reported content and its author from the report, so the call names neither. See [Handle Report](/v8/api-reference/spaces/moderation/handle-report) for every rule and error.

```typescript
await sublay.spaces.handleSpaceReport({
  spaceId: "spc_abc123",
  reportId: "rpt_xyz789",
  actions: ["remove-entity", "ban-user"],
  reason: "Repeated spam",
  summary: "Removed and banned for spam",
});
```

<ParamField body="spaceId" type="string" required>
  The Sublay space ID where the report was filed.
</ParamField>

<ParamField body="reportId" type="string" required>
  The Sublay report ID.
</ParamField>

<ParamField body="actions" type="SpaceReportAction[]" required>
  One or more actions to apply. Which ones a report takes depends on what was reported:

  - an entity report: `"remove-entity"`, `"ban-user"`, `"dismiss"`
  - a comment report: `"remove-comment"`, `"ban-user"`, `"dismiss"`
  - a chat message report: `"remove-message"`, `"ban-user"`, `"dismiss"`

  An action the report's type doesn't take is refused with `400 report/invalid-actions`, and `"dismiss"` can't be combined with other actions. `"ban-user"` bans the author of the reported content from the space and requires `reason`; it is refused with `400 report/cannot-ban-self` when that author is the logged-in user.
</ParamField>

<ParamField body="summary" type="string" required>
  The resolution note stored on the report, up to 1000 characters. Required for every report type; without it (or with only whitespace) the request is refused with `400 report/missing-fields`.
</ParamField>

<ParamField body="reason" type="string">
  Reason for the ban, kept in the space's ban log, up to 1000 characters. Required when `actions` includes `"ban-user"`.
</ParamField>

**Returns** — `Promise<void>`. It resolves with no value once the actions are applied.

`SpaceReportAction` is `"remove-entity" | "remove-comment" | "remove-message" | "ban-user" | "dismiss"`.

### moderateSpaceEntity

Approves or removes an entity in a space.

```typescript
const result = await sublay.spaces.moderateSpaceEntity({
  spaceId: "spc_abc123",
  entityId: "ent_222",
  action: "remove",
  reason: "Off-topic",
});
```

<ParamField body="spaceId" type="string" required>
  The Sublay space ID.
</ParamField>

<ParamField body="entityId" type="string" required>
  The ID of the entity to moderate.
</ParamField>

<ParamField body="action" type="string" required>
  The action to take: `"approve"` or `"remove"`.
</ParamField>

<ParamField body="reason" type="string">
  The reason for the moderation action.
</ParamField>

**Returns** — `Promise<{ message: string; moderationStatus: "approved" | "removed" }>`

---

### setSpaceEntityNsfw

Sets the NSFW own-flag on an entity within a space — including other users' entities. Separate from `moderateSpaceEntity`: it **labels** the entity (`nsfw`), it does not approve/remove it. Requires the acting user to be an admin or moderator of the space.

```typescript
const result = await sublay.spaces.setSpaceEntityNsfw({
  spaceId: "spc_abc123",
  entityId: "ent_222",
  nsfw: true,
});
```

<ParamField body="spaceId" type="string" required>
  The Sublay space ID containing the entity.
</ParamField>

<ParamField body="entityId" type="string" required>
  The ID of the entity to flag or unflag.
</ParamField>

<ParamField body="nsfw" type="boolean" required>
  The NSFW own-flag to set on the entity.
</ParamField>

**Returns** — `Promise<{ message: string; nsfw: boolean }>`

### moderateSpaceChatMessage

Removes a chat message in a space conversation.

```typescript
const result = await sublay.spaces.moderateSpaceChatMessage({
  spaceId: "spc_abc123",
  messageId: "msg_222",
  action: "remove",
  reason: "Spam",
});
```

<ParamField body="spaceId" type="string" required>
  The Sublay space ID.
</ParamField>

<ParamField body="messageId" type="string" required>
  The ID of the chat message to moderate.
</ParamField>

<ParamField body="action" type='"remove"' required>
  The moderation action. Chat messages are never held for approval, so `"remove"` is the only value.
</ParamField>

<ParamField body="reason" type="string">
  The reason for the removal. Trimmed; up to 1,000 characters.
</ParamField>

**Returns** — `Promise<{ message: string; moderationStatus: "removed" }>`

### fetchManyRules

Fetches all rules for a space. The rules of a space the logged-in user can't see are answered `404 space/not-found`.

```typescript
const rules = await sublay.spaces.fetchManyRules({ spaceId: "spc_abc123" });
```

<ParamField body="spaceId" type="string" required>
  The Sublay space ID.
</ParamField>

**Returns** — `Promise<FetchManyRulesResponse>`

---

### fetchRule

Fetches a single rule by ID. A rule of a space the logged-in user can't see is answered `404 space/not-found`.

```typescript
const rule = await sublay.spaces.fetchRule({
  spaceId: "spc_abc123",
  ruleId: "rul_222",
});
```

<ParamField body="spaceId" type="string" required>
  The Sublay space ID.
</ParamField>

<ParamField body="ruleId" type="string" required>
  The ID of the rule to fetch.
</ParamField>

**Returns** — `Promise<Rule>`

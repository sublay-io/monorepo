---
title: "Fetch Space"
api: "GET /v8/:projectId/spaces/:spaceId"
description: "Get a single space by its UUID"
---

Fetches a space by UUID. Returns full space details including membership permissions for the viewer (the signed-in user, or the user a service key names in `actingUserId`), parent space, and child space previews.

## Path Parameters

<ParamField path="spaceId" type="string" required>
  UUID of the space.
</ParamField>

## Query Parameters

<ParamField query="actingUserId" type="string">
  Service key only: the user to read as. The response is exactly what that user's own access token would get (their role, `memberPermissions` and membership). Leave it out for the anonymous view. A user token always acts as its own user and must not send it, and neither may a request with no credentials (`400 space/acting-user-not-allowed`).
</ParamField>

<ParamField query="include" type="string">
  Optional. Pass `"files"` to include avatar and banner file objects.
</ParamField>

## Response

Returns a [SpaceDetailed](/v8/data-models/space) object including `memberPermissions`, `parentSpace`, and `childSpaces`.

## Error Responses

<AccordionGroup>
  <Accordion title="Invalid Id — 400">
    Returned when `spaceId` isn't a valid UUID. Checked before sign-in, permissions and the endpoint's other checks.
    ```json
    { "error": "Invalid space id: expected a UUID.", "code": "space/invalid-params" }
    ```
  </Accordion>
  <Accordion title="Not Found — 404">
    ```json
    { "error": "Space not found.", "code": "space/not-found" }
    ```
  </Accordion>
  <Accordion title="Acting User Not Allowed — 400">
    A user token, or a request with no credentials, sent `actingUserId`, even naming its own user. Only a service key names the user it acts as; a user token always acts as its own user.

    ```json
    { "error": "actingUserId is only accepted with a service key. A user's own token always acts as that user.", "code": "space/acting-user-not-allowed" }
    ```
  </Accordion>
  <Accordion title="User Not Found — 404">
    Returned when a service key names an `actingUserId` that isn't a user in this project.

    ```json
    { "error": "No user with this actingUserId exists in this project.", "code": "space/user-not-found" }
    ```
  </Accordion>
</AccordionGroup>

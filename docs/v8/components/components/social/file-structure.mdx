42 files (43 for the inline styles variant on React Native and Expo) organized for simplicity and clarity: the component's own 25 files, and the shared pieces it is built from in `shared/`. The trees below list every file.

## Key Files

### `social-comment-section.tsx` — Main Component

The entry component. Edit this to modify the overall layout, add headers or footers, or change how the component is structured.

---

### `new-comment-form.tsx` — Comment Input

Handles both top-level comment input and reply input (reused for both). Edit to:
- Customize placeholder text
- Change submit button styles
- Add character limits

---

### `heart-button.tsx` — Like Button

The heart icon and like count. Edit to:
- Change the heart icon color or style
- Modify the like count display
- Add animations on like

---

### `sort-by-button.tsx` — Sort Control

A single button of the Top/New/Old sort switcher. Edit to:
- Change how the active and inactive states render

The list of options — their labels and which sort each one applies — is `sortOptions` in `social-comment-section.tsx`.

---

### `use-social-comments.tsx` — Main Hook

Contains all comment logic and the key behavioral callbacks you'll want to customize:

- `loginRequiredCallback` — Called when an unauthenticated user tries to comment
- `usernameRequiredCallback` — Called when a user without a username tries to comment
- `commentTooShortCallback` — Called when a user tries to post an empty comment or reply
- `currentUserClickCallback` — Called when a user clicks their own profile
- `otherUserClickCallback(userId, foreignId)` — Called when a user clicks another user's profile

The hook returns `{ CommentSectionProvider, providerProps, CommentsFeed, NewCommentForm }`. The React Native variants also return `SortByButton`. `providerProps` holds everything the provider is given: the entity, the highlighted comment, the callbacks and the loading settings (`limit`, `defaultSortByReaction`). ``social-comment-section.tsx`` spreads it onto the provider:

```tsx
const { CommentSectionProvider, providerProps } = useSocialComments({ entityId });

<CommentSectionProvider {...providerProps}>
  {/* feed and form */}
</CommentSectionProvider>
```

To pass the provider something new, add it to `providerProps`.

---

### `shared/` — Shared Pieces

Presentational pieces the component is built from: the GIF picker, the user avatar, loading skeletons, mention parsing, icons, the emoji bar, relative timestamps and a few helpers. They are installed into the component's own folder and are yours to edit like every other file. Each installed component has its own copy, so editing one component's `shared/` folder does not affect another.

`user-avatar.tsx` shows the first of these a user has: the avatar file uploaded through Sublay, then the `avatar` URL, then a generated avatar. An uploaded avatar is stored in several sizes, and `pick-avatar-source.ts` picks the smallest one that is still sharp at the size the avatar is displayed at on the device's screen.

`theme.ts` holds the light and dark colors these pieces draw with (GIF picker surface and controls, skeletons, the emoji bar divider, mention text). Edit it to change them.

- **Inline styles variant, and every React Native / Expo variant:** the component passes its `theme` to the pieces.
- **Tailwind variant on web:** the pieces read CSS custom properties (`--sublay-ui-surface`, `--sublay-ui-control`, `--sublay-ui-muted`, `--sublay-ui-text`, `--sublay-ui-divider`, `--sublay-ui-skeleton`, `--sublay-ui-mention`). The root element in `social-comment-section.tsx` sets them to the dark values under `dark:`. If you build your own layout from `CommentsFeed` and `NewCommentForm`, keep those classes on an element that wraps both.

## Key Differences from Threaded Comments

| Threaded | Social |
|---------|--------|
| `vote-buttons.tsx` | `heart-button.tsx` |
| Threading lines + indentation | Flat design |
| Unlimited nesting | Max 2 levels |
| No sort button | `sort-by-button.tsx` |
| Complex thread collapse | Simple reply expansion |

## Common Customizations

### Change Heart Color

```tsx
// Edit: components/comments-feed/comment/heart-button.tsx
<span style={{ color: '#EC4899' }}>  {/* Pink heart */}
  ❤️
</span>
```

### Modify Sort Options

```tsx
// Edit: components/social-comment-section.tsx
const sortOptions = [
  { label: "Top", sortBy: "top", sortDir: "desc" },      // ranked by likes
  { label: "New", sortBy: "createdAt", sortDir: "desc" },
  // { label: "Old", sortBy: "createdAt", sortDir: "asc" },  // removed
];
```

`top` ranks by the `like` reaction, set by `defaultSortByReaction: "like"` in `providerProps` in `use-social-comments.tsx`.

### Customize Empty State

```tsx
// Edit: components/comments-feed/no-comments-placeholder.tsx
<p>No comments yet. Be the first! 🎉</p>
```

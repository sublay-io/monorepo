## Overview

`useFetchCommentReactionsWrapper` is a stateful wrapper around [`useFetchCommentReactions`](/v8/hooks/reactions/use-fetch-comment-reactions) that manages pagination and reaction list state for you. Use it to build "who reacted" UIs for comments — for example, a popover showing users who liked a specific comment.

By default the hook does not fetch on mount. Set `autoFetch: true` to start fetching immediately, or call `refetch()` manually when you're ready (e.g., when a popover opens).

## Usage Example

```tsx
import { useFetchCommentReactionsWrapper } from "@sublay/react-js";

function CommentReactions({ commentId }: { commentId: string }) {
  const { reactions, loading, hasMore, loadMore, refetch } =
    useFetchCommentReactionsWrapper({
      commentId,
      reactionType: "like",
      limit: 20,
      autoFetch: true,
    });

  return (
    <div>
      <ul>
        {reactions.map((r) => (
          <li key={r.id}>{r.user?.username}</li>
        ))}
      </ul>
      {hasMore && (
        <button onClick={loadMore} disabled={loading}>
          Load more
        </button>
      )}
    </div>
  );
}
```

## Parameters

<ParamField body="commentId" type="string" required>
  The comment to fetch reactions for.
</ParamField>

<ParamField body="limit" type="number">
  Number of reactions per page: a whole number from `1` to `100`. Defaults to `20`. A larger value is rejected with `400 comment/invalid-query`, never lowered to `100`.
</ParamField>

<ParamField body="reactionType" type="ReactionType" optional>
  Filter to a specific reaction type. When omitted, all reaction types are returned.
</ParamField>

<ParamField body="sortDir" type='"asc" | "desc"' optional>
  Sort direction by creation date. Default: `"desc"`.
</ParamField>

<ParamField body="autoFetch" type="boolean" optional>
  If `true`, fetch automatically on mount. Default: `false`.
</ParamField>

## Returns

<ResponseField name="reactions" type="Reaction[]">
  The current list of fetched reactions. Appended to on each `loadMore` call.
</ResponseField>

<ResponseField name="loading" type="boolean">
  `true` while fetching the initial page or loading more.
</ResponseField>

<ResponseField name="error" type="Error | null">
  The last load failure, or `null`. Cleared when the next load starts; `loadMore()` retries it.
</ResponseField>

<ResponseField name="hasMore" type="boolean">
  `true` while `loadMore()` has something to fetch: a next page, or a load that failed.
</ResponseField>

<ResponseField name="loadMore" type="() => Promise<void>">
  Load the next page of reactions and append it, or retry the load that failed. With `autoFetch` off, the first call loads page 1. Does nothing while a load is running or when there is nothing more. Never rejects: a failure lands in `error`.
</ResponseField>

<ResponseField name="refetch" type="() => Promise<void>">
  Reload from page 1. The loaded reactions stay until the new first page replaces them. Never rejects: a failure lands in `error`.
</ResponseField>

## Overview

Returns a function that sends a connection request to another user. An optional message can be included with the request. The current user must be authenticated.

## Usage Example

```tsx
import { useRequestConnection } from "@sublay/react-js";

function ConnectButton({ userId }: { userId: string }) {
  const requestConnection = useRequestConnection();

  const handleConnect = async () => {
    const result = await requestConnection({ userId, message: "Let's connect!" });
    console.log("Request sent:", result.id);
  };

  return <button onClick={handleConnect}>Connect</button>;
}
```

## Parameters

The hook returns a function. That function accepts:

<ParamField path="userId" type="string" required>
  The ID of the user to send a connection request to.
</ParamField>

<ParamField path="message" type="string">
  An optional message to include with the connection request.
</ParamField>

## Returns

A `Promise<ConnectionRow>` that resolves to the connection, seen from the signed-in user's side. See [ConnectionRow](/v8/data-models/connection#connectionrow).

- A new request resolves to the new pending row.
- When the signed-in user's own request is still pending, or the two are already connected, it resolves to that existing row, so a repeat is safe. The stored message is kept and no second notification is sent.
- When the other user already sent the signed-in user a request, it rejects with `409 connection/request-received`. The error body carries their request as `connection`, so you can offer [to accept it](/v8/hooks/connections/use-accept-connection).
- After the other user declined the signed-in user's request, it rejects with `409 connection/request-declined`.

<ResponseField name="id" type="string">
  The connection's ID. Accept, decline and remove take it.
</ResponseField>

<ResponseField name="user" type="User">
  The user the request was sent to. Public profile fields only.
</ResponseField>

<ResponseField name="type" type='"sent" | "received"'>
  `"sent"` when the signed-in user sent the request (always, for a new one); `"received"` for an existing accepted connection the other user started.
</ResponseField>

<ResponseField name="message" type="string | null">
  The note sent with the request, or `null`.
</ResponseField>

<ResponseField name="status" type='"pending" | "accepted" | "declined"'>
  `"pending"` until the receiver responds.
</ResponseField>

<ResponseField name="createdAt" type="string">
  ISO timestamp of when the request was sent.
</ResponseField>

<ResponseField name="respondedAt" type="string | null">
  When the request was accepted; `null` while it is pending.
</ResponseField>

---
title: "Add Host"
api: "POST /v8/:projectId/events/:eventId/hosts"
description: "Grant a user host privileges on an event (owner-only)"
---

Adds a user to the event's `hostIds`. **Owner-only**: the caller must be the event's [owner](/v8/data-models/event#owner-and-hosts) (`userId`), and, for an event in a space, an active member of that space who isn't banned in it or a space above it. A service key acts as the user it names in `actingUserId`. The operation is idempotent (adding an existing host is a no-op) and takes a row-level lock to serialize concurrent host changes.

For an event in a space, the target must be an active member of that space (`409 event/host-not-member`). For an event with no space, any user can be made a host. The owner is always kept in the stored `hostIds`.

## Path Parameters

<ParamField path="eventId" type="string" required>
  UUID of the event.
</ParamField>

## Body Parameters

<ParamField body="userId" type="string" required>
  The user to grant host on the event.
</ParamField>

<ParamField body="actingUserId" type="string">
  Required with a service key: the user this request acts as. It has exactly that user's powers, so it is refused unless they are the event's owner, and it is recorded as theirs. A user token always acts as its own user and must not send it (`400 event/acting-user-not-allowed`).
</ParamField>

## Response

Returns the updated [Event](/v8/data-models/event) with the new `hostIds`.

## Error Responses

<AccordionGroup>
  <Accordion title="Missing Acting User — 400">
    A service key sent no `actingUserId`.
    ```json
    { "error": "A service key must send actingUserId: the user this request acts as.", "code": "event/missing-user-id" }
    ```
  </Accordion>
  <Accordion title="Invalid Acting User — 400">
    `actingUserId` is not a user id.
    ```json
    { "error": "actingUserId must be a user id.", "code": "event/invalid-body" }
    ```
  </Accordion>
  <Accordion title="Acting User Not Allowed — 400">
    A user token sent `actingUserId`, even naming its own user. Only a service key names the user it acts as; a user token always acts as its own user.
    ```json
    { "error": "actingUserId is only accepted with a service key. A user's own token always acts as that user.", "code": "event/acting-user-not-allowed" }
    ```
  </Accordion>
  <Accordion title="Wrong Location — 400">
    `actingUserId` was sent in the query string. On this endpoint every field goes in the request body.
    ```json
    {
      "error": "`actingUserId` goes in the request body on this endpoint.",
      "code": "event/wrong-location",
      "param": "actingUserId"
    }
    ```
  </Accordion>
  <Accordion title="User Not Found — 404">
    Returned when a service key names an `actingUserId` that isn't a user in this project.
    ```json
    { "error": "No user with this actingUserId exists in this project.", "code": "event/user-not-found" }
    ```
  </Accordion>
  <Accordion title="Not Found — 404">
    The event doesn't exist, or the caller can't [see it](/v8/data-models/event#visibility) and isn't one of its hosts.
    ```json
    { "error": "Event not found", "code": "event/not-found" }
    ```
  </Accordion>
  <Accordion title="Forbidden (not the owner) — 403">
    The caller isn't the event's owner. Other hosts can't add or remove hosts; on an event whose owner's account was deleted, nobody can.
    ```json
    { "error": "Only the event's owner may add or remove hosts.", "code": "event/forbidden" }
    ```
  </Accordion>
  <Accordion title="Host Not an Active Member — 403">
    The caller is the owner, but the event is in a space they aren't an active member of, or they are banned in it or a space above it. One body for every case.
    ```json
    { "error": "Hosts must be active members of this event's space, and not banned from it or a space above it, to do this.", "code": "event/not-space-member" }
    ```
  </Accordion>
  <Accordion title="Host Not a Member — 409">
    The target isn't an active member of the event's space (not a member, pending or banned — the same body for each).
    ```json
    { "error": "This user isn't an active member of this space.", "code": "event/host-not-member" }
    ```
  </Accordion>
</AccordionGroup>

See also: [useAddHost](/v8/hooks/events/use-add-host)

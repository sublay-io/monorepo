# Social Comments Props

The `SocialCommentSection` component follows the same **minimal props philosophy** as all Sublay components. It works with a single prop that identifies the entity and offers optional props for specific needs.

---

## Component Import

```tsx
import { SocialCommentSection } from './components/comments-social';
```

---

## Props Interface

```tsx
interface SocialCommentSectionProps {
  // Entity identification (provide ONE of these)
  entity?: Entity | undefined | null;
  entityId?: string | undefined | null;
  foreignId?: string | undefined | null;
  shortId?: string | undefined | null;

  // With foreignId: create the entity if it doesn't exist yet
  createIfNotFound?: boolean;

  // Optional features
  isVisible?: boolean;
  highlightedCommentId?: string | undefined | null;
  gifPickerFullScreen?: boolean;
  theme?: 'light' | 'dark';   // Not used by the Tailwind variant on React
  children?: React.ReactNode;
}
```

---

## Entity Identification

**Provide one of these** to identify which entity the comments belong to:

### `entity`
**Type:** `Entity | undefined | null`

A complete Entity object. Use when you already have it from `useFetchEntity` or similar hooks.

### `entityId`
**Type:** `string | undefined | null`

The Sublay entity's own `id` (a UUID), as returned by the SDK and the API.

### `foreignId`
**Type:** `string | undefined | null`

Your external/custom ID for the entity. The component finds the Sublay entity that has this `foreignId`. It creates one only when [`createIfNotFound`](#createifnotfound) is also set.

### `shortId`
**Type:** `string | undefined | null`

A short, human-readable identifier if you've set one on the entity.

<Note>
**You only need ONE of these props.** Use whichever fits your data model best.
</Note>

---

### `createIfNotFound`

**Type:** `boolean` — **Default:** `false`

Used with `foreignId`. When set, the entity is created the first time the section is shown if no entity with that `foreignId` exists yet.

```tsx
<SocialCommentSection foreignId="photo_123" createIfNotFound />
```

Without it, the section only finds an existing entity. When there is none, it shows its ["Couldn't load comments" state](/v8/components/components/social/features#error-states) instead of the comments.

It has no effect with `entity`, `entityId` or `shortId`.

The other examples on this page pass `foreignId` alone, for an entity that already exists.

---

## Optional Props

### `isVisible`

**Type:** `boolean` — **Default:** `true`

Controls whether the comment section is visible. Useful when rendering inside a modal, drawer, or bottom sheet.

```tsx
<SocialCommentSection
  foreignId="photo_123"
  isVisible={showComments}
/>
```

---

### `highlightedCommentId`

**Type:** `string | undefined | null`

ID of a specific comment to highlight on load. Once it loads, the component shows it at the top of the list with a highlight background color: a top-level comment on its own, or a reply under its parent comment, visible even while the parent's other replies are collapsed. The rest of the comments follow below, without repeating it. If the comment doesn't exist, the list shows as usual.

```tsx
<SocialCommentSection
  foreignId="photo_123"
  highlightedCommentId="comment_456"
/>
```

---

### `gifPickerFullScreen`

**Type:** `boolean` — **Default:** `false`

Where the GIF picker opens, on React, React Native and Expo. By default it covers the comment section: the comment list and the form. When set, it covers the whole screen. On React Native and Expo the full-screen picker opens in a `Modal`, so it covers the screen wherever the section sits in your app, and Android's back button closes it.

```tsx
<SocialCommentSection
  foreignId="photo_123"
  gifPickerFullScreen
/>
```

See [GIF Picker Placement](/v8/components/customization/layout-structure#gif-picker-placement) for custom layouts.

---

### `theme`

**Type:** `'light' | 'dark'` — **Default:** `'light'`

Sets the color theme for the component: in both variants on React Native and Expo, and in the inline styles variant on React. The Tailwind variant on React ignores it.

<Tabs>
  <Tab title="Inline Styles Variant">
    ```tsx
    <SocialCommentSection
      foreignId="photo_123"
      theme={isDark ? 'dark' : 'light'}
    />
    ```
  </Tab>

  <Tab title="Tailwind Variant">
    **React Native and Expo:** pass `theme` as above. Each class is chosen from it in code; there is no Tailwind dark mode setup.

    **React:** ignores this prop. Use Tailwind's dark mode system instead:

    ```tsx
    <html className={isDark ? 'dark' : ''}>
      <SocialCommentSection foreignId="photo_123" />
    </html>
    ```

    Requires Tailwind's dark mode to follow the `dark` class: `darkMode: 'class'` in `tailwind.config.js` (Tailwind CSS 3), or `@custom-variant dark (&:where(.dark, .dark *));` in your CSS (Tailwind CSS 4).
  </Tab>
</Tabs>

---

### `children`

**Type:** `React.ReactNode`

Optional content rendered within the comment section.

```tsx
<SocialCommentSection foreignId="photo_123">
  <div className="text-center text-gray-400 text-sm my-2">
    Share your thoughts!
  </div>
</SocialCommentSection>
```

---

## Usage Examples

### Minimal

```tsx
<SocialCommentSection foreignId="photo_123" createIfNotFound />
```

---

### With Dark Mode (Inline Styles)

```tsx
function PhotoPost({ photo }) {
  const [isDark, setIsDark] = useState(false);

  return (
    <>
      <img src={photo.url} />
      <SocialCommentSection
        foreignId={photo.id}
        theme={isDark ? 'dark' : 'light'}
      />
    </>
  );
}
```

---

### With Highlighted Comment

```tsx
import { useSearchParams } from 'react-router-dom';

function PhotoPost({ photo }) {
  const [searchParams] = useSearchParams();

  return (
    <SocialCommentSection
      foreignId={photo.id}
      highlightedCommentId={searchParams.get('commentId')}
    />
  );
}
```

---

### In a React Native Bottom Sheet

```tsx
import BottomSheet from '@gorhom/bottom-sheet';

function PhotoScreen({ photo }) {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <PhotoView photo={photo} onCommentPress={() => setIsOpen(true)} />

      <BottomSheet isOpen={isOpen}>
        <SocialCommentSection
          foreignId={photo.id}
          isVisible={isOpen}
        />
      </BottomSheet>
    </>
  );
}
```

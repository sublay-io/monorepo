## Overview

`useFetchManySpaces` returns a callable function for fetching multiple spaces. It supports searching by name, slug or description, filtering by parent space, and sorting.

For paginated, stateful lists with load-more support, use [`useSpaceList`](/v8/hooks/space-lists/use-space-list) instead.

<Note>
  This is a discovery surface: only `public` spaces are listed, for every caller. `unlisted` and `private` spaces are never listed here, not even to their members (they stay reachable by direct link). To list the spaces the current user is a member of, whatever their visibility, use [`useFetchUserSpaces`](/v8/hooks/spaces/use-fetch-user-spaces). See [Space visibility](/v8/data-models/space#visibility).
</Note>

## Usage Example

```tsx
import { useFetchManySpaces } from "@sublay/react-js";

function SpaceSearch() {
  const fetchSpaces = useFetchManySpaces();

  const handleSearch = async (query: string) => {
    // Top-level spaces by default; add parentSpaceId: "any" to search every level.
    const result = await fetchSpaces({ query, sortBy: "createdAt" });
    console.log(result.data, result.pagination);
  };
}
```

## Parameters

<ParamField path="page" type="number">
  Page number to fetch. Defaults to `1`.
</ParamField>

<ParamField path="limit" type="number">
  Number of results per page.
</ParamField>

<ParamField path="sortBy" type="string">
  Sort order: `"createdAt"` (when the space was created), `"members"` (by active member count) or `"alphabetical"` (by name). Defaults to `"members"`.
</ParamField>

<ParamField path="sortDir" type="string">
  Direction, `"asc"` or `"desc"`, for any `sortBy`. Left out: A–Z for `"alphabetical"`, otherwise newest / most first.
</ParamField>

<ParamField path="query" type="string | null">
  Free-text search term, matched as a case-insensitive substring. A blank value is left out of the request, and `searchFields` with it.
</ParamField>

<ParamField path="searchFields" type='"slug" | "name" | "description" | null'>
  The one field `query` is matched against. Leave it out to match the slug, the name or the description.
</ParamField>

<ParamField path="parentSpaceId" type='string | "none" | "any" | null'>
  Which level of the space tree to return. A space id returns that space's public direct sub-spaces; this is how to page through a space's sub-spaces (add `sortBy: "alphabetical"` to order them A–Z by name). An id that matches no space returns an empty page, not a 404. `"none"` returns top-level spaces only. `"any"` returns spaces at every level. Left out or `null`: nothing is sent, so the API's default applies: top-level spaces only.
</ParamField>

<ParamField path="nsfwFilter" type='"include-all" | "exclude" | "only"'>
  Filter by each space's `nsfwEffective` (own flag OR any ancestor). `"include-all"` (default) adds no predicate; `"exclude"` drops effective-NSFW spaces; `"only"` returns only them. Because the filter keys off effective status, `"only"` may return an NSFW child whose safe parent is omitted — results are not guaranteed to form a contiguous tree. See [Space NSFW flagging](/v8/data-models/space#nsfw-flagging).
</ParamField>

<ParamField path="include" type="SpaceIncludeParam">
  Optional. A single value or an array; the only value is `"files"`. Pass it to include avatar and banner file objects in each result.
</ParamField>

## Returns

<ResponseField name="data" type="Space[]">
  Array of [Space](/v8/data-models/space) objects.
</ResponseField>

<ResponseField name="pagination" type="object">
  Pagination metadata including `page`, `limit`, `total`, and `hasMore`.
</ResponseField>

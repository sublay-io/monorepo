# Installing the Sublay CLI

The Sublay CLI copies fully customizable comment components directly into your project as editable source code. You can use it with `npx` (no installation required) or install it globally.

---

## Prerequisites

<Steps>
  <Step title="Node.js 20.5+">
    ```bash
    node --version
    # Should output v20.5.0 or higher
    ```
  </Step>

  <Step title="A React, React Native, or Expo project">
    Supported platforms:
    - React (Web) ✅
    - React Native ✅
    - Expo ✅
  </Step>

  <Step title="A Sublay project">
    Create a project in the [Sublay Dashboard](https://dash.sublay.io) if you haven't already.
  </Step>
</Steps>

---

## Using npx (Recommended)

No installation required — `npx` always uses the latest version:

```bash
npx @sublay/cli init
```

---

## Global Installation (Optional)

```bash
npm install -g @sublay/cli
```

Then use without `npx`:

```bash
sublay init
sublay add comments-threaded
```

<Note>
The rest of this documentation uses `npx @sublay/cli` to stay version-agnostic, but `sublay` works identically when installed globally.
</Note>

---

## Initializing Your Project

Run the init command from your project root:

```bash
cd your-react-app
npx @sublay/cli init
```

## What Happens During Init

1. **Detects your project type** from `package.json`
2. **Creates `sublay.json`** in your project root
3. **Checks for required peer dependencies** and offers to install missing ones

---

## The sublay.json File

After initialization, a `sublay.json` file is created in your project root:

```json
{
  "platform": "react",
  "style": "tailwind",
  "typescript": true,
  "paths": {
    "components": "src/components"
  },
  "aliases": {
    "@/components": "./src/components"
  }
}
```

See [Configuration](/v7/components/installation/configuration) for a full reference.

---

## Installing Dependencies

The CLI checks for required peer dependencies and prompts to install them if missing.

**React (Web):**
```bash
npm install @sublay/react-js
```

**React Native:**
```bash
npm install @sublay/react-native
```

**Expo:**
```bash
npm install @sublay/expo
```

<Warning>
These packages are **required**. Components use them for data fetching, authentication, real-time updates, and core functionality.
</Warning>

If your project already has one of these packages at a version below the one a component needs, `add` lists it as needing an upgrade and offers to install the required version.

## Command Reference

### `init`

```bash
npx @sublay/cli init
```

Creates `sublay.json` in the current directory. It asks its questions interactively and takes no options.

### `add <component>`

```bash
npx @sublay/cli add comments-threaded
```

Copies a component into the `paths.components` directory from `sublay.json`, using the platform and style configured there, then checks the component's dependencies against your `package.json`.

| Option | Description |
|--------|-------------|
| `--ref <branch>` | Read the component from this branch of the [Sublay repository](https://github.com/sublay-io/monorepo) instead of the default branch, `main`. |

```bash
npx @sublay/cli add comments-threaded --ref my-branch
```

`--ref` applies to that one command and is not saved to `sublay.json`. A branch name may contain letters, digits, `.`, `_`, `-` and `/`. A commit pushed to a branch can take a few minutes to be served.

A component installed from another branch can require different package versions than the one on `main`; the dependency check after the install lists what that branch's component needs.

`add` downloads every file before it writes any. If the branch or the component does not exist, or a file cannot be downloaded, the command names what is missing, exits with code 1, and leaves your project unchanged.

## Troubleshooting

<AccordionGroup>
  <Accordion title="Warning: No package.json found" icon="folder-xmark">
    ```
    ⚠️  No package.json found
    ```
    After installing a component's files, `add` reads your `package.json` to
    check which of the component's dependencies you already have. If there is
    no `package.json` in the current directory it prints this warning and skips
    that check — the component itself is still installed, and the command still
    succeeds.

    Run `add` from your project root (where `package.json` lives) to get the
    dependency check.
  </Accordion>

  <Accordion title="CLI hangs or doesn't respond" icon="hourglass">
    1. Press `Ctrl+C` to cancel
    2. Clear npx cache: `npx clear-npx-cache`
    3. Try again: `npx @sublay/cli init`
  </Accordion>

  <Accordion title="Want to change configuration" icon="gear">
    Delete `sublay.json` and run `npx @sublay/cli init` again, or manually edit the file and re-run `add` commands.
  </Accordion>
</AccordionGroup>

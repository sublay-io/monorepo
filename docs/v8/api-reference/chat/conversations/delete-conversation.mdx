---
title: "Delete Conversation"
api: "DELETE /v8/:projectId/chat/conversations/:conversationId"
description: "Delete a group or space conversation and all its messages"
---

Permanently deletes a conversation and all associated messages, members, reactions, and file attachments. This action is irreversible.

Direct conversations (`type: "direct"`) cannot be deleted.

**Authorization:**
- `group` conversations: caller must be an active `admin` member.
- `space` conversations: caller must be an active `admin` member of the parent Space (a banned admin is refused).

## Path Parameters

<ParamField path="conversationId" type="string" required>
  The ID of the conversation to delete.
</ParamField>

## Query Parameters

<ParamField query="actingUserId" type="string">
  Service key only, and required with one: the user this request acts as. Must be allowed to delete the conversation (see **Authorization** above). A user token always acts as its own user and must not send it (`400 chat/acting-user-not-allowed`).
</ParamField>

## Response

```json
{ "message": "Conversation deleted." }
```

## Error Responses

<AccordionGroup>
  <Accordion title="Acting User Not Allowed — 400">
    A user token sent `actingUserId`, even naming its own user. Only a service key names the user it acts as; a user token always acts as its own user.
    ```json
    { "error": "actingUserId is only accepted with a service key. A user's own token always acts as that user.", "code": "chat/acting-user-not-allowed" }
    ```
  </Accordion>
  <Accordion title="User Not Found — 404">
    Returned when a service key names an `actingUserId` that isn't a user in this project.
    ```json
    { "error": "No user with this actingUserId exists in this project.", "code": "chat/user-not-found" }
    ```
  </Accordion>
  <Accordion title="Unsupported Parameter — 400">
    The request sent `userId`. On this route the user a service key acts as is `actingUserId`.

    With a service key:

    ```json
    {
      "error": "`userId` was renamed to `actingUserId`: send the user this service key acts as in `actingUserId`.",
      "code": "chat/unsupported-param",
      "param": "userId"
    }
    ```

    With a user token, or with no credentials:

    ```json
    {
      "error": "`userId` isn't accepted here: a user's own token always acts as that user.",
      "code": "chat/unsupported-param",
      "param": "userId"
    }
    ```
  </Accordion>
  <Accordion title="Missing User — 400">
    A service key sent no `actingUserId`.
    ```json
    { "error": "A service key must send actingUserId: the user this request acts as.", "code": "chat/missing-user-id" }
    ```
  </Accordion>
  <Accordion title="Not Found — 404">
    ```json
    { "error": "Conversation not found.", "code": "chat/not-found" }
    ```
  </Accordion>
  <Accordion title="Cannot Delete DM — 400 Bad Request">
    ```json
    { "error": "Direct conversations cannot be deleted.", "code": "chat/cannot-delete-dm" }
    ```
  </Accordion>
  <Accordion title="Forbidden (group) — 403">
    ```json
    { "error": "Only group admins can delete this conversation.", "code": "chat/not-a-member" }
    ```
  </Accordion>
  <Accordion title="Forbidden (space) — 403">
    ```json
    { "error": "Only space admins can delete the space conversation.", "code": "chat/not-a-member" }
    ```
  </Accordion>
</AccordionGroup>

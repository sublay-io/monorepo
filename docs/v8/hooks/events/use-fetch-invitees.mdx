## Overview

`useFetchInvitees` returns a callable that fetches the paginated invitee (guest) list for an event. Open to the event's hosts — for an event in a space, while they are active members of it and not banned in it or a space above it (otherwise `403 event/not-space-member`) — and to the space's active admins and moderators. Anyone else who can see the event receives `403 event/forbidden`, and anyone who can't see it `404`. Each item is an [EventInvite](/v8/data-models/event-invite) with the invited `user` populated.

## Usage Example

```tsx
import { useFetchInvitees } from "@sublay/react-js";

function useInvitees(eventId: string) {
  const fetchInvitees = useFetchInvitees();
  return () => fetchInvitees({ eventId, page: 1, limit: 20 });
}
```

## Parameters

<ParamField path="eventId" type="string" required>The event ID.</ParamField>
<ParamField path="page" type="number">Page number (1-indexed). Defaults to `1`.</ParamField>
<ParamField path="limit" type="number">Results per page. Capped at `100`.</ParamField>

## Returns

Returns a `Promise<PaginatedResponse<EventInvite>>` — `{ data, pagination }`.
